# 📄8.Type Casting-

## 📌 Theory

-Type casting is the process of converting a value from one data type to another.

-For example, converting an int into a float:
```cpp
int a = 10;
float b = (float)a;
```
-C++ supports both implicit and explicit type conversion.

### 🔹 1. Implicit Type Conversion-

-Implicit conversion happens automatically by the compiler when converting one compatible type to another.

-Example.
```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    double b = a;    // int is automatically converted to double

    cout << b;

    return 0;
}
```
-Output:
```
10
```
-Here:

-int → double

-The conversion happens automatically.

### 🔹 2. Explicit Type Conversion-

-Explicit conversion is performed manually by the programmer.

-Syntax:
```cpp
(type) value;
```
-Example:
```cpp
#include <iostream>
using namespace std;

int main()
{
    double num = 10.75;

    int result = (int)num;    // Explicitly converts double to int

    cout << result;

    return 0;
}
```
-Output:
```
10
```
-The decimal part is removed when converting double to int.

### 🔹 C++ Cast Syntax-

-C++ also provides a more modern syntax called static_cast.

-Syntax:
```cpp
static_cast<new_type>(value);
```
-Example:
```cpp
#include <iostream>
using namespace std;

int main()
{
    double num = 10.75;

    int result = static_cast<int>(num);  // Converts double to int

    cout << result;

    return 0;
}
```
-Output:
```
10
```
-static_cast is generally preferred over the old C-style (int) syntax because it makes the conversion more explicit.

### 🔹 Integer to Floating-Point-
```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 5;

    double b = static_cast<double>(a);

    cout << b;

    return 0;
}
```
-Output:
```
5
```
-The value is now stored as a double.

### 🔹 Floating-Point to Integer-
```cpp
#include <iostream>
using namespace std;

int main()
{
    double a = 5.99;

    int b = static_cast<int>(a);

    cout << b;

    return 0;
}
```
-Output:
```
5
```
-The fractional part is discarded; this does not round the number.

### 🔹 Character to Integer-

-Characters have corresponding integer character codes.
```cpp
#include <iostream>
using namespace std;

int main()
{
    char ch = 'A';

    int value = static_cast<int>(ch);  // Converts character to its integer code

    cout << value;

    return 0;
}
```
-For typical ASCII-based systems:
```
'A' → 65
```
### 🔹 Integer to Character-

-The reverse conversion is also possible.
```cpp
#include <iostream>
using namespace std;

int main()
{
    int value = 65;

    char ch = static_cast<char>(value);  // Converts integer code to character

    cout << ch;

    return 0;
}
```
-Output:
```
A
```
### 🔹 Type Casting in Division-

-Type casting is particularly useful when performing division.

-Without casting:
```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 2;

    cout << a / b;    // Integer division

    return 0;
}
```
-Output:
```
2
```
-With casting:
```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 5;
    int b = 2;

    double result = static_cast<double>(a) / b;

    cout << result;

    return 0;
}
```
-Output:
```
2.5
```
-Casting a to double causes the division to be performed using floating-point arithmetic.

## 📝 Important Points:-

-Implicit conversion → performed automatically by the compiler.

-Explicit conversion → performed manually by the programmer.

-static_cast<type>(value) is the standard C++ syntax for many basic conversions.

-Converting double to int discards the fractional part.

-Casting can be useful for obtaining decimal results from integer division.

-Be careful when converting between incompatible types because information can be lost.

## 🎯 Summary:

                    ┌──────────────┐
                    │ Type Casting │
                    └──────┬───────┘
                           │
                 ┌─────────┴─────────┐
                 ▼                   ▼
          ┌────────────┐      ┌────────────┐
          │  Implicit  │      │  Explicit  │
          └─────┬──────┘      └─────┬──────┘
                │                   │
                ▼             ┌─────┴─────┐
     Automatic Conversion     ▼           ▼
                          (int)value  static_cast<int>(value)
    
*Common syntax-
```

```
*Example-
```
double x = 10.5;

y becomes 10.
```
# 📄9.if-else Statement:

## 📌 Theory-

-The `if-else` statement is a **conditional statement** used to choose between two blocks of code.

* If the condition is **true**, the `if` block executes.
  
* If the condition is **false**, the `else` block executes.

### 🔹 Syntax-

```cpp
if (condition)
{
    // Executes when condition is true
}
else
{
    // Executes when condition is false
}
```

### 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    // Check whether number is greater than or equal to 0
    if (number >= 0)
    {
        // This block executes when the condition is true
        cout << "Positive number";
    }
    else
    {
        // This block executes when the condition is false
        cout << "Negative number";
    }

    return 0;
}
```

*Output-

```text
Positive number
```

### 🔹 Example with User Input

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age;

    // Take age as input from the user
    cout << "Enter your age: ";
    cin >> age;

    // Check whether the age is 18 or more
    if (age >= 18)
    {
        cout << "Adult";
    }
    else
    {
        cout << "Minor";
    }

    return 0;
}
```

### 🔹 Using Comparison Operators-

-Conditions commonly use comparison operators:

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

## 📝 Important Points

* `if` checks the condition.

* `else` executes when the `if` condition is false.

* Only **one** of the two blocks executes.
 
* The condition is written inside `()`.

* Curly braces `{}` define the block of statements.

* `else` cannot be used without a corresponding `if`.

## 🎯 Summary

```text
             if-else
                │
        Check the condition
           /          \
       TRUE           FALSE
        │               │
    if block         else block
        │               │
        └───────┬───────┘
                ↓
             Continue
```
#📄10.else-if Statement:-

## 📌 Theory-

-The `else-if` statement is used when there are **multiple conditions** to check.

-C++ checks the conditions **from top to bottom**:

* If the first `if` condition is true, its block executes.
  
* Otherwise, the next `else-if` condition is checked.
  
* This continues until a true condition is found.
  
* If none of the conditions are true, the `else` block executes.

## 🔹 Syntax-

```cpp
if (condition1)
{
    // Statements
}
else if (condition2)
{
    // Statements
}
else if (condition3)
{
    // Statements
}
else
{
    // Statements when all conditions are false
}
```

## 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int marks;

    // Take marks as input
    cout << "Enter your marks: ";
    cin >> marks;

    // Check the conditions from top to bottom
    if (marks >= 90)
    {
        cout << "Grade A";
    }
    else if (marks >= 75)
    {
        // Executes if marks are below 90 but at least 75
        cout << "Grade B";
    }
    else if (marks >= 60)
    {
        // Executes if marks are below 75 but at least 60
        cout << "Grade C";
    }
    else if (marks >= 40)
    {
        // Executes if marks are below 60 but at least 40
        cout << "Grade D";
    }
    else
    {
        // Executes when marks are below 40
        cout << "Fail";
    }

    return 0;
}
```

### Example Output-

```text
Enter your marks: 82
Grade B
```

## 🔹 How It Works-
```cpp
For `marks = 82`:
```
```text
marks >= 90  → False
marks >= 75  → True
                   ↓
               Grade B
```

-Once a condition becomes true, the remaining `else-if` conditions are **not checked**.

## 📝 Important Points

* `else-if` is used for **multiple conditions**.
  
* Conditions are evaluated from **top to bottom**.
  
* Only the **first true block** is executed.
  
* `else` is optional.
  
* There can be multiple `else-if` blocks.
  
* The order of conditions is important.

## 🎯 Summary-

```text
if
 │
 ├── False → else-if
 │             │
 │             ├── False → else-if
 │             │
 │             └── True → Execute
 │
 └── True → Execute
```
# 📄11. Nested if Statement-

## 📌 Theory-

-A **nested `if` statement** means placing one `if` statement inside another `if` statement.

-It is useful when a second condition should be checked **only if the first condition is true**.

## 🔹 Syntax-

```cpp
if (condition1)
{
    if (condition2)
    {
        // Statements
    }
}
```

## 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age;
    bool hasID;

    // Take age as input
    cout << "Enter your age: ";
    cin >> age;

    // Take ID status as input
    cout << "Do you have an ID? (1 = Yes, 0 = No): ";
    cin >> hasID;

    // First check whether the person is 18 or older
    if (age >= 18)
    {
        // This condition is checked only if age >= 18
        if (hasID)
        {
            cout << "Entry allowed";
        }
        else
        {
            cout << "ID required";
        }
    }
    else
    {
        // Executes when age is below 18
        cout << "Entry not allowed";
    }

    return 0;
}
```

### Example Output

```text
Enter your age: 20
Do you have an ID? (1 = Yes, 0 = No): 1
Entry allowed
```

## 🔹 How It Works

```text
             age >= 18?
              /      \
           False      True
             │          │
       Entry denied   Has ID?
                       /   \
                    False   True
                      │       │
                  ID needed  Entry allowed
```

## 🔹 Multiple Nested Conditions-

-An `if` can contain another `if`, which can contain another `if`.

```cpp
if (condition1)
{
    if (condition2)
    {
        if (condition3)
        {
            // Statements
        }
    }
}
```

-However, excessive nesting can make code difficult to read. When possible, simpler conditions or logical operators can improve readability.

## 📝 Important Points-

* Nested `if` means an `if` inside another `if`.
  
* The inner `if` is checked only when the outer condition allows execution to reach it.
  
* Multiple levels of nesting are possible.
  
* Proper indentation makes nested conditions easier to understand.
  
* Avoid unnecessary deep nesting.

## 🎯 Summary-

```text
Outer if
   │
   └── condition true
          │
          └── Inner if
                 │
                 ├── True  → Execute
                 └── False → Skip
```
# 📄12. switch Statement-

## 📌 Theory

-The `switch` statement is a **selection statement** used to execute one block of code from multiple possible choices.

-It compares an expression with different `case` values.

* `case` defines a possible value.
  
* `break` stops execution of the `switch`.
  
* `default` executes when no case matches.

## 🔹 Syntax-

```cpp
switch (expression)
{
    case value1:
        // Statements
        break;

    case value2:
        // Statements
        break;

    default:
        // Statements when no case matches
}
```

## 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int day;

    // Take a number representing a day
    cout << "Enter day number (1-7): ";
    cin >> day;

    // Compare day with each case
    switch (day)
    {
        case 1:
            cout << "Monday";
            break;  // Exit switch after executing this case

        case 2:
            cout << "Tuesday";
            break;

        case 3:
            cout << "Wednesday";
            break;

        case 4:
            cout << "Thursday";
            break;

        case 5:
            cout << "Friday";
            break;

        case 6:
            cout << "Saturday";
            break;

        case 7:
            cout << "Sunday";
            break;

        default:
            // Executes when day is not between 1 and 7
            cout << "Invalid day";
    }

    return 0;
}
```

### Example Output-

```text
Enter day number (1-7): 3
Wednesday
```

## 🔹 Importance of `break`-

-The `break` statement terminates the `switch` statement.

-Without `break`, C++ may continue executing the statements in the following cases. This behavior is called **fall-through**.

```cpp
switch (choice)
{
    case 1:
        cout << "One";
        break;

    case 2:
        cout << "Two";
        break;
}
```

## 🔹 `default` Case-

-The `default` case runs when none of the `case` values match.

```cpp
int choice = 5;

switch (choice)
{
    case 1:
        cout << "Option 1";
        break;

    case 2:
        cout << "Option 2";
        break;

    default:
        cout << "Invalid option";
}
```

### Output-

```text
Invalid option
```

## 🔹 Switch vs if-else-

| `switch`                         | `if-else`                          |
| -------------------------------- | ---------------------------------- |
| Best for fixed values            | Best for conditions                |
| Uses `case` values               | Uses logical/relational conditions |
| Usually easier to read for menus | Better for ranges                  |
| Uses `break`                     | Does not require `break`           |
| Has optional `default`           | Has optional `else`                |

## 📝 Important Points-

* `switch` is useful for **multiple fixed choices**.
  
* Each `case` represents a possible value.
  
* `break` prevents unwanted fall-through.
  
* `default` handles unmatched values.
  
* `case` values must be constant values.
  
* `switch` is commonly used for menus and option-based programs.

## 🎯 Summary-

```text
              switch
                 │
          Check expression
                 │
       ┌─────────┼─────────┐
     case 1     case 2    case 3
       │          │          │
    Execute    Execute    Execute
       │          │          │
      break      break      break
                 │
              default
          if no case matches
```
# 13. break Statement

## 📌 Theory

-The `break` statement is used to **immediately stop** a loop or `switch` statement.

-When C++ reaches `break`, it exits the current loop or `switch` and continues executing the statement after it.

## 🔹 Syntax-

```cpp
break;
```

## 💻 Example with `for` Loop-

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Loop starts from 1
    for (int i = 1; i <= 10; i++)
    {
        // Stop the loop when i becomes 6
        if (i == 6)
        {
            break;
        }

        cout << i << endl;
    }

    // Program continues here after break
    cout << "Loop ended.";

    return 0;
}
```

### Output-

```text
1
2
3
4
5
Loop ended.
```

## 🔹 How It Works-

```text
Start loop
    ↓
Check condition
    ↓
Execute body
    ↓
Is break reached?
   /       \
 Yes       No
  ↓         ↓
Exit      Continue
loop      loop
```

## 🔹 `break` in `while` Loop-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int i = 1;

    while (i <= 10)
    {
        // Stop when i reaches 5
        if (i == 5)
        {
            break;
        }

        cout << i << endl;

        i++;
    }

    return 0;
}
```

### Output-

```text
1
2
3
4
```

## 🔹 `break` in `switch`-

`break` is also commonly used in a `switch` statement to stop execution of the current case.

```cpp
switch (choice)
{
    case 1:
        cout << "Option 1";
        break;

    case 2:
        cout << "Option 2";
        break;

    default:
        cout << "Invalid option";
}
```

## 🔹 `break` in Nested Loops-

-When `break` is used inside nested loops, it exits **only the innermost loop** in which it appears.

```cpp
#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 3; i++)
    {
        for (int j = 1; j <= 3; j++)
        {
            // Exit only the inner loop
            if (j == 2)
            {
                break;
            }

            cout << i << " " << j << endl;
        }
    }

    return 0;
}
```

## 📝 Important Points-

- `break` immediately terminates the current loop or `switch`.
  
- It transfers control to the statement after that loop or `switch`.
  
- It can be used with `for`, `while`, `do-while`, and `switch`.
  
- In nested loops, `break` exits only the **innermost** loop.
  
- `break;` must end with a semicolon.

## 🎯 Summary-

```text
Loop
  ↓
Condition / statements
  ↓
break reached?
  ↓
YES
  ↓
Exit current loop
  ↓
Continue program
```
