# 📄18.Functions Basics-

## 📌 Theory-

-A **function** is a block of code designed to perform a specific task.

-Functions help us:

- Avoid repeating the same code.
  
- Divide a large program into smaller parts.
  
- Make code easier to read and maintain.
  
- Reuse code whenever required.

## 🔹 Syntax-

```cpp
return_type function_name()
{
    // Statements
}
```

-A function is generally made up of:

| Part | Meaning |
|---|---|
| Return type | Type of value returned by the function |
| Function name | Name used to call the function |
| Parameters | Input values given to the function |
| Function body | Statements performed by the function |

## 🔹 Simple Function-

```cpp
#include <iostream>
using namespace std;

// Function definition
void greet()
{
    // This code runs when greet() is called
    cout << "Hello, World!";
}

int main()
{
    // Calling the function
    greet();

    return 0;
}
```

### Output-

```text
Hello, World!
```

## 🔹 Function Declaration-

-A function can be declared before `main()` and defined later.

```cpp
#include <iostream>
using namespace std;

// Function declaration
void greet();

int main()
{
    // Call the function
    greet();

    return 0;
}

// Function definition
void greet()
{
    cout << "Hello from function!";
}
```

## 🔹 Function with Parameters-

-Parameters allow us to send data to a function.

```cpp
#include <iostream>
using namespace std;

// Function receives two integer parameters
void add(int a, int b)
{
    // Add the two values
    cout << "Sum = " << a + b;
}

int main()
{
    // Pass 10 and 20 to the function
    add(10, 20);

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 Function with Return Value-

-A function can calculate a value and return it to the calling code.

```cpp
#include <iostream>
using namespace std;

// int means the function returns an integer
int add(int a, int b)
{
    // Return the sum to the calling code
    return a + b;
}

int main()
{
    // Store the returned value in result
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 `void` Function-

-A `void` function does **not return a value**.

```cpp
void display()
{
    cout << "Hello";
}
```

## 🔹 Function Call-

-A function executes when it is **called**.

```cpp
greet();
```

-Here, `greet()` is the function call.

## 📝 Important Points-

- A function is a reusable block of code.
  
- A function can accept parameters.
  
- A function can return a value.
  
- `void` means the function does not return a value.
  
- A function should be called to execute its code.
  
- Functions make programs more organized and reusable.

## 🎯 Summary-

```text
Function
   │
   ├── Function Name
   │
   ├── Parameters
   │       ↓
   │    Input
   │
   ├── Function Body
   │       ↓
   │    Processing
   │
   └── Return Value
           ↓
         Output
```
# 📄19.Function Parameters-

## 📌 Theory-

-**Parameters** are variables defined in a function that receive values when the function is called.

-They allow a function to work with different input values instead of using fixed values.

### Example

```cpp
void add(int a, int b)
```

-Here:

- `a` and `b` are **parameters**.
  
- The values passed while calling the function are called **arguments**.

```cpp
add(10, 20);
```

-Here, `10` and `20` are arguments.

## 🔹 Syntax

```cpp
return_type function_name(data_type parameter1, data_type parameter2)
{
    // Statements
}
```

## 🔹 Function with One Parameter

```cpp
#include <iostream>
using namespace std;

// 'number' is a parameter
void square(int number)
{
    // Calculate and display the square
    cout << "Square = " << number * number;
}

int main()
{
    // 5 is the argument passed to the function
    square(5);

    return 0;
}
```

### Output-

```text
Square = 25
```

## 🔹 Function with Multiple Parameters

```cpp
#include <iostream>
using namespace std;

// Function accepts two integer parameters
void add(int a, int b)
{
    cout << "Sum = " << a + b;
}

int main()
{
    // 10 and 20 are arguments
    add(10, 20);

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 Parameters with Return Value

-A function can accept parameters and also return a value.

```cpp
#include <iostream>
using namespace std;

// Receive two numbers and return their sum
int add(int a, int b)
{
    return a + b;
}

int main()
{
    // Pass values to the function
    int result = add(15, 25);

    cout << "Sum = " << result;

    return 0;
}
```

### Output

```text
Sum = 40
```

## 🔹 Parameters vs Arguments

| Parameters | Arguments |
|---|---|
| Written in the function definition | Written in the function call |
| Receive the input values | Provide the input values |
| Example: `int a` | Example: `10` |
| Also called formal parameters | Also called actual arguments |

-Example:

```cpp
int add(int a, int b)  // a and b → parameters
{
    return a + b;
}

add(10, 20);           // 10 and 20 → arguments
```

## 🔹 Different Data Types

-Parameters can have different data types.

```cpp
#include <iostream>
using namespace std;

// name is a string parameter and age is an integer parameter
void student(string name, int age)
{
    cout << "Name: " << name << endl;
    cout << "Age: " << age;
}

int main()
{
    // Pass a string and an integer as arguments
    student("Shivam", 19);

    return 0;
}
```

### Output-

```text
Name: Shivam
Age: 19
```

## 📝 Important Points-

- Parameters are variables used to receive data inside a function.
  
- Arguments are the actual values passed to the function.
  
- A function can have zero, one, or multiple parameters.
  
- Parameters can have different data types.
  
- The order of arguments should match the order of parameters.
  
- Functions can use parameters and return values together.

## 🎯 Summary-

```text
Function Definition
       ↓
int add(int a, int b)
             ↑
         Parameters
             ↑
             │
Function Call
       ↓
add(10, 20)
       ↑
    Arguments
```
# 📄20.Return Values-

## 📌 Theory

- **return value** is the value that a function sends back to the part of the program that called it.

-The `return` statement is used to send a value back.

-The function's **return type** must match the type of value it returns.

## 🔹 Syntax

```cpp
return_type function_name(parameters)
{
    // Statements

    return value;
}
```

## 💻 Example-

```cpp id="a8v3kp"
#include <iostream>
using namespace std;

// int means this function returns an integer
int add(int a, int b)
{
    // Calculate the sum and return it
    return a + b;
}

int main()
{
    // Call the function and store its returned value
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 Returning Different Data Types

-The return type can be different depending on the value being returned.

### Integer

```cpp id="e5b8nw"
int getNumber()
{
    // Return an integer
    return 100;
}
```

### Double

```cpp id="b7ydqf"
double getPrice()
{
    // Return a decimal value
    return 99.99;
}
```

### Character

```cpp id="r0g5ea"
char getGrade()
{
    // Return a character
    return 'A';
}
```

### Boolean

```cpp id="j1p4zs"
bool isAdult()
{
    // Return true or false
    return true;
}
```

## 🔹 Returning a Calculated Value

-A function does not have to return a fixed value. It can return the result of a calculation.

```cpp id="2xq8xk"
#include <iostream>
using namespace std;

// Return the larger of two numbers
int maximum(int a, int b)
{
    if (a > b)
    {
        return a;
    }
    else
    {
        return b;
    }
}

int main()
{
    // Store the returned maximum value
    int result = maximum(25, 40);

    cout << "Maximum = " << result;

    return 0;
}
```

### Output

```text
Maximum = 40
```

## 🔹 `return` in a `void` Function

-A `void` function does not return a value.

-However, `return;` can be used to **exit the function early**.

```cpp id="2pr6ez"
#include <iostream>
using namespace std;

void checkNumber(int number)
{
    // Exit the function if the number is negative
    if (number < 0)
    {
        return;
    }

    cout << "Positive number";
}

int main()
{
    checkNumber(10);

    return 0;
}
```

### Output

```text
Positive number
```

## 🔹 Function Result Used Directly

-The returned value does not always need to be stored in a variable.

```cpp id="8y3qfz"
#include <iostream>
using namespace std;

int multiply(int a, int b)
{
    return a * b;
}

int main()
{
    // Directly use the returned value in cout
    cout << multiply(5, 4);

    return 0;
}
```

### Output-

```text
20
```

## 📝 Important Points-

- `return` sends a value back from a function.
  
- The return type should match the returned value.
  
- A function can return only one value directly through `return`.
  
- `return` also immediately terminates the function.
  
- `void` functions do not return a value.
  
- `return;` can be used to exit a `void` function early.

## 🎯 Summary-

```text
Function Call
     ↓
Function executes
     ↓
Calculates result
     ↓
return value
     ↓
Calling code receives value
     ↓
Use the result
```
# 📄21.Default Arguments

## 📌 Theory-

-A **default argument** is a value automatically used by a function when the caller does not provide a value for that parameter.

-Default arguments make some function parameters **optional**.

## 🔹 Syntax-

```cpp
return_type function_name(data_type parameter = default_value)
{
    // Statements
}
```

## 💻 Basic Example-

```cpp
#include <iostream>
using namespace std;

// If no value is provided for b, it will automatically be 10
int add(int a, int b = 10)
{
    return a + b;
}

int main()
{
    // Both values are provided
    cout << add(5, 20) << endl;

    // Only a is provided, so b uses its default value 10
    cout << add(5);

    return 0;
}
```

### Output-

```text
25
15
```

## 🔹 Multiple Default Arguments-

-A function can have more than one default argument.

```cpp
#include <iostream>
using namespace std;

// b and c have default values
int add(int a, int b = 10, int c = 20)
{
    return a + b + c;
}

int main()
{
    // All three values are provided
    cout << add(1, 2, 3) << endl;

    // b and c use their default values
    cout << add(1) << endl;

    // Only c uses its default value
    cout << add(1, 2) << endl;

    return 0;
}
```

### Output-

```text
6
31
23
```

## 🔹 Important Rule

-Default arguments should generally be given from **right to left**.

### Correct-

```cpp
int calculate(int a, int b = 10, int c = 20);
```

-Here, `b` and `c` have default values.

### Incorrect-

```cpp
int calculate(int a = 10, int b, int c = 20);
```

-A parameter with a default value should not be followed by a parameter without a default value in the same parameter list.

## 🔹 Default Arguments with Function Declaration-

-Default arguments are commonly specified in the function declaration.

```cpp
#include <iostream>
using namespace std;

// Default value is specified in the declaration
int multiply(int a, int b = 2);

int main()
{
    cout << multiply(5);

    return 0;
}

// Do not need to repeat the default value here
int multiply(int a, int b)
{
    return a * b;
}
```

### Output

```text
10
```

## 🔹 Example with a String-

```cpp
#include <iostream>
using namespace std;

// If no name is provided, "Guest" is used
void greet(string name = "Guest")
{
    cout << "Hello, " << name;
}

int main()
{
    // Uses the provided argument
    greet("Shivam");

    cout << endl;

    // Uses the default argument
    greet();

    return 0;
}
```

### Output

```text
Hello, Shivam
Hello, Guest
```

## 📝 Important Points-

- Default arguments provide automatic values for missing arguments.
  
- They make function parameters optional.
  
- Default arguments are assigned in the function parameter list.
  
- Default parameters should generally be placed on the right side.
  
- If an argument is provided, the provided value is used instead of the default.
  
- Default arguments can be used with different data types.

## 🎯 Summary-

```text
Function:
add(int a, int b = 10)

        ↓

add(5, 20)
   ↓
Uses 20

add(5)
   ↓
Uses default value 10
```
# 📄22. Function Overloading-

## 📌 Theory

-**Function overloading** allows multiple functions to have the **same name** but different parameter lists.

-The compiler determines which function to call based on:

- Number of parameters
  
- Type of parameters
  
- Order of parameters

-Function overloading is an example of **compile-time polymorphism**.

## 🔹 Basic Syntax-

```cpp
return_type function_name(parameter_list)
{
    // Statements
}

return_type function_name(different_parameter_list)
{
    // Statements
}
```

-The functions must have different parameter lists.

## 💻 Example — Different Number of Parameters

```cpp
#include <iostream>
using namespace std;

// Function with two parameters
int add(int a, int b)
{
    return a + b;
}

// Same function name, but three parameters
int add(int a, int b, int c)
{
    return a + b + c;
}

int main()
{
    // Calls the two-parameter version
    cout << add(10, 20) << endl;

    // Calls the three-parameter version
    cout << add(10, 20, 30) << endl;

    return 0;
}
```

### Output-

```text
30
60
```

## 🔹 Different Parameter Types-

-Functions can also be overloaded using different parameter types.

```cpp
#include <iostream>
using namespace std;

// Function for integers
int display(int number)
{
    return number;
}

// Function for double values
double display(double number)
{
    return number;
}

int main()
{
    // Calls int version
    cout << display(10) << endl;

    // Calls double version
    cout << display(10.5);

    return 0;
}
```

### Output-

```text
10
10.5
```

## 🔹 Different Order of Parameters-

-The order of parameter types can also be different.

```cpp
#include <iostream>
using namespace std;

// int followed by double
void show(int a, double b)
{
    cout << "int, double" << endl;
}

// double followed by int
void show(double a, int b)
{
    cout << "double, int" << endl;
}

int main()
{
    // Calls the first function
    show(10, 5.5);

    // Calls the second function
    show(5.5, 10);

    return 0;
}
```

### Output-

```text
int, double
double, int
```

## 🔹 What Cannot Be Used for Overloading?-

-Functions **cannot** be overloaded by changing only the return type.

### ❌ Invalid-

```cpp
int calculate(int a)
{
    return a;
}

double calculate(int a)
{
    return a;
}
```

-Both functions have the same name and the same parameter list. The return type alone is not enough for overloading.

## 🔹 How the Compiler Chooses-

-Consider:

```cpp
void show(int a)
{
    cout << "Integer";
}

void show(double a)
{
    cout << "Double";
}
```

-When we write:

```cpp
show(10);
```

-C++ selects:

```cpp
show(int a);
```

-When we write:

```cpp
show(10.5);
```

-C++ selects:

```cpp
show(double a);
```

## 📝 Important Points-

- Function overloading means using the same function name with different parameter lists.
  
- The number, type, or order of parameters must differ.
  
- Return type alone cannot overload a function.
  
- Function overloading is resolved at **compile time**.
  
- It improves readability by allowing related operations to use the same function name.
  
- It is an example of **compile-time polymorphism**.

## 🎯 Summary-

```text
             Function Overloading
                     │
              Same Function Name
                     │
          ┌──────────┼──────────┐
          ↓          ↓          ↓
      2 params    3 params   Different type
          │          │          │
          ↓          ↓          ↓
       Function   Function   Function
        chosen     chosen     chosen
```
