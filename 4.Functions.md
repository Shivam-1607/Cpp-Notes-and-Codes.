# 📄18.Functions Basics-

## 📌 Theory-

-A **function** is a block of code designed to perform a specific task.

-Functions help us:

- Avoid repeating the same code.
  
- Divide a large program into smaller parts.
  
- Make code easier to read and maintain.
  
- Reuse code whenever required.

## 🔹 Syntax-

```cpp
return_type function_name()
{
    // Statements
}
```

-A function is generally made up of:

| Part | Meaning |
|---|---|
| Return type | Type of value returned by the function |
| Function name | Name used to call the function |
| Parameters | Input values given to the function |
| Function body | Statements performed by the function |

## 🔹 Simple Function-

```cpp
#include <iostream>
using namespace std;

// Function definition
void greet()
{
    // This code runs when greet() is called
    cout << "Hello, World!";
}

int main()
{
    // Calling the function
    greet();

    return 0;
}
```

### Output-

```text
Hello, World!
```

## 🔹 Function Declaration-

-A function can be declared before `main()` and defined later.

```cpp
#include <iostream>
using namespace std;

// Function declaration
void greet();

int main()
{
    // Call the function
    greet();

    return 0;
}

// Function definition
void greet()
{
    cout << "Hello from function!";
}
```

## 🔹 Function with Parameters-

-Parameters allow us to send data to a function.

```cpp
#include <iostream>
using namespace std;

// Function receives two integer parameters
void add(int a, int b)
{
    // Add the two values
    cout << "Sum = " << a + b;
}

int main()
{
    // Pass 10 and 20 to the function
    add(10, 20);

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 Function with Return Value-

-A function can calculate a value and return it to the calling code.

```cpp
#include <iostream>
using namespace std;

// int means the function returns an integer
int add(int a, int b)
{
    // Return the sum to the calling code
    return a + b;
}

int main()
{
    // Store the returned value in result
    int result = add(10, 20);

    cout << "Sum = " << result;

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 `void` Function-

-A `void` function does **not return a value**.

```cpp
void display()
{
    cout << "Hello";
}
```

## 🔹 Function Call-

-A function executes when it is **called**.

```cpp
greet();
```

-Here, `greet()` is the function call.

## 📝 Important Points-

- A function is a reusable block of code.
  
- A function can accept parameters.
  
- A function can return a value.
  
- `void` means the function does not return a value.
  
- A function should be called to execute its code.
  
- Functions make programs more organized and reusable.

## 🎯 Summary-

```text
Function
   │
   ├── Function Name
   │
   ├── Parameters
   │       ↓
   │    Input
   │
   ├── Function Body
   │       ↓
   │    Processing
   │
   └── Return Value
           ↓
         Output
```
# 📄19.Function Parameters-

## 📌 Theory-

-**Parameters** are variables defined in a function that receive values when the function is called.

-They allow a function to work with different input values instead of using fixed values.

### Example

```cpp
void add(int a, int b)
```

-Here:

- `a` and `b` are **parameters**.
  
- The values passed while calling the function are called **arguments**.

```cpp
add(10, 20);
```

-Here, `10` and `20` are arguments.

## 🔹 Syntax

```cpp
return_type function_name(data_type parameter1, data_type parameter2)
{
    // Statements
}
```

## 🔹 Function with One Parameter

```cpp
#include <iostream>
using namespace std;

// 'number' is a parameter
void square(int number)
{
    // Calculate and display the square
    cout << "Square = " << number * number;
}

int main()
{
    // 5 is the argument passed to the function
    square(5);

    return 0;
}
```

### Output-

```text
Square = 25
```

## 🔹 Function with Multiple Parameters

```cpp
#include <iostream>
using namespace std;

// Function accepts two integer parameters
void add(int a, int b)
{
    cout << "Sum = " << a + b;
}

int main()
{
    // 10 and 20 are arguments
    add(10, 20);

    return 0;
}
```

### Output-

```text
Sum = 30
```

## 🔹 Parameters with Return Value

-A function can accept parameters and also return a value.

```cpp
#include <iostream>
using namespace std;

// Receive two numbers and return their sum
int add(int a, int b)
{
    return a + b;
}

int main()
{
    // Pass values to the function
    int result = add(15, 25);

    cout << "Sum = " << result;

    return 0;
}
```

### Output

```text
Sum = 40
```

## 🔹 Parameters vs Arguments

| Parameters | Arguments |
|---|---|
| Written in the function definition | Written in the function call |
| Receive the input values | Provide the input values |
| Example: `int a` | Example: `10` |
| Also called formal parameters | Also called actual arguments |

-Example:

```cpp
int add(int a, int b)  // a and b → parameters
{
    return a + b;
}

add(10, 20);           // 10 and 20 → arguments
```

## 🔹 Different Data Types

-Parameters can have different data types.

```cpp
#include <iostream>
using namespace std;

// name is a string parameter and age is an integer parameter
void student(string name, int age)
{
    cout << "Name: " << name << endl;
    cout << "Age: " << age;
}

int main()
{
    // Pass a string and an integer as arguments
    student("Shivam", 19);

    return 0;
}
```

### Output-

```text
Name: Shivam
Age: 19
```

## 📝 Important Points-

- Parameters are variables used to receive data inside a function.
  
- Arguments are the actual values passed to the function.
  
- A function can have zero, one, or multiple parameters.
  
- Parameters can have different data types.
  
- The order of arguments should match the order of parameters.
  
- Functions can use parameters and return values together.

## 🎯 Summary-

```text
Function Definition
       ↓
int add(int a, int b)
             ↑
         Parameters
             ↑
             │
Function Call
       ↓
add(10, 20)
       ↑
    Arguments
```
