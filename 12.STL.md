# 📄61. Standard Template Library (STL) in C++-

## What is STL?-

- **STL (Standard Template Library)** is a collection of built-in template classes and functions in C++.
- It provides ready-made components such as containers, algorithms, and iterators.
- STL helps programmers perform common operations without writing everything from scratch.
- It is widely used in C++ for storing, accessing, searching, sorting, and manipulating data.

## Characteristics of STL-

- STL provides reusable and efficient code.
- It uses templates to support different data types.
- It contains containers for storing collections of data.
- It provides algorithms for operations such as sorting and searching.
- It uses iterators to access and move through container elements.
- It reduces code duplication and makes programs easier to maintain.

## Main Components of STL-

STL mainly consists of three important components:

1. **Containers** – Used to store and organize data.
2. **Algorithms** – Used to perform operations on data.
3. **Iterators** – Used to access and traverse elements in containers.

---

## 1. Containers-

- A **container** is an object that stores a collection of elements.
- STL provides different containers depending on how data needs to be stored and accessed.

### Types of Containers-

**A. Sequence Containers-**

- Sequence containers store elements in a linear order.
- Elements are arranged according to their position.

Common sequence containers:

| Container | Description |
|---|---|
| `vector` | Stores elements in a dynamic array. |
| `list` | Stores elements in a doubly linked list. |
| `deque` | Allows insertion and deletion at both ends. |
| `array` | Stores a fixed-size collection of elements. |
| `forward_list` | Stores elements in a singly linked list. |

### Example 1: Vector Container-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    for (int i = 0; i < numbers.size(); i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40
```

### Explanation-

1. The `vector` container is included using the `<vector>` header file.
2. A vector named `numbers` is created to store integers.
3. Four elements are initialized inside the vector.
4. The `for` loop accesses and displays each element.
5. A vector can automatically increase or decrease its size when elements are added or removed.

**B. Associative Containers-**

- Associative containers store elements in an organized order based on keys.
- They are generally implemented using balanced search trees.

| Container | Description |
|---|---|
| `set` | Stores unique elements in sorted order. |
| `multiset` | Stores duplicate elements in sorted order. |
| `map` | Stores unique keys with associated values. |
| `multimap` | Allows multiple values to be associated with the same key. |

### Example 2: Set Container-

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {30, 10, 20, 10};

    for (int x : numbers) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30
```

### Explanation-

1. The `set` container stores unique elements.
2. Duplicate values are automatically removed.
3. Elements are arranged in sorted order.
4. The range-based `for` loop displays all the elements.

**C. Unordered Associative Containers-**

- These containers store elements using hash tables.
- Elements are not maintained in sorted order.
- They generally provide fast average-case searching, insertion, and deletion.

| Container | Description |
|---|---|
| `unordered_set` | Stores unique elements without sorting. |
| `unordered_multiset` | Stores duplicate elements without sorting. |
| `unordered_map` | Stores unique keys with associated values. |
| `unordered_multimap` | Allows duplicate keys without sorting. |

**D. Container Adapters-**

- Container adapters provide a restricted interface to existing containers.
- They are designed for specific data-handling operations.

| Container Adapter | Description |
|---|---|
| `stack` | Follows LIFO (Last In, First Out). |
| `queue` | Follows FIFO (First In, First Out). |
| `priority_queue` | Gives priority to the highest-priority element by default. |

### Example 3: Stack Container-

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << s.top() << endl;

    s.pop();

    cout << s.top() << endl;

    return 0;
}
```

### Output-

```text
30
20
```

### Explanation-

1. The `stack` container is created using the `<stack>` header file.
2. The `push()` function inserts elements into the stack.
3. The `top()` function returns the top element.
4. The `pop()` function removes the top element.
5. Stack follows the LIFO principle.

---

## 2. Algorithms-

- **Algorithms** are predefined functions provided by STL to perform operations on container elements.
- They help us perform tasks such as sorting, searching, reversing, and counting elements.
- Most general-purpose STL algorithms are available through the `<algorithm>` header file.

### Common STL Algorithms-

| Algorithm | Description |
|---|---|
| `sort()` | Sorts elements in ascending order by default. |
| `reverse()` | Reverses the order of elements. |
| `find()` | Searches for a particular element. |
| `count()` | Counts occurrences of a value. |
| `max_element()` | Finds the maximum element. |
| `min_element()` | Finds the minimum element. |
| `binary_search()` | Searches for an element in a sorted range. |

### Example 4: Using STL Algorithms-

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {40, 10, 30, 20};

    sort(numbers.begin(), numbers.end());

    for (int x : numbers) {
        cout << x << " ";
    }

    cout << endl;

    reverse(numbers.begin(), numbers.end());

    for (int x : numbers) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40
40 30 20 10
```

### Explanation-

1. A vector named `numbers` stores four integer values.
2. `sort()` arranges the elements in ascending order.
3. `begin()` returns an iterator to the first element.
4. `end()` returns an iterator representing the position just after the last element.
5. `reverse()` reverses the order of the elements.
6. Both algorithms operate on the specified iterator range.

---

## 3. Iterators-

- An **iterator** is an object that allows us to access and traverse elements stored in a container.
- It works similarly to a pointer because it can refer to elements inside a container.
- Iterators connect containers with STL algorithms.

### Common Types of Iterators-

| Iterator | Description |
|---|---|
| Input Iterator | Reads elements while moving forward. |
| Output Iterator | Writes elements while moving forward. |
| Forward Iterator | Reads and writes elements while moving forward. |
| Bidirectional Iterator | Moves both forward and backward. |
| Random Access Iterator | Supports direct access and movement in both directions. |
| Contiguous Iterator | Provides random access to elements stored contiguously in memory. |

### Example 5: Using Iterators-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numbers = {10, 20, 30, 40};

    vector<int>::iterator it;

    for (it = numbers.begin(); it != numbers.end(); it++) {
        cout << *it << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40
```

### Explanation-

1. A vector named `numbers` stores four integer values.
2. `vector<int>::iterator` declares an iterator for an integer vector.
3. `begin()` returns an iterator pointing to the first element.
4. `end()` represents the position just after the last element.
5. `it++` moves the iterator to the next element.
6. `*it` accesses the value stored at the iterator's current position.

---

## Advantages of STL-

1. **Code Reusability:** STL provides ready-made components that can be reused in different programs.
2. **Time Saving:** Programmers do not need to implement common data structures and algorithms manually.
3. **Efficiency:** STL components are designed to provide efficient operations.
4. **Flexibility:** Templates allow STL components to work with different data types.
5. **Easy Maintenance:** Standard components make programs easier to understand and maintain.

## Important Points About STL-

- STL is a part of the C++ Standard Library.
- Containers are used to store data.
- Algorithms are used to perform operations on data.
- Iterators are used to access and traverse container elements.
- Different containers have different performance characteristics.
- The `<algorithm>` header provides many commonly used algorithms.
- The `<vector>`, `<list>`, `<map>`, and `<set>` headers provide their respective containers.

## Summary-

- STL stands for Standard Template Library.
- It provides reusable template-based components in C++.
- Its three main components are containers, algorithms, and iterators.
- Containers store data, algorithms process data, and iterators access data.
- STL makes C++ programming more efficient and reduces unnecessary code.

# 📄62. Vector in C++ (STL)-

## What is a Vector?-

- A **vector** is a sequence container in C++ STL that stores elements in a dynamic array.
- Unlike a normal array, a vector can automatically change its size when elements are added or removed.
- Vector elements are stored in contiguous memory locations, which allows direct access using an index.
- Vectors are commonly used when the number of elements may change during program execution.

## Characteristics of Vector-

- A vector stores elements of the same data type.
- It can dynamically increase or decrease its size.
- Elements are stored in contiguous memory locations.
- Elements can be accessed using an index.
- It supports insertion and deletion of elements.
- It provides several built-in member functions.
- It is available through the `<vector>` header file.

## Declaration of Vector-

### Syntax-

```cpp
vector<data_type> vector_name;
```

### Example-

```cpp
vector<int> numbers;
```

- `vector` – Keyword used to declare a vector.
- `int` – Data type of the elements.
- `numbers` – Name of the vector.

## Initialization of Vector-

A vector can be initialized in different ways.

### Example 1: Different Ways to Initialize a Vector-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v1;
    vector<int> v2 = {10, 20, 30};
    vector<int> v3(5, 100);

    cout << "Vector 1 size: " << v1.size() << endl;

    for (int x : v2) {
        cout << x << " ";
    }

    cout << endl;

    for (int x : v3) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
Vector 1 size: 0
10 20 30
100 100 100 100 100
```

### Explanation-

1. `v1` creates an empty vector.
2. `v2` creates a vector initialized with three values.
3. `v3(5, 100)` creates a vector containing five elements, each initialized to `100`.
4. The `size()` function returns the number of elements in a vector.
5. Range-based `for` loops are used to display vector elements.

---

## Common Member Functions of Vector-

| Function | Description |
|---|---|
| `push_back()` | Adds an element at the end. |
| `pop_back()` | Removes the last element. |
| `size()` | Returns the number of elements. |
| `capacity()` | Returns the number of elements that can fit in the currently allocated storage without reallocation. |
| `empty()` | Checks whether the vector is empty. |
| `front()` | Returns the first element. |
| `back()` | Returns the last element. |
| `at()` | Accesses an element with bounds checking. |
| `clear()` | Removes all elements. |
| `insert()` | Inserts an element at a specified position. |
| `erase()` | Removes an element or a range of elements. |
| `begin()` | Returns an iterator to the first element. |
| `end()` | Returns an iterator to the position after the last element. |
| `resize()` | Changes the number of elements. |

## 1. push_back() Function-

- The `push_back()` function adds a new element at the end of the vector.

### Example 2-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    v.push_back(40);
    v.push_back(50);

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40 50
```

### Explanation-

1. A vector is initialized with three elements.
2. `push_back(40)` adds `40` at the end.
3. `push_back(50)` adds `50` after `40`.
4. The loop displays all vector elements.

## 2. pop_back() Function-

- The `pop_back()` function removes the last element from the vector.
- It does not return the removed element.

### Example 3-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40};

    v.pop_back();

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30
```

### Explanation-

1. A vector is initialized with four elements.
2. `pop_back()` removes the last element, which is `40`.
3. The remaining elements are displayed.

## 3. size() and capacity() Functions-

- The `size()` function returns the current number of elements in a vector.
- The `capacity()` function returns the number of elements that can fit in the allocated storage without requiring reallocation.
- Capacity is always greater than or equal to size.

### Example 4-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    cout << "Size: " << v.size() << endl;
    cout << "Capacity: " << v.capacity() << endl;

    return 0;
}
```

### Possible Output-

```text
Size: 3
Capacity: 3
```

### Explanation-

1. The vector contains three elements.
2. `size()` returns `3`.
3. `capacity()` returns the allocated storage capacity.
4. The exact capacity can vary depending on the implementation and how the vector was constructed.

## 4. at() and [] Operators-

- Both `at()` and the `[]` operator are used to access vector elements using their index.
- The `at()` function performs bounds checking and throws an `out_of_range` exception if the index is invalid.
- The `[]` operator does not perform bounds checking.

### Example 5-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    cout << "Using at(): " << v.at(1) << endl;
    cout << "Using []: " << v[2] << endl;

    return 0;
}
```

### Output-

```text
Using at(): 20
Using []: 30
```

### Explanation-

1. `v.at(1)` accesses the element at index `1`.
2. `v[2]` accesses the element at index `2`.
3. Vector indexing starts from `0`.
4. Therefore, the values returned are `20` and `30`.

## 5. insert() Function-

- The `insert()` function adds an element at a specified position in a vector.
- It uses an iterator to identify the insertion position.

### Example 6-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 40};

    v.insert(v.begin() + 2, 30);

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40
```

### Explanation-

1. The vector initially contains `10`, `20`, and `40`.
2. `begin()` returns an iterator to the first element.
3. `begin() + 2` identifies the position with index `2`.
4. `insert()` adds `30` at that position.
5. The updated vector is displayed.

## 6. erase() Function-

- The `erase()` function removes an element or a range of elements from a vector.
- It uses iterators to identify the elements to be removed.

### Example 7-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30, 40, 50};

    v.erase(v.begin() + 1);

    for (int x : v) {
        cout << x << " ";
    }

    return 0;
}
```

### Output-

```text
10 30 40 50
```

### Explanation-

1. A vector is initialized with five elements.
2. `begin() + 1` identifies the element at index `1`.
3. `erase()` removes the element `20`.
4. The remaining elements are displayed.

## 7. clear() and empty() Functions-

- The `clear()` function removes all elements from a vector.
- The `empty()` function checks whether a vector contains any elements.
- It returns `true` if the vector is empty; otherwise, it returns `false`.

### Example 8-

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    v.clear();

    if (v.empty()) {
        cout << "Vector is empty";
    } else {
        cout << "Vector is not empty";
    }

    return 0;
}
```

### Output-

```text
Vector is empty
```

### Explanation-

1. A vector is initialized with three elements.
2. `clear()` removes all elements.
3. `empty()` checks whether the vector contains any elements.
4. Since all elements have been removed, it returns `true`.

---

## Advantages of Vector-

1. **Dynamic Size:** A vector can automatically grow or shrink during program execution.
2. **Direct Access:** Elements can be accessed quickly using indexes.
3. **Easy Insertion:** Elements can be added at the end using `push_back()`.
4. **Memory Management:** Vector manages its allocated memory automatically.
5. **STL Support:** It works with STL algorithms and iterators.

## Disadvantages of Vector-

1. **Insertion Cost:** Inserting elements near the beginning or middle can be slow because other elements may need to be shifted.
2. **Deletion Cost:** Removing elements from the beginning or middle can require shifting remaining elements.
3. **Reallocation:** Adding elements beyond the current capacity may require allocating new memory and moving existing elements.
4. **Memory Overhead:** A vector may allocate more memory than its current size requires.

## Difference Between Array and Vector-

| Array | Vector |
|---|---|
| Usually has a fixed size after creation. | Can dynamically change its size. |
| Can be declared without including a special container header. | Requires the `<vector>` header. |
| Does not provide member functions like `push_back()`. | Provides functions like `push_back()` and `pop_back()`. |
| Does not automatically manage dynamic resizing. | Automatically manages resizing. |
| Can be stored on the stack or dynamically allocated, depending on how it is declared. | Manages its element storage dynamically. |

## Important Points About Vector-

- Vector is a sequence container in C++ STL.
- It is declared using the `<vector>` header file.
- Vector indexing starts from `0`.
- Vector elements are stored in contiguous memory locations.
- `push_back()` adds an element at the end.
- `pop_back()` removes the last element.
- `size()` returns the number of elements.
- `capacity()` returns the allocated storage capacity.
- `clear()` removes all elements but does not necessarily release allocated capacity.
- Accessing an invalid index using `[]` results in undefined behavior.

## Summary-

- A vector is a dynamic array provided by C++ STL.
- It can store multiple elements of the same data type.
- It automatically manages its size and memory.
- It provides useful functions such as `push_back()`, `pop_back()`, `size()`, `insert()`, and `erase()`.
- Vectors are useful when the number of elements may change during program execution.
