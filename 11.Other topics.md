# 📄58. Type Conversion in C++-

## What is Type Conversion?-

-**Type conversion** is the process of converting a value from one data type to another data type.

-It allows us to work with different data types in a C++ program.

-For example, an integer value can be converted into a floating-point value, or a floating-point value can be converted into an integer.

-Type conversion in C++ is mainly divided into two types:

1. **Implicit Type Conversion**
2. **Explicit Type Conversion**

## Types of Type Conversion-

### 1. Implicit Type Conversion-

-**Implicit type conversion** is the conversion of one data type into another automatically by the compiler.

-It is also known as **automatic type conversion**.

-The compiler performs this conversion without requiring the programmer to write a type cast.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 10;

    // Automatically converting int into double
    double result = num;

    cout << "Integer value: " << num << endl;
    cout << "Double value: " << result << endl;

    return 0;
}
```

### Output-

```text
Integer value: 10
Double value: 10
```

### Explanation-

1. An integer variable `num` is initialized with the value `10`.
2. A double variable `result` is declared.
3. The integer value is automatically converted into a double.
4. The converted value is stored in `result`.
5. Both values are displayed.

### Important Points of Implicit Type Conversion-

* The compiler performs the conversion automatically.
* No explicit type casting is required.
* It commonly occurs when values of different data types are used in expressions.
* Converting a smaller-range type to a larger-range type often avoids loss of information, but not every implicit conversion is lossless.
* Converting a floating-point value to an integer can discard the fractional part.

## 2. Explicit Type Conversion-

-**Explicit type conversion** is the process of manually converting a value from one data type to another by specifying the desired type.

-It is also known as **type casting**.

-The programmer explicitly tells the compiler which type conversion is required.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 10.75;

    // Explicitly converting double into int
    int result = (int)num;

    cout << "Original value: " << num << endl;
    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Original value: 10.75
Converted value: 10
```

### Explanation-

1. A double variable `num` is initialized with `10.75`.
2. `(int)num` explicitly converts the double value into an integer.
3. The fractional part is discarded during the conversion.
4. The converted value `10` is stored in `result`.
5. Both values are displayed.

### Important Points of Explicit Type Conversion-

* The programmer specifies the target data type.
* It is also called type casting.
* It can be used to convert values between different data types.
* Converting from a floating-point type to an integer discards the fractional part.
* Explicit conversion does not guarantee that the conversion is safe or lossless.

## 3. Different Ways of Explicit Type Casting-

C++ provides different ways to perform explicit type conversion.

### A. C-Style Casting-

C-style casting uses parentheses around the target data type.

**Syntax-**

```cpp
(targetType)expression;
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 15.85;

    int result = (int)num;

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 15
```

### B. Functional-Style Casting-

Functional-style casting uses the target type followed by parentheses containing the value.

**Syntax-**

```cpp
targetType(expression);
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 25.75;

    int result = int(num);

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 25
```

### C. static_cast-

`static_cast` is a C++ casting operator used for well-defined conversions, such as converting an integer into a double or a double into an integer.

**Syntax-**

```cpp
static_cast<targetType>(expression);
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 45.95;

    int result = static_cast<int>(num);

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 45
```

### Explanation-

1. `static_cast<int>(num)` converts the double value into an integer.
2. The fractional part is discarded.
3. The converted value is stored in `result`.
4. The result is displayed.

**Important:** In modern C++, `static_cast` is generally preferred over C-style casting because it makes the intended conversion clearer.

## 4. Type Conversion in Expressions-

When different data types are used in an expression, C++ may automatically convert one or more values to a common type before performing the operation.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    double b = 5.5;

    double result = a + b;

    cout << "Result: " << result << endl;

    return 0;
}
```

### Output-

```text
Result: 15.5
```

### Explanation-

1. Variable `a` contains an integer value `10`.
2. Variable `b` contains a double value `5.5`.
3. Before addition, the integer value is converted into a double.
4. The addition is performed as `10.0 + 5.5`.
5. The final result is `15.5`.

## 5. Type Conversion Between Class and Basic Data Types-

C++ also allows conversion between user-defined class types and built-in data types.

There are two common forms:

### A. Basic Data Type to Class Type-

A constructor can be used to convert a basic data type into a class object.

**Example-**

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    // Conversion constructor
    Number(int n) {
        value = n;
    }
};

int main() {
    // Converting int into a class object
    Number obj = 100;

    cout << "Value: " << obj.value << endl;

    return 0;
}
```

### Output-

```text
Value: 100
```

### Explanation-

1. The `Number` class contains an integer data member named `value`.
2. Its constructor accepts an integer argument.
3. The statement `Number obj = 100;` creates an object using that constructor.
4. The integer value `100` is stored in the object's data member.
5. The value is displayed.

**Note:** This is an example of an implicit conversion through a converting constructor. The constructor can be declared `explicit` to prevent this implicit conversion.

### B. Class Type to Basic Data Type-

A conversion function can be used to convert a class object into a basic data type.

**Example-**

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int n) {
        value = n;
    }

    // Conversion function
    operator int() {
        return value;
    }
};

int main() {
    Number obj(50);

    // Converting class object into int
    int num = obj;

    cout << "Integer value: " << num << endl;

    return 0;
}
```

### Output-

```text
Integer value: 50
```

### Explanation-

1. The `Number` class contains an integer data member named `value`.
2. The conversion function `operator int()` defines how an object can be converted into an integer.
3. The object `obj` is initialized with the value `50`.
4. The statement `int num = obj;` invokes the conversion function.
5. The converted integer is stored in `num`.

## Difference Between Implicit and Explicit Type Conversion-

| Implicit Type Conversion | Explicit Type Conversion |
|---|---|
| Performed automatically by the compiler. | Specified manually by the programmer. |
| No explicit cast syntax is required. | Requires a cast or conversion syntax. |
| Also called automatic type conversion. | Also called type casting. |
| The compiler determines the required conversion. | The programmer specifies the target type. |
| May sometimes cause unexpected conversions. | Makes the intended conversion more visible. |
| Example: `double x = 10;` | Example: `int x = static_cast<int>(10.5);` |

## Important Points-

* Type conversion changes a value from one data type to another.
* Implicit conversion is performed automatically by the compiler.
* Explicit conversion is specified by the programmer.
* C-style casting uses `(type)value`.
* Functional-style casting uses `type(value)`.
* `static_cast` is commonly preferred for ordinary explicit conversions in modern C++.
* Converting a floating-point value into an integer discards the fractional part.
* Constructors can convert basic data types into class objects.
* Conversion functions can convert class objects into basic data types.
* Type conversion may cause data loss, so the target type should be chosen carefully.

## Summary-

Type conversion in C++ is the process of converting a value from one data type to another. It is mainly divided into implicit and explicit conversion. Implicit conversion is performed automatically by the compiler, whereas explicit conversion is specified by the programmer using casting syntax. C++ also supports conversions between class types and basic data types using constructors and conversion functions.

# 📄59. Exception Handling in C++-

## What is Exception Handling?-

-**Exception handling** is a mechanism in C++ used to handle runtime errors and unexpected situations without abruptly terminating the program.

-An **exception** is an event that occurs during program execution and interrupts the normal flow of instructions.

-For example, dividing a number by zero or trying to access a resource that is unavailable can cause an error that needs to be handled.

-C++ provides three main keywords for exception handling:

1. `try`
2. `throw`
3. `catch`

-Exception handling helps separate error-handling code from normal program logic.

## Characteristics of Exception Handling-

* It helps handle runtime errors and exceptional conditions.
* It uses the `try`, `throw`, and `catch` keywords.
* The `try` block contains code that may throw an exception.
* The `throw` keyword is used to signal an exception.
* The `catch` block handles an exception thrown from a corresponding `try` block.
* Multiple `catch` blocks can handle different exception types.
* A single `try` block can have multiple `catch` blocks.
* If no matching handler is found, the exception is passed to an enclosing handler.
* If no handler is found, the program terminates.
* Exception handling helps maintain a clear separation between normal and error-handling code.

## Basic Syntax-

```cpp
try {
    // Code that may cause an exception

    throw exception;
}
catch (dataType variable) {
    // Code to handle the exception
}
```

**Explanation-**

1. `try` contains the statements that may generate an exception.
2. `throw` signals an exception when an exceptional condition occurs.
3. `catch` receives and handles the thrown exception.
4. The `dataType` specifies the type of exception the handler can catch.

## 1. Simple Example of Exception Handling-

```cpp
#include <iostream>
using namespace std;

int main() {

    try {
        throw 10;
    }

    catch (int e) {
        cout << "Exception caught: " << e << endl;
    }

    return 0;
}
```

### Output-

```text
Exception caught: 10
```

### Explanation-

1. The `try` block contains the statement `throw 10`.
2. The `throw` keyword generates an integer exception.
3. The program searches for a matching `catch` block.
4. The `catch(int e)` block handles the exception.
5. The value `10` is stored in `e` and displayed.

## 2. Exception Handling with Division by Zero-

We can use exception handling to prevent invalid division operations.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 0;

    try {
        if (b == 0) {
            throw "Division by zero is not allowed!";
        }

        cout << "Result: " << a / b << endl;
    }

    catch (const char* message) {
        cout << "Error: " << message << endl;
    }

    return 0;
}
```

### Output-

```text
Error: Division by zero is not allowed!
```

### Explanation-

1. Two integer variables are declared.
2. The variable `b` contains zero.
3. The `try` block checks whether the divisor is zero.
4. If it is zero, the program throws an exception.
5. The `catch` block receives the error message and displays it.
6. The division operation is skipped because the exception is thrown first.

**Important:** In C++, integer division by zero causes undefined behavior. Checking the divisor before performing the operation is necessary.

## 3. Multiple Catch Blocks-

C++ allows us to use multiple `catch` blocks to handle different types of exceptions.

```cpp
#include <iostream>
using namespace std;

int main() {

    try {
        int choice = 2;

        if (choice == 1) {
            throw 10;
        }
        else if (choice == 2) {
            throw 5.5;
        }
        else {
            throw "Unknown error";
        }
    }

    catch (int e) {
        cout << "Integer exception: " << e << endl;
    }

    catch (double e) {
        cout << "Double exception: " << e << endl;
    }

    catch (const char* e) {
        cout << "String exception: " << e << endl;
    }

    return 0;
}
```

### Output-

```text
Double exception: 5.5
```

### Explanation-

1. The `try` block checks the value of `choice`.
2. Since `choice` is `2`, the program throws the double value `5.5`.
3. The compiler searches for a matching exception handler at runtime.
4. The `catch(double e)` block handles the exception.
5. The other `catch` blocks are skipped.

## 4. Catch-All Handler-

C++ provides a special catch-all handler using `catch(...)`.

-It can handle exceptions of any type that are not already handled by an earlier matching handler.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {

    try {
        throw 'A';
    }

    catch (int e) {
        cout << "Integer exception caught." << endl;
    }

    catch (...) {
        cout << "Unknown exception caught." << endl;
    }

    return 0;
}
```

### Output-

```text
Unknown exception caught.
```

### Explanation-

1. The `try` block throws the character `'A'`.
2. The first handler accepts only integer exceptions.
3. Since the thrown value is a character, that handler does not match.
4. The catch-all handler `catch(...)` handles the exception.
5. The message is displayed.

**Important:** A catch-all handler should generally be placed after specific `catch` handlers because it can catch any exception type.

## 5. Nested Try-Catch Blocks-

A `try` block can be placed inside another `try` block. This is called nested exception handling.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {

    try {
        cout << "Outer try block." << endl;

        try {
            throw 100;
        }

        catch (int e) {
            cout << "Inner exception: " << e << endl;
            throw;
        }
    }

    catch (int e) {
        cout << "Outer exception: " << e << endl;
    }

    return 0;
}
```

### Output-

```text
Outer try block.
Inner exception: 100
Outer exception: 100
```

### Explanation-

1. The outer `try` block contains another `try` block.
2. The inner `try` block throws the integer exception `100`.
3. The inner `catch` block handles the exception.
4. The `throw;` statement rethrows the currently handled exception.
5. The outer `catch` block receives the rethrown exception and handles it.

## 6. Standard Exceptions in C++-

C++ provides several predefined exception classes through its standard library.

Many standard exception classes are derived from `std::exception`.

| Exception | Description |
|---|---|
| `std::exception` | Base class for many standard exceptions. |
| `std::runtime_error` | Represents errors detected during runtime. |
| `std::logic_error` | Represents errors related to program logic. |
| `std::out_of_range` | Indicates an argument is outside an allowed range. |
| `std::invalid_argument` | Indicates an invalid argument. |
| `std::bad_alloc` | Indicates a memory allocation failure. |
| `std::overflow_error` | Represents an arithmetic overflow error reported through this exception type. |

### Example-

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

int main() {

    try {
        throw runtime_error("Something went wrong!");
    }

    catch (const exception& e) {
        cout << "Exception: " << e.what() << endl;
    }

    return 0;
}
```

### Output-

```text
Exception: Something went wrong!
```

### Explanation-

1. The `stdexcept` header provides standard exception classes such as `runtime_error`.
2. The `try` block throws a `runtime_error` object.
3. The `catch(const exception& e)` handler catches it through its base class.
4. The `what()` function returns a descriptive error message.
5. The message is displayed on the screen.

## 7. Rethrowing an Exception-

Sometimes a catch block may handle part of an exception but still need to pass it to another handler.

This can be done using the `throw;` statement.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {

    try {
        try {
            throw 50;
        }

        catch (int e) {
            cout << "Exception received: " << e << endl;

            // Rethrowing the exception
            throw;
        }
    }

    catch (int e) {
        cout << "Exception handled again: " << e << endl;
    }

    return 0;
}
```

### Output-

```text
Exception received: 50
Exception handled again: 50
```

### Explanation-

1. The inner `try` block throws the integer value `50`.
2. The inner `catch` block receives the exception.
3. The `throw;` statement rethrows the same exception.
4. The exception moves to the enclosing handler.
5. The outer `catch` block handles it.

## Advantages of Exception Handling-

* **Error management:** Helps handle exceptional situations during program execution.
* **Code separation:** Separates error-handling logic from normal program logic.
* **Better reliability:** Allows a program to recover from certain errors when recovery is possible.
* **Multiple handlers:** Different exception types can be handled separately.
* **Exception propagation:** An exception can be passed to an appropriate handler in an enclosing scope.

## Important Points-

* Exception handling is used to manage exceptional conditions during program execution.
* C++ uses three main keywords: `try`, `throw`, and `catch`.
* The `try` block contains code that may throw an exception.
* The `throw` keyword signals an exception.
* The `catch` block handles a matching exception.
* Multiple `catch` blocks can handle different exception types.
* `catch(...)` is a catch-all handler.
* `throw;` rethrows the currently handled exception.
* Standard exception classes are available through the C++ standard library.
* If an exception is not handled, the program terminates.
* Exception handling does not automatically fix every runtime error. Some errors, such as undefined behavior, cannot reliably be handled using exceptions.

## Summary-

Exception handling in C++ is a mechanism used to handle exceptional situations during program execution. It uses `try`, `throw`, and `catch` to detect, signal, and handle exceptions. C++ also supports multiple handlers, catch-all handlers, nested exception handling, and standard exception classes. It helps make programs more reliable by separating error-handling code from normal program logic.
