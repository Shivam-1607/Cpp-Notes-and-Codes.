# 📄58. Type Conversion in C++-

## What is Type Conversion?-

-**Type conversion** is the process of converting a value from one data type to another data type.

-It allows us to work with different data types in a C++ program.

-For example, an integer value can be converted into a floating-point value, or a floating-point value can be converted into an integer.

-Type conversion in C++ is mainly divided into two types:

1. **Implicit Type Conversion**
2. **Explicit Type Conversion**

## Types of Type Conversion-

### 1. Implicit Type Conversion-

-**Implicit type conversion** is the conversion of one data type into another automatically by the compiler.

-It is also known as **automatic type conversion**.

-The compiler performs this conversion without requiring the programmer to write a type cast.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 10;

    // Automatically converting int into double
    double result = num;

    cout << "Integer value: " << num << endl;
    cout << "Double value: " << result << endl;

    return 0;
}
```

### Output-

```text
Integer value: 10
Double value: 10
```

### Explanation-

1. An integer variable `num` is initialized with the value `10`.
2. A double variable `result` is declared.
3. The integer value is automatically converted into a double.
4. The converted value is stored in `result`.
5. Both values are displayed.

### Important Points of Implicit Type Conversion-

* The compiler performs the conversion automatically.
* No explicit type casting is required.
* It commonly occurs when values of different data types are used in expressions.
* Converting a smaller-range type to a larger-range type often avoids loss of information, but not every implicit conversion is lossless.
* Converting a floating-point value to an integer can discard the fractional part.

## 2. Explicit Type Conversion-

-**Explicit type conversion** is the process of manually converting a value from one data type to another by specifying the desired type.

-It is also known as **type casting**.

-The programmer explicitly tells the compiler which type conversion is required.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 10.75;

    // Explicitly converting double into int
    int result = (int)num;

    cout << "Original value: " << num << endl;
    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Original value: 10.75
Converted value: 10
```

### Explanation-

1. A double variable `num` is initialized with `10.75`.
2. `(int)num` explicitly converts the double value into an integer.
3. The fractional part is discarded during the conversion.
4. The converted value `10` is stored in `result`.
5. Both values are displayed.

### Important Points of Explicit Type Conversion-

* The programmer specifies the target data type.
* It is also called type casting.
* It can be used to convert values between different data types.
* Converting from a floating-point type to an integer discards the fractional part.
* Explicit conversion does not guarantee that the conversion is safe or lossless.

## 3. Different Ways of Explicit Type Casting-

C++ provides different ways to perform explicit type conversion.

### A. C-Style Casting-

C-style casting uses parentheses around the target data type.

**Syntax-**

```cpp
(targetType)expression;
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 15.85;

    int result = (int)num;

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 15
```

### B. Functional-Style Casting-

Functional-style casting uses the target type followed by parentheses containing the value.

**Syntax-**

```cpp
targetType(expression);
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 25.75;

    int result = int(num);

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 25
```

### C. static_cast-

`static_cast` is a C++ casting operator used for well-defined conversions, such as converting an integer into a double or a double into an integer.

**Syntax-**

```cpp
static_cast<targetType>(expression);
```

**Example-**

```cpp
#include <iostream>
using namespace std;

int main() {
    double num = 45.95;

    int result = static_cast<int>(num);

    cout << "Converted value: " << result << endl;

    return 0;
}
```

### Output-

```text
Converted value: 45
```

### Explanation-

1. `static_cast<int>(num)` converts the double value into an integer.
2. The fractional part is discarded.
3. The converted value is stored in `result`.
4. The result is displayed.

**Important:** In modern C++, `static_cast` is generally preferred over C-style casting because it makes the intended conversion clearer.

## 4. Type Conversion in Expressions-

When different data types are used in an expression, C++ may automatically convert one or more values to a common type before performing the operation.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    double b = 5.5;

    double result = a + b;

    cout << "Result: " << result << endl;

    return 0;
}
```

### Output-

```text
Result: 15.5
```

### Explanation-

1. Variable `a` contains an integer value `10`.
2. Variable `b` contains a double value `5.5`.
3. Before addition, the integer value is converted into a double.
4. The addition is performed as `10.0 + 5.5`.
5. The final result is `15.5`.

## 5. Type Conversion Between Class and Basic Data Types-

C++ also allows conversion between user-defined class types and built-in data types.

There are two common forms:

### A. Basic Data Type to Class Type-

A constructor can be used to convert a basic data type into a class object.

**Example-**

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    // Conversion constructor
    Number(int n) {
        value = n;
    }
};

int main() {
    // Converting int into a class object
    Number obj = 100;

    cout << "Value: " << obj.value << endl;

    return 0;
}
```

### Output-

```text
Value: 100
```

### Explanation-

1. The `Number` class contains an integer data member named `value`.
2. Its constructor accepts an integer argument.
3. The statement `Number obj = 100;` creates an object using that constructor.
4. The integer value `100` is stored in the object's data member.
5. The value is displayed.

**Note:** This is an example of an implicit conversion through a converting constructor. The constructor can be declared `explicit` to prevent this implicit conversion.

### B. Class Type to Basic Data Type-

A conversion function can be used to convert a class object into a basic data type.

**Example-**

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int n) {
        value = n;
    }

    // Conversion function
    operator int() {
        return value;
    }
};

int main() {
    Number obj(50);

    // Converting class object into int
    int num = obj;

    cout << "Integer value: " << num << endl;

    return 0;
}
```

### Output-

```text
Integer value: 50
```

### Explanation-

1. The `Number` class contains an integer data member named `value`.
2. The conversion function `operator int()` defines how an object can be converted into an integer.
3. The object `obj` is initialized with the value `50`.
4. The statement `int num = obj;` invokes the conversion function.
5. The converted integer is stored in `num`.

## Difference Between Implicit and Explicit Type Conversion-

| Implicit Type Conversion | Explicit Type Conversion |
|---|---|
| Performed automatically by the compiler. | Specified manually by the programmer. |
| No explicit cast syntax is required. | Requires a cast or conversion syntax. |
| Also called automatic type conversion. | Also called type casting. |
| The compiler determines the required conversion. | The programmer specifies the target type. |
| May sometimes cause unexpected conversions. | Makes the intended conversion more visible. |
| Example: `double x = 10;` | Example: `int x = static_cast<int>(10.5);` |

## Important Points-

* Type conversion changes a value from one data type to another.
* Implicit conversion is performed automatically by the compiler.
* Explicit conversion is specified by the programmer.
* C-style casting uses `(type)value`.
* Functional-style casting uses `type(value)`.
* `static_cast` is commonly preferred for ordinary explicit conversions in modern C++.
* Converting a floating-point value into an integer discards the fractional part.
* Constructors can convert basic data types into class objects.
* Conversion functions can convert class objects into basic data types.
* Type conversion may cause data loss, so the target type should be chosen carefully.

## Summary-

Type conversion in C++ is the process of converting a value from one data type to another. It is mainly divided into implicit and explicit conversion. Implicit conversion is performed automatically by the compiler, whereas explicit conversion is specified by the programmer using casting syntax. C++ also supports conversions between class types and basic data types using constructors and conversion functions.
