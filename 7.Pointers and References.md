# 📄34. Pointers Basics-

## 📌 Theory-

-A **pointer** is a variable that stores the **memory address of another variable**.

-Normally, a variable stores a value:

```cpp
int age = 20;
```

-Here:

```text
age → 20
```

-A pointer does not directly store `20`. Instead, it stores the address where `age` is stored in memory.

```text
age       → 20
           ↑
           |
pointer → address of age
```

-Pointers are an important part of C++ because they allow programs to work directly with memory.

---

## 🔹 Declaring a Pointer-

### Syntax

```cpp
dataType* pointerName;
```

-Example:

```cpp
int* ptr;
```

-This declares a pointer that can store the address of an `int` variable.

-Other examples:

```cpp
float* ptr1;
char* ptr2;
double* ptr3;
```

-The pointer type should generally match the type of variable whose address it stores.

---

## 🔹 Address-of Operator `&`-

-The `&` operator is called the **address-of operator**.

-It gives the memory address of a variable.

### Syntax

```cpp
&variableName
```

-Example:

```cpp
int age = 20;

cout << &age;
```

-This prints the memory address where `age` is stored.

-The exact address can be different every time the program runs.

---

## 💻 Example 1 — Getting a Variable's Address-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age = 20;

    // &age gives the memory address of age.
    cout << "Value of age: " << age << endl;

    cout << "Address of age: " << &age << endl;

    return 0;
}
```

### Example Output-

```text
Value of age: 20
Address of age: 0x7ffd1234
```

-The address shown is only an example. The actual address depends on the program's memory layout.

---

## 🔹 Storing an Address in a Pointer-

-We can store the address of a variable inside a pointer.

```cpp
int age = 20;

int* ptr = &age;
```

-Now:

```text
age → 20

ptr → address of age
```

-The pointer `ptr` does not contain the value `20` directly. It contains the address of `age`.

---

## 💻 Example 2 — Basic Pointer-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age = 20;

    // Store the address of age inside ptr.
    int* ptr = &age;

    // Display the value stored in age.
    cout << "Value of age: " << age << endl;

    // Display the address of age.
    cout << "Address of age: " << &age << endl;

    // ptr contains the address of age.
    cout << "Value stored in ptr: " << ptr << endl;

    return 0;
}
```

### Example Output-

```text
Value of age: 20
Address of age: 0x7ffd1234
Value stored in ptr: 0x7ffd1234
```

-Notice:

```text
&age == ptr
```

-Both represent the address of `age`.

---

## 🔹 Dereference Operator `*`-

-The `*` operator has another important use with pointers.

-It is called the **dereference operator** when used with a pointer.

-Dereferencing a pointer means:

> Go to the address stored in the pointer and access the value located there.

Example:

```cpp
int age = 20;
int* ptr = &age;

cout << *ptr;
```

Output:

```text
20
```

-Because `ptr` contains the address of `age`, `*ptr` accesses the value stored at that address.

## 💻 Example 4 — Changing a Variable Using a Pointer-

# 📄35. Pointers Dereferencing-

## 📌 Theory-

-**Dereferencing** means accessing the value stored at the memory address held by a pointer.

-The **dereference operator `*`** is used to access or modify the value of the variable pointed to by a pointer.

-For example:

```cpp
int number = 10;
int* ptr = &number;

// ptr stores the address of number
// *ptr accesses the value stored at that address
```

-Here:

* `number` → stores `10`
* `&number` → gives the address of `number`
* `ptr` → stores that address
* `*ptr` → gives the value `10`

---

## 🔹 Dereferencing a Pointer-

### Syntax-

```cpp
*pointerName
```

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // Create a pointer and store the address of number
    int* ptr = &number;

    // *ptr accesses the value stored at the address
    cout << *ptr << endl;

    return 0;
}
```

### Output-

```text
10
```

-The pointer `ptr` contains the address of `number`, and `*ptr` accesses the value stored at that address.

---

## 🔹 Reading a Value Through a Pointer-

-A pointer can be used to read the value of the original variable.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 19;

    // Store the address of age
    int* ptr = &age;

    // Read age using the pointer
    cout << "Age: " << *ptr << endl;

    return 0;
}
```

### Output-

```text
Age: 19
```

-`*ptr` gives us the value stored in `age`.

---

## 🔹 Changing a Value Through a Pointer-

-One of the important uses of dereferencing is that we can **change the original variable through the pointer**.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // ptr stores the address of number
    int* ptr = &number;

    // Change number through the pointer
    *ptr = 50;

    // number has now changed to 50
    cout << "Number: " << number << endl;

    return 0;
}
```

### Output-

```text
Number: 50
```

### What happened?-

-Initially:

```text
number = 10
```

-Then:

```cpp
*ptr = 50;
```

-means:

> Go to the address stored in `ptr` and put `50` there.

-Since `ptr` points to `number`, the value of `number` becomes `50`.

-`&` gives the **memory address** of a variable.

-:

# 📄36. Pointer Arithmetic-

## 📌 Theory-

--**Pointer arithmetic** means performing arithmetic operations on pointers.

-Pointers store memory addresses, so C++ allows us to perform certain operations on them.

-The main pointer arithmetic operations are:

* Increment `++`
  
* Decrement `--`
  
* Addition `+`
  
* Subtraction `-`
  
* Difference between two pointers

-Pointer arithmetic is especially useful when working with **arrays**.

---

## 🔹 Pointer Increment-

-The `++` operator moves a pointer to the **next element** of its data type.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // ptr stores the address of number
    int* ptr = &number;

    // Move the pointer forward
    ptr++;

    return 0;
}
```

-For an `int*`, `ptr++` does **not simply add 1 byte** to the address.

-It moves the pointer by the size of one `int`.

-For example, if an integer occupies 4 bytes:

```text
Before:
ptr → address 1000

After ptr++:
ptr → address 1004
```

-The exact addresses depend on the system.

---

## 🔹 Pointer Decrement-

-The `--` operator moves the pointer to the previous element.

```cpp
int* ptr;

ptr--;
```

-If an `int` occupies 4 bytes:

```text
Before:
ptr → 1004

After ptr--:
ptr → 1000
```

-Again, the actual addresses depend on the system.

---

## 🔹 Pointer Addition-

-We can add an integer to a pointer.

```cpp
ptr + 2
```

-This moves the pointer forward by **2 elements**, not necessarily 2 bytes.

-For example, if `ptr` is an `int*` and an `int` is 4 bytes:

```text
ptr       → address 1000
ptr + 1   → address 1004
ptr + 2   → address 1008
```

---

## 🔹 Pointer Subtraction-

-We can subtract an integer from a pointer.

```cpp
ptr - 2
```

-This moves the pointer backward by 2 elements.

-Example:

```text
ptr       → 1008
ptr - 1   → 1004
ptr - 2   → 1000
```

---

## 🔹 Pointer Arithmetic with Arrays-

-Pointer arithmetic becomes especially useful with arrays.

-Consider:

```cpp
int numbers[4] = {10, 20, 30, 40};
```

-The elements are stored sequentially in memory.

-Conceptually:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
```

-A pointer can point to the first element:

```cpp
int* ptr = numbers;
```

-Then:

```cpp
*ptr
```

-gives:

```text
10
```

-Moving the pointer:

```cpp
ptr++;
```

-now makes it point to the next element.

```text
*ptr → 20
```

---

## 💻 Example: Traversing an Array Using a Pointer-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // The array name represents the address of its first element
    int* ptr = numbers;

    // Print the first element
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    return 0;
}
```

### Output-

```text
10
20
30
40
50
```

---

## 🔹 Pointer Addition with an Array-

-Instead of repeatedly using `ptr++`, we can use pointer arithmetic directly.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element
    int* ptr = numbers;

    // Access different elements using pointer arithmetic
    cout << *(ptr + 0) << endl;
    cout << *(ptr + 1) << endl;
    cout << *(ptr + 2) << endl;
    cout << *(ptr + 3) << endl;
    cout << *(ptr + 4) << endl;

    return 0;
}
```

### Output-

```text
10
20
30
40
50
```

-The expressions work like this:

```text
*(ptr + 0) → numbers[0]
*(ptr + 1) → numbers[1]
*(ptr + 2) → numbers[2]
*(ptr + 3) → numbers[3]
*(ptr + 4) → numbers[4]
```

---

## 🔹 Pointer Arithmetic Does Not Always Move One Byte-

-This is an important concept.

-Suppose:

```cpp
int* ptr;
```

-If an `int` occupies 4 bytes, then:

```cpp
ptr + 1
```

-moves by 4 bytes.

-If:

```cpp
double* ptr;
```

-and a `double` occupies 8 bytes, then:

```cpp
ptr + 1
```

-moves by 8 bytes.

-Therefore:

> Pointer arithmetic moves according to the size of the pointer's data type.

---

## 🔹 Pointer Arithmetic with Different Data Types-

### Integer Pointer-

```cpp
int* ptr;
ptr++;
```

-Moves by the size of an `int`.

### Character Pointer-

```cpp
char* ptr;
ptr++;
```

-Moves by the size of a `char`, which is 1 byte.

### Double Pointer-

```cpp
double* ptr;
ptr++;
```

-Moves by the size of a `double`.

---

## 🔹 Subtracting Two Pointers-

-Two pointers pointing into the **same array** can be subtracted.

-The result tells us how many elements are between them.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element
    int* ptr1 = &numbers[0];

    // Point to the fourth element
    int* ptr2 = &numbers[3];

    // Find the number of elements between the pointers
    cout << ptr2 - ptr1 << endl;

    return 0;
}
```

### Output-

```text
3
```

-Why?

```text
numbers[0] → ptr1
numbers[1]
numbers[2]
numbers[3] → ptr2
```

-There are 3 element positions between them.

---

## 🔹 Pointer Comparison-

-Pointers can also be compared.

-For example:

```cpp
ptr1 < ptr2
ptr1 > ptr2
ptr1 == ptr2
ptr1 != ptr2
```

-Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr1 = &numbers[0];
    int* ptr2 = &numbers[2];

    // Check whether ptr1 and ptr2 point to the same location
    if (ptr1 == ptr2) {
        cout << "Same address";
    } else {
        cout << "Different addresses";
    }

    return 0;
}
```

### Output-

```text
Different addresses
```

---

## 🔹 Complete Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element of the array
    int* ptr = numbers;

    // Print the current value
    cout << "Current value: " << *ptr << endl;

    // Move one element forward
    ptr++;

    cout << "After ptr++: " << *ptr << endl;

    // Move another two elements forward
    ptr = ptr + 2;

    cout << "After ptr + 2: " << *ptr << endl;

    // Move one element backward
    ptr--;

    cout << "After ptr--: " << *ptr << endl;

    return 0;
}
```

### Output-

```text
Current value: 10
After ptr++: 20
After ptr + 2: 40
After ptr--: 30
```

---

## 📝 Important Points-

* Pointer arithmetic operates on memory addresses.
  
* `ptr++` moves to the next element.
  
* `ptr--` moves to the previous element.
  
* `ptr + n` moves forward by `n` elements.
  
* `ptr - n` moves backward by `n` elements.
  
* Pointer movement depends on the size of its data type.
  
* Pointer arithmetic is commonly used with arrays.
  
* Two pointers can be subtracted when they point into the same array.
  
* The result of subtracting two pointers represents the number of elements between them.
  
* Pointer arithmetic should only be used within a valid memory range.

## 🎯 Summary-

```text
ptr++       → next element
ptr--       → previous element
ptr + n     → n elements forward
ptr - n     → n elements backward
ptr2 - ptr1 → number of elements between pointers
```

-For arrays:

```cpp
int* ptr = numbers;
```

-then:

```cpp
*(ptr + 0) → first element
*(ptr + 1) → second element
*(ptr + 2) → third element
```

-Pointer arithmetic is the foundation for understanding how **pointers and arrays work together** in C++.

# 📄37.Pointers and Arrays-

## 📌 Theory-

-In C++, **arrays and pointers are closely related**.

-The name of an array can be used as the address of its **first element**.

-For example:

```cpp
int numbers[4] = {10, 20, 30, 40};
```

-The expression:

```cpp
numbers
```

-represents the address of:

```cpp
numbers[0]
```

-Therefore:

```cpp
int* ptr = numbers;
```

-makes `ptr` point to the first element of the array.

---

## 🔹 Array Name as an Address-

-Consider:

```cpp
int numbers[4] = {10, 20, 30, 40};
```

-The array can be visualized as:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
```

-The array name `numbers` points to the first element:

```text
numbers
   ↓
numbers[0]
```

-So:

```cpp
int* ptr = numbers;
```

-is equivalent to:

```cpp
int* ptr = &numbers[0];
```

-Both make `ptr` point to the first element.

---

## 🔹 Accessing the First Element-

```cpp
#include <iostream>

```

### Output-

```text
10
```

-Here:

```cpp
*ptr
```

-accesses:

```cpp
numbers[0]
```

---

## 🔹 Accessing Array Elements Using Pointer Arithmetic-

-Pointer arithmetic can be used to access different array elements.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element
    int* ptr = numbers;

    // Access elements using pointer arithmetic
    cout << *(ptr + 0) << endl;
    cout << *(ptr + 1) << endl;
    cout << *(ptr + 2) << endl;
    cout << *(ptr + 3) << endl;
    cout << *(ptr + 4) << endl;

    return 0;
}
```

### Output-

```text
10
20
30
40
50
```

-The relationship is:

```text
*(ptr + 0) → numbers[0]
*(ptr + 1) → numbers[1]
*(ptr + 2) → numbers[2]
*(ptr + 3) → numbers[3]
*(ptr + 4) → numbers[4]
```

## 🔹 Array Indexing and Pointer Arithmetic-

-An important fact in C++ is:

```cpp
numbers[i]
```

-is equivalent to:

```cpp
*(numbers + i)
```

-For example:

```cpp
numbers[2]
```

-is equivalent to:

```cpp
*(numbers + 2)
```

-Both access the third element.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[4] = {10, 20, 30, 40};

    // Access the third element using normal indexing
    cout << numbers[2] << endl;

    // Access the same element using pointer arithmetic
    cout << *(numbers + 2) << endl;

    return 0;
}
```

### Output-

```text
30
30
```

## 🔹 Using a Pointer to Modify an Array-

-A pointer can also modify array elements.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[4] = {10, 20, 30, 40};

    // Point to the first element
    int* ptr = numbers;

    // Change the first element
    *ptr = 100;

    // Change the third element
    *(ptr + 2) = 300;

    // Print the modified array
    for (int i = 0; i < 4; i++) {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
100 20 300 40
```

-The pointer directly modified the values stored in the array.

## 🔹 Traversing an Array Using a Pointer-

-A pointer can be moved through an array using `++`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Start at the first element
    int* ptr = numbers;

    // Move through all five elements
    for (int i = 0; i < 5; i++) {
        // Dereference ptr to get the current element
        cout << *ptr << " ";

        // Move the pointer to the next element
        ptr++;
    }

    return 0;
}
```

### Output

```text
10 20 30 40 50
```

-The pointer moves like this:

```text
ptr
 ↓
10 → 20 → 30 → 40 → 50
```

## 🔹 Pointer and Array Addresses-

-We can print the addresses of array elements.

#include <iostream>

int main() {

## 🔹 `numbers` vs `&numbers[0]`-

-For most expressions, the array name:

```cpp
numbers
```

-acts like the address of the first element:

```cpp
&numbers[0]
```

-Therefore:

```cpp
int* ptr1 = numbers;
int* ptr2 = &numbers[0];
```

-Both pointers point to the first element.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    // Both pointers point to the first element
    int* ptr1 = numbers;
    int* ptr2 = &numbers[0];

    cout << *ptr1 << endl;
    cout << *ptr2 << endl;

    return 0;
}
```

### Output-

```text
10
10
```

## 🔹 Important Difference: Array vs Pointer-

-Although arrays and pointers are closely related, they are **not the same thing**.

### Array-

```cpp
int numbers[5];
```

-Creates storage for 5 integers.

### Pointer-

```cpp
int* ptr;
```

-Creates a pointer variable that can store the address of an integer.

-Example:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

int* ptr = numbers;
```

-Here:

```text
numbers → array containing 5 integers

ptr → pointer storing the address of the first integer
```

---

## 🔹 Changing a Pointer vs Changing an Array-

-A pointer can be moved:

```cpp
ptr++;
```

-This changes where the pointer points.

-However, the array name itself cannot be incremented:

```cpp
numbers++;
```

-This is invalid.

-For example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr = numbers;

    // Move the pointer to the second element
    ptr++;

    cout << *ptr << endl;

    return 0;
}
```

### Output-

```text
20
```

-The pointer moved from the first element to the second element.

## 🔹 Traversing with Pointer Start and End-

-We can also use pointers to determine the beginning and end of an array.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Pointer to the first element
    int* start = numbers;

    // Pointer one position after the last element
    int* end = numbers + 5;

    // Continue until start reaches end
    while (start < end) {
        cout << *start << " ";

        // Move to the next element
        start++;
    }

    return 0;
}
```

### Output-

```text
10 20 30 40 50
```

-`numbers + 5` points **one position after the last element**. It should not be dereferenced.

---

## 🔹 Complete Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // The array name gives the address of the first element
    int* ptr = numbers;

    cout << "Array elements:" << endl;

    // Traverse the array using the pointer
    for (int i = 0; i < 5; i++) {
        // *ptr gives the current element
        cout << *ptr << " ";

        // Move to the next array element
        ptr++;
    }

    return 0;
}
```

### Output-

```text
Array elements:
10 20 30 40 50
```

## 📝 Important Points-

* An array name generally represents the address of its first element in expressions.
  
* `numbers` is equivalent to `&numbers[0]` when used as an expression that decays to a pointer.
  
* `int* ptr = numbers;` makes `ptr` point to the first element.
  
* `*(ptr + i)` can be used to access the `i`th element.
  
* `numbers[i]` is equivalent to `*(numbers + i)`.
  
* Pointers can be incremented to move through an array.
  
* A pointer can modify array elements through dereferencing.
  
* The array name itself cannot be incremented or assigned to.
  
* `numbers + size` points one position past the last element and must not be dereferenced.
  
* Arrays and pointers are related, but an array is not itself a pointer variable.

## 🎯 Summary-

-The most important relationship is:

```text
numbers[i] == *(numbers + i)
```

-For example:

```cpp
int numbers[4] = {10, 20, 30, 40};

int* ptr = numbers;
```

-Then:

```text
*ptr       → 10
*(ptr + 1) → 20
*(ptr + 2) → 30
*(ptr + 3) → 40
```

-This connection between **arrays, pointers, dereferencing, and pointer arithmetic** is fundamental to understanding pointers in C++.

# 📄38.References Basics-

## 📌 Theory-

-A **reference** is another name, or an **alias**, for an existing variable.

-Instead of creating a new variable, a reference gives an existing variable another name.

### Syntax-

```cpp
dataType& referenceName = variableName;
```

-For example:

```cpp
int number = 10;

int& ref = number;
```

-Here:

* `number` is the original variable.
  
* `ref` is a reference to `number`.
  
* Both names refer to the same value.

---

## 🔹 Basic Reference Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // ref becomes another name for number
    int& ref = number;

    // Access the value using the reference
    cout << ref << endl;

    return 0;
}
```

### Output-

```text
10
```

-The reference does not contain a separate copy of `number`.

-It simply provides another name for the same variable.

---

## 🔹 Changing a Variable Through a Reference-

-A reference can be used to modify the original variable.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // Create a reference to number
    int& ref = number;

    // Change number through the reference
    ref = 50;

    // The original variable has also changed
    cout << number << endl;

    return 0;
}
```

### Output-

```text
50
```

-Why?

```text
number → 10
   ↑
   |
  ref
```

-When we write:

```cpp
ref = 50;
```

-we are actually changing `number`.

---

## 🔹 Reference and Original Variable-

-Consider:

```cpp
int number = 25;
int& ref = number;
```

-Both names refer to the same variable:

```text
       ┌──────────────┐
number │     25       │
       └──────────────┘
          ↑       ↑
          |       |
       number     ref
```

-Therefore:

```cpp
number = 30;
```

-also means:

```text
ref → 30
```

-And:

```cpp
ref = 40;
```

-also means:

```text
number → 40
```

---

## 🔹 Reference Must Be Initialized-

-A reference must be connected to a variable when it is declared.

-Correct:

```cpp
int number = 10;

int& ref = number;
```

-Incorrect:

```cpp
int& ref;
```

-A reference cannot exist without being initialized.

---

## 🔹 Reference Cannot Be Changed to Refer to Another Variable-

-Once a reference is initialized, it remains an alias for that variable.

-Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int first = 10;
    int second = 20;

    // ref refers to first
    int& ref = first;

    // This changes first, not what ref refers to
    ref = second;

    cout << "First: " << first << endl;
    cout << "Second: " << second << endl;

    return 0;
}
```

### Output-

```text
First: 20
Second: 20
```

-The statement:

```cpp
ref = second;
```

-does **not** make `ref` refer to `second`.

-Instead, it copies the value of `second` into `first`.

-After initialization, `ref` still refers to `first`.

---

## 🔹 Reference with Different Data Types-

-A reference normally has the same data type as the variable it refers to.

```cpp
int number = 10;
int& ref = number;
```

-For a `double`:

```cpp
double price = 99.5;
double& ref = price;
```

-For a `char`:

```cpp
char grade = 'A';
char& ref = grade;
```

---

## 🔹 Reference with `float`-

```cpp
#include <iostream>
using namespace std;

int main() {
    float marks = 85.5f;

    // Create a reference to marks
    float& ref = marks;

    // Modify marks through the reference
    ref = 90.5f;

    cout << "Marks: " << marks << endl;

    return 0;
}
```

### Output-

```text
Marks: 90.5
```

---

## 🔹 Reference Does Not Create a Copy-

-Compare these two examples.

### Normal Variable-

```cpp
int number = 10;

int copy = number;
```

-Here, `copy` is a separate variable.

```text
number → 10

copy   → 10
```

-Changing `copy` does not change `number`.

```cpp
copy = 50;
```

-Now:

```text
number → 10
copy   → 50
```

---

### Reference-

```cpp
int number = 10;

int& ref = number;
```

-Here, `ref` is another name for `number`.

```text
number
   ↑
   |
  ref
```

-Changing `ref` changes `number`.

```cpp
ref = 50;
```

-Now:

```text
number → 50
ref    → 50
```

---

## 🔹 Reference and Memory-

-A reference is an alias for an existing object.

-Example:

```cpp
int number = 100;
int& ref = number;
```

-Both `number` and `ref` refer to the same object.

-We can demonstrate this using addresses:

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 100;

    // ref is an alias for number
    int& ref = number;

    // Print the address of the original variable
    cout << &number << endl;

    // Print the address through the reference
    cout << &ref << endl;

    return 0;
}
```

-The two addresses will be the same.

-This demonstrates that the reference refers to the same object.

---

## 🔹 References with Arrays-

-A reference can also refer to an array.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    // Create a reference to the entire array
    int (&ref)[3] = numbers;

    // Access the array through the reference
    cout << ref[0] << endl;
    cout << ref[1] << endl;
    cout << ref[2] << endl;

    return 0;
}
```

### Output-

```text
10
20
30
```

-The syntax is more complex because the reference refers to the **entire array**, not just one element.

---

## 🔹 Reference with `const`

-A reference can be declared as `const`.

```cpp
const int number = 10;

// Reference cannot modify number
const int& ref = number;
```

-Now:

```cpp
ref = 20;
```

-is not allowed because `ref` is a reference to a constant value.

-Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // const reference can read the value
    // but cannot modify it through the reference
    const int& ref = number;

    cout << ref << endl;

    return 0;
}
```

### Output-

```text
10
```

---

## 🔹 Reference as a Function Parameter-

-References become especially useful with functions.

-A reference parameter allows a function to modify the original variable.

```cpp
#include <iostream>
using namespace std;

// ref is a reference to the original variable
void changeValue(int& ref) {
    // Modify the original variable
    ref = 100;
}

int main() {
    int number = 10;

    // Pass number to the function
    changeValue(number);

    // number was changed by the function
    cout << number << endl;

    return 0;
}
```

### Output-

```text
100
```

-Without a reference, the function would normally receive a copy of the value.

## 📝 Important Points-

* A reference is an **alias** for an existing variable.
  
* A reference is declared using `&`.
  
* A reference must be initialized when declared.
  
* A reference cannot be uninitialized.
  
* A reference cannot be made to refer to another variable after initialization.
  
* Changing a reference changes the original variable.
  
* A reference does not create an independent copy of the value.
  
* References are commonly used with function parameters.
  
* `const` references can read a value without allowing modification through the reference.
  
* The reference and the original variable refer to the same object.
