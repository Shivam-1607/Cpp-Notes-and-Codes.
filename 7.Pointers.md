# 📄34. Pointers Basics-

## 📌 Theory-

-A **pointer** is a variable that stores the **memory address of another variable**.

-Normally, a variable stores a value:

```cpp
int age = 20;
```

-Here:

```text
age → 20
```

-A pointer does not directly store `20`. Instead, it stores the address where `age` is stored in memory.

```text
age       → 20
           ↑
           |
pointer → address of age
```

-Pointers are an important part of C++ because they allow programs to work directly with memory.

---

## 🔹 Declaring a Pointer-

### Syntax

```cpp
dataType* pointerName;
```

-Example:

```cpp
int* ptr;
```

-This declares a pointer that can store the address of an `int` variable.

-Other examples:

```cpp
float* ptr1;
char* ptr2;
double* ptr3;
```

-The pointer type should generally match the type of variable whose address it stores.

---

## 🔹 Address-of Operator `&`-

-The `&` operator is called the **address-of operator**.

-It gives the memory address of a variable.

### Syntax

```cpp
&variableName
```

-Example:

```cpp
int age = 20;

cout << &age;
```

-This prints the memory address where `age` is stored.

-The exact address can be different every time the program runs.

---

## 💻 Example 1 — Getting a Variable's Address-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age = 20;

    // &age gives the memory address of age.
    cout << "Value of age: " << age << endl;

    cout << "Address of age: " << &age << endl;

    return 0;
}
```

### Example Output-

```text
Value of age: 20
Address of age: 0x7ffd1234
```

-The address shown is only an example. The actual address depends on the program's memory layout.

---

## 🔹 Storing an Address in a Pointer-

-We can store the address of a variable inside a pointer.

```cpp
int age = 20;

int* ptr = &age;
```

-Now:

```text
age → 20

ptr → address of age
```

-The pointer `ptr` does not contain the value `20` directly. It contains the address of `age`.

---

## 💻 Example 2 — Basic Pointer-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age = 20;

    // Store the address of age inside ptr.
    int* ptr = &age;

    // Display the value stored in age.
    cout << "Value of age: " << age << endl;

    // Display the address of age.
    cout << "Address of age: " << &age << endl;

    // ptr contains the address of age.
    cout << "Value stored in ptr: " << ptr << endl;

    return 0;
}
```

### Example Output-

```text
Value of age: 20
Address of age: 0x7ffd1234
Value stored in ptr: 0x7ffd1234
```

-Notice:

```text
&age == ptr
```

-Both represent the address of `age`.

---

## 🔹 Dereference Operator `*`-

-The `*` operator has another important use with pointers.

-It is called the **dereference operator** when used with a pointer.

-Dereferencing a pointer means:

> Go to the address stored in the pointer and access the value located there.

Example:

```cpp
int age = 20;
int* ptr = &age;

cout << *ptr;
```

Output:

```text
20
```

-Because `ptr` contains the address of `age`, `*ptr` accesses the value stored at that address.

---

## 💻 Example 3 — Dereferencing a Pointer-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int age = 20;

    // ptr stores the address of age.
    int* ptr = &age;

    // *ptr accesses the value stored at that address.
    cout << "Value using pointer: " << *ptr;

    return 0;
}
```

### Output-

```text
Value using pointer: 20
```

---

## 🔹 Understanding `&` and `*`

-These two operators are extremely important when learning pointers.

```cpp
int age = 20;

int* ptr = &age;
```

-Here:

```text

 ↓

```

-Therefore:

```cpp

```

and:


-refer to the same value.

## 💻 Example 4 — Changing a Variable Using a Pointer-

-A pointer can be used to modify the original variable.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    // ptr stores the address of number.
    int* ptr = &number;

    cout << "Before: " << number << endl;

    // *ptr accesses number.
    // Changing *ptr changes the original variable.
    *ptr = 50;

    cout << "After: " << number << endl;

    return 0;
}
```

### Output-

```text
Before: 10
After: 50
```

-The important relationship is:

```text
ptr
 ↓
address of number
 ↓
number
```

-So when we write:

```cpp
*ptr = 50;
```

-we are effectively changing `number`.

-Pointers can point to different data types.

### Integer Pointer-

```cpp

```

## 💻 Example 5 — Different Pointer Types-


## 🔹 Null Pointer-

-A pointer that does not point to a valid object can be initialized with `nullptr`.

```cpp
int* ptr = nullptr;
```

-`nullptr` means that the pointer currently points to **nothing**.

### Example

```cpp
#include <iostream>
using namespace std;

int main()
{
    // ptr currently does not point to any variable.
    int* ptr = nullptr;

    // Check whether the pointer is null.
    if (ptr == nullptr)
    {
        cout << "Pointer is null";
    }

    return 0;
}
```

### Output

```text
Pointer is null
```

-You should not dereference a null pointer:

```cpp
*ptr = 10; // Wrong
```

-because `ptr` does not point to a valid object.

---

## 🔹 Pointer Declaration vs Dereferencing

-The `*` symbol can be confusing because it has different meanings.

### During declaration-

```cpp
int* ptr;
```

-Here `*` means that `ptr` is a pointer.

### During use

```cpp
*ptr
```

-Here `*` means dereference the pointer and access the value at its stored address.

## 📝 Important Points-

1. A pointer stores a **memory address**.
   
2. `&` is the **address-of operator**.
   
3. `*` is the **dereference operator** when used with a pointer.
   
4. Example:

   ```cpp
   int number = 10;
   int* ptr = &number;
   ```
5. `ptr` contains the address of `number`.
   
6. `*ptr` accesses the value of `number`.
    
7. Changing `*ptr` changes the original variable.
    
8. Pointer types should normally match the data they point to.
    
9. `nullptr` represents a pointer that currently points to nothing.
    
10. Never dereference a null or invalid pointer.
    
11. Memory addresses can differ between program executions.
    
12. Pointers are fundamental for arrays, dynamic memory, functions, and data structures.

## 🎯 Summary


```text

   ↑
   |
 *ptr

```

-The three most important concepts are:

```text

pointer    → Stores the address

```

-Understanding these three concepts is the foundation for learning more advanced pointer operations in C++.

# 📄35. Pointers Dereferencing-

## 📌 Theory-

-**Dereferencing** means accessing the value stored at the memory address held by a pointer.

-The **dereference operator `*`** is used to access or modify the value of the variable pointed to by a pointer.

-For example:

```cpp
int number = 10;
int* ptr = &number;

// ptr stores the address of number
// *ptr accesses the value stored at that address
```

-Here:

* `number` → stores `10`
* `&number` → gives the address of `number`
* `ptr` → stores that address
* `*ptr` → gives the value `10`

---

## 🔹 Dereferencing a Pointer-

### Syntax-

```cpp
*pointerName
```

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // Create a pointer and store the address of number
    int* ptr = &number;

    // *ptr accesses the value stored at the address
    cout << *ptr << endl;

    return 0;
}
```

### Output-

```text
10
```

-The pointer `ptr` contains the address of `number`, and `*ptr` accesses the value stored at that address.

---

## 🔹 Reading a Value Through a Pointer-

-A pointer can be used to read the value of the original variable.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 19;

    // Store the address of age
    int* ptr = &age;

    // Read age using the pointer
    cout << "Age: " << *ptr << endl;

    return 0;
}
```

### Output-

```text
Age: 19
```

-`*ptr` gives us the value stored in `age`.

---

## 🔹 Changing a Value Through a Pointer-

-One of the important uses of dereferencing is that we can **change the original variable through the pointer**.

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // ptr stores the address of number
    int* ptr = &number;

    // Change number through the pointer
    *ptr = 50;

    // number has now changed to 50
    cout << "Number: " << number << endl;

    return 0;
}
```

### Output-

```text
Number: 50
```

### What happened?-

-Initially:

```text
number = 10
```

-Then:

```cpp
*ptr = 50;
```

-means:

> Go to the address stored in `ptr` and put `50` there.

-Since `ptr` points to `number`, the value of `number` becomes `50`.

---

## 🔹 `&` vs `*`-

-The symbols `&` and `*` are very important when working with pointers.

### `&` — Address-of Operator-

-`&` gives the **memory address** of a variable.

```cpp
int number = 10;

cout << &number;
```

- prints the memory address of `number`.

---

### `*` — Dereference Operator

`*` accesses the **value stored at the address**.

```cpp
int number = 10;
int* ptr = &number;

cout << *ptr;
```

-:

```text
10
```

-So:

```text
&number → address of number
ptr     → stores that address
*ptr    → value at that address
```

---

## 🔹 Understanding the Relationship-

-Consider:

```cpp
int number = 25;
int* ptr = &number;
```

-The relationship can be understood as:

```text
number
  |
  | contains 25
  ↓
[ 25 ]

ptr
  |
  | contains address of number
  ↓
[address of number]
       |
       ↓
     [ 25 ]
```

-Therefore:

```cpp
ptr
```

-gives the address stored in the pointer.

-While:

```cpp
*ptr
```

-gives the value stored at that address.

---

## 🔹 Important Difference in `*`-

-The `*` symbol has two common uses with pointers.

-Here, `*` means that `ptr` is a pointer to an integer.

### 2. Dereferencing-

## 📝 Important Points-

* Dereferencing means accessing the value stored at a pointer's address.
  
* The dereference operator is `*`.
  
* `&` is used to obtain an address.

# 📄36. Pointer Arithmetic-

## 📌 Theory-

--**Pointer arithmetic** means performing arithmetic operations on pointers.

-Pointers store memory addresses, so C++ allows us to perform certain operations on them.

-The main pointer arithmetic operations are:

* Increment `++`
  
* Decrement `--`
  
* Addition `+`
  
* Subtraction `-`
  
* Difference between two pointers

-Pointer arithmetic is especially useful when working with **arrays**.

---

## 🔹 Pointer Increment-

-The `++` operator moves a pointer to the **next element** of its data type.

### Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    // ptr stores the address of number
    int* ptr = &number;

    // Move the pointer forward
    ptr++;

    return 0;
}
```

-For an `int*`, `ptr++` does **not simply add 1 byte** to the address.

-It moves the pointer by the size of one `int`.

-For example, if an integer occupies 4 bytes:

```text
Before:
ptr → address 1000

After ptr++:
ptr → address 1004
```

-The exact addresses depend on the system.

---

## 🔹 Pointer Decrement-

-The `--` operator moves the pointer to the previous element.

```cpp
int* ptr;

ptr--;
```

-If an `int` occupies 4 bytes:

```text
Before:
ptr → 1004

After ptr--:
ptr → 1000
```

-Again, the actual addresses depend on the system.

---

## 🔹 Pointer Addition-

-We can add an integer to a pointer.

```cpp
ptr + 2
```

-This moves the pointer forward by **2 elements**, not necessarily 2 bytes.

-For example, if `ptr` is an `int*` and an `int` is 4 bytes:

```text
ptr       → address 1000
ptr + 1   → address 1004
ptr + 2   → address 1008
```

---

## 🔹 Pointer Subtraction-

-We can subtract an integer from a pointer.

```cpp
ptr - 2
```

-This moves the pointer backward by 2 elements.

-Example:

```text
ptr       → 1008
ptr - 1   → 1004
ptr - 2   → 1000
```

---

## 🔹 Pointer Arithmetic with Arrays-

-Pointer arithmetic becomes especially useful with arrays.

-Consider:

```cpp
int numbers[4] = {10, 20, 30, 40};
```

-The elements are stored sequentially in memory.

-Conceptually:

```text
numbers[0] → 10
numbers[1] → 20
numbers[2] → 30
numbers[3] → 40
```

-A pointer can point to the first element:

```cpp
int* ptr = numbers;
```

-Then:

```cpp
*ptr
```

-gives:

```text
10
```

-Moving the pointer:

```cpp
ptr++;
```

-now makes it point to the next element.

```text
*ptr → 20
```

---

## 💻 Example: Traversing an Array Using a Pointer-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // The array name represents the address of its first element
    int* ptr = numbers;

    // Print the first element
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    // Move to the next element
    ptr++;
    cout << *ptr << endl;

    return 0;
}
```

### Output-

```text
10
20
30
40
50
```

---

## 🔹 Pointer Addition with an Array-

-Instead of repeatedly using `ptr++`, we can use pointer arithmetic directly.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element
    int* ptr = numbers;

    // Access different elements using pointer arithmetic
    cout << *(ptr + 0) << endl;
    cout << *(ptr + 1) << endl;
    cout << *(ptr + 2) << endl;
    cout << *(ptr + 3) << endl;
    cout << *(ptr + 4) << endl;

    return 0;
}
```

### Output-

```text
10
20
30
40
50
```

-The expressions work like this:

```text
*(ptr + 0) → numbers[0]
*(ptr + 1) → numbers[1]
*(ptr + 2) → numbers[2]
*(ptr + 3) → numbers[3]
*(ptr + 4) → numbers[4]
```

---

## 🔹 Pointer Arithmetic Does Not Always Move One Byte-

-This is an important concept.

-Suppose:

```cpp
int* ptr;
```

-If an `int` occupies 4 bytes, then:

```cpp
ptr + 1
```

-moves by 4 bytes.

-If:

```cpp
double* ptr;
```

-and a `double` occupies 8 bytes, then:

```cpp
ptr + 1
```

-moves by 8 bytes.

-Therefore:

> Pointer arithmetic moves according to the size of the pointer's data type.

---

## 🔹 Pointer Arithmetic with Different Data Types-

### Integer Pointer-

```cpp
int* ptr;
ptr++;
```

-Moves by the size of an `int`.

### Character Pointer-

```cpp
char* ptr;
ptr++;
```

-Moves by the size of a `char`, which is 1 byte.

### Double Pointer-

```cpp
double* ptr;
ptr++;
```

-Moves by the size of a `double`.

---

## 🔹 Subtracting Two Pointers-

-Two pointers pointing into the **same array** can be subtracted.

-The result tells us how many elements are between them.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element
    int* ptr1 = &numbers[0];

    // Point to the fourth element
    int* ptr2 = &numbers[3];

    // Find the number of elements between the pointers
    cout << ptr2 - ptr1 << endl;

    return 0;
}
```

### Output-

```text
3
```

-Why?

```text
numbers[0] → ptr1
numbers[1]
numbers[2]
numbers[3] → ptr2
```

-There are 3 element positions between them.

---

## 🔹 Pointer Comparison-

-Pointers can also be compared.

-For example:

```cpp
ptr1 < ptr2
ptr1 > ptr2
ptr1 == ptr2
ptr1 != ptr2
```

-Example:

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[3] = {10, 20, 30};

    int* ptr1 = &numbers[0];
    int* ptr2 = &numbers[2];

    // Check whether ptr1 and ptr2 point to the same location
    if (ptr1 == ptr2) {
        cout << "Same address";
    } else {
        cout << "Different addresses";
    }

    return 0;
}
```

### Output-

```text
Different addresses
```

---

## 🔹 Complete Example-

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    // Point to the first element of the array
    int* ptr = numbers;

    // Print the current value
    cout << "Current value: " << *ptr << endl;

    // Move one element forward
    ptr++;

    cout << "After ptr++: " << *ptr << endl;

    // Move another two elements forward
    ptr = ptr + 2;

    cout << "After ptr + 2: " << *ptr << endl;

    // Move one element backward
    ptr--;

    cout << "After ptr--: " << *ptr << endl;

    return 0;
}
```

### Output-

```text
Current value: 10
After ptr++: 20
After ptr + 2: 40
After ptr--: 30
```

---

## 📝 Important Points-

* Pointer arithmetic operates on memory addresses.
  
* `ptr++` moves to the next element.
  
* `ptr--` moves to the previous element.
  
* `ptr + n` moves forward by `n` elements.
  
* `ptr - n` moves backward by `n` elements.
  
* Pointer movement depends on the size of its data type.
  
* Pointer arithmetic is commonly used with arrays.
  
* Two pointers can be subtracted when they point into the same array.
  
* The result of subtracting two pointers represents the number of elements between them.
  
* Pointer arithmetic should only be used within a valid memory range.

## 🎯 Summary-

```text
ptr++       → next element
ptr--       → previous element
ptr + n     → n elements forward
ptr - n     → n elements backward
ptr2 - ptr1 → number of elements between pointers
```

-For arrays:

```cpp
int* ptr = numbers;
```

-then:

```cpp
*(ptr + 0) → first element
*(ptr + 1) → second element
*(ptr + 2) → third element
```

-Pointer arithmetic is the foundation for understanding how **pointers and arrays work together** in C++.
