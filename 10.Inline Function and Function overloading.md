# 📄55. Inline Functions in C++-

## What is an Inline Function?-

-An **inline function** is a function declared using the `inline` keyword, suggesting to the compiler that it may replace a function call with the actual function code.

-This process is called **function inlining**.

-It can reduce function-call overhead for small, frequently called functions, although the compiler decides whether to perform the optimization.

-For example, a small function that calculates the square of a number may be declared as an inline function.

## Characteristics of an Inline Function-

* The `inline` keyword is used when declaring or defining an inline function.
* Inline functions can reduce function-call overhead when the compiler performs inlining.
* They are generally suitable for small functions that are called frequently.
* The compiler is **not required** to inline a function just because it is declared with `inline`.
* A function defined inside a class definition is implicitly inline, subject to the language's rules.
* Inline functions can have parameters and return values like ordinary functions.
* Inline functions follow the same rules for return types, arguments, and scope as ordinary functions.
* The `inline` keyword also permits a function with the same definition to appear in multiple translation units, provided the One Definition Rule is satisfied.
* Making a function inline does not guarantee that the program will run faster. Excessive inlining can increase code size.

## Basic Syntax-

```cpp
inline returnType functionName(parameters) {
    // Function body
}
```

**Explanation-**

1. `inline` indicates that the function is an inline function.
2. `returnType` specifies the type of value returned by the function.
3. `functionName` is the name of the function.
4. `parameters` are the values received by the function.
5. The function body contains the statements to be executed.

## 1. Simple Example of an Inline Function-

```cpp
#include <iostream>
using namespace std;

// Inline function
inline void display() {
    cout << "Hello from an inline function!" << endl;
}

int main() {
    display();

    return 0;
}
```

### Output-

```text
Hello from an inline function!
```

### Explanation-

1. The `display()` function is declared using the `inline` keyword.
2. It prints a message to the screen.
3. The function is called from `main()`.
4. The program produces the expected output whether the compiler inlines the function or executes it as a normal function call.

## 2. Inline Function with Parameters-

An inline function can accept parameters and perform calculations.

```cpp
#include <iostream>
using namespace std;

// Inline function with parameters
inline int square(int n) {
    return n * n;
}

int main() {
    cout << "Square of 5: " << square(5) << endl;
    cout << "Square of 8: " << square(8) << endl;

    return 0;
}
```

### Output-

```text
Square of 5: 25
Square of 8: 64
```

### Explanation-

1. The `square()` function accepts an integer parameter `n`.
2. It returns the product of `n` multiplied by itself.
3. The function is called with arguments `5` and `8`.
4. The returned values are displayed.
5. Since the function is small, it may be a good candidate for inlining.

## 3. Inline Function with a Return Value-

An inline function can return a value to the calling function.

```cpp
#include <iostream>
using namespace std;

// Inline function to find the greater number
inline int maximum(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

int main() {
    int result = maximum(10, 20);

    cout << "Greater number: " << result << endl;

    return 0;
}
```

### Output-

```text
Greater number: 20
```

### Explanation-

1. The `maximum()` function accepts two integer parameters.
2. It compares the two values.
3. It returns the greater value.
4. The returned value is stored in the variable `result`.
5. The result is displayed on the screen.

## 4. Inline Function Defined Inside a Class-

A member function defined inside a class definition is implicitly inline, so the `inline` keyword is not required.

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    // Defined inside the class: implicitly inline
    int add(int a, int b) {
        return a + b;
    }
};

int main() {
    Calculator c;

    cout << "Sum: " << c.add(10, 20) << endl;

    return 0;
}
```

### Output-

```text
Sum: 30
```

### Explanation-

1. The `Calculator` class contains the member function `add()`.
2. The function is defined inside the class definition.
3. Therefore, it is implicitly inline under C++ language rules.
4. The function adds two numbers and returns their sum.
5. The result is displayed in `main()`.

**Important:** Being implicitly inline is a language property. It does not guarantee that the compiler will replace the function call with the function's code.

## 5. Inline Function Defined Outside a Class-

A member function can be declared inside a class and defined outside it using the scope resolution operator.

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int multiply(int a, int b);
};

// Defining the function outside the class
inline int Calculator::multiply(int a, int b) {
    return a * b;
}

int main() {
    Calculator c;

    cout << "Product: " << c.multiply(4, 5) << endl;

    return 0;
}
```

### Output-

```text
Product: 20
```

### Explanation-

1. The `multiply()` function is declared inside the `Calculator` class.
2. It is defined outside the class using `Calculator::multiply()`.
3. The `inline` keyword is specified in the definition.
4. The function multiplies two numbers and returns the result.
5. The product is displayed in `main()`.

## Advantages of Inline Functions-

* **Reduced function-call overhead:** Inlining may avoid some overhead associated with a normal function call.
* **Useful for small functions:** Short functions that are called frequently may benefit from inlining.
* **Improved optimization opportunities:** The compiler may optimize the surrounding code more effectively.
* **Class compatibility:** Small member functions can be defined inside a class and are implicitly inline.

## Disadvantages of Inline Functions-

* **Increased code size:** Replacing many function calls with repeated function bodies may increase the size of the executable.
* **No guarantee of inlining:** The compiler may choose not to inline a function.
* **Limited benefit for large functions:** Large functions may not be suitable for inlining.
* **Not always faster:** Excessive inlining can negatively affect performance, such as instruction-cache usage.

## Difference Between Normal Function and Inline Function-

| Normal Function | Inline Function |
|---|---|
| Declared without requiring the `inline` keyword. | Can be declared using the `inline` keyword. |
| The compiler may generate a normal function call. | The compiler may replace a call with the function's code. |
| Function-call overhead may occur. | Inlining may reduce function-call overhead. |
| Suitable for functions of any size. | Often considered for small, frequently called functions. |
| The compiler may optimize it in various ways. | The compiler still decides whether inlining is beneficial. |

## Important Points-

* The `inline` keyword does not force the compiler to inline a function.
* Inlining is an optimization decision made by the compiler.
* Functions defined inside a class definition are implicitly inline.
* A function defined outside a class can also be declared inline.
* Inline functions can accept parameters and return values.
* Inline functions are often useful for small, frequently called functions.
* Avoid assuming that inline functions always improve performance.
* The `inline` keyword has an additional purpose in allowing compliant identical function definitions across multiple translation units.

## Summary-

An inline function is a function declared with the `inline` keyword or one that is implicitly inline under the language rules. It allows the compiler to consider replacing a function call with the function's code, potentially reducing function-call overhead. However, the compiler decides whether to perform this optimization, and inlining does not always improve performance.

# 📄56. Function Overloading in C++-

## What is Function Overloading?-

-**Function overloading** is a feature of C++ that allows multiple functions to have the same name but different parameter lists.

-These functions can differ in the number of parameters, the types of parameters, or the order of parameter types.

-The compiler determines which overloaded function to call based on the arguments supplied.

-Function overloading is an example of **compile-time polymorphism** in C++.

-For example, we can create multiple functions named `add()` to add two integers, two floating-point numbers, or three integers.

## Characteristics of Function Overloading-

* Multiple functions can have the same name in the same scope.
* The functions must have different parameter lists.
* Functions can differ by the number of parameters.
* Functions can differ by the types of parameters.
* Functions can differ by the order of parameter types.
* The compiler selects the appropriate overload based on the arguments and overload resolution rules.
* Function overloading supports compile-time polymorphism.
* Functions cannot be overloaded by changing only their return type.
* Default arguments and implicit type conversions can sometimes make overloaded calls ambiguous.

## Basic Syntax-

```cpp
returnType functionName(int a) {
    // Function body
}

returnType functionName(int a, int b) {
    // Function body
}

returnType functionName(double a, double b) {
    // Function body
}
```

**Explanation-**

1. All three functions have the same name: `functionName`.
2. The first function accepts one integer.
3. The second function accepts two integers.
4. The third function accepts two floating-point values.
5. Their parameter lists differ, so they can be overloaded.

## 1. Function Overloading Based on the Number of Parameters-

Functions can have the same name but accept different numbers of parameters.

```cpp
#include <iostream>
using namespace std;

// Function with two parameters
int add(int a, int b) {
    return a + b;
}

// Function with three parameters
int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    cout << "Sum of two numbers: " << add(10, 20) << endl;
    cout << "Sum of three numbers: " << add(10, 20, 30) << endl;

    return 0;
}
```

### Output-

```text
Sum of two numbers: 30
Sum of three numbers: 60
```

### Explanation-

1. The first `add()` function accepts two integers.
2. The second `add()` function accepts three integers.
3. When `add(10, 20)` is called, the compiler selects the two-parameter function.
4. When `add(10, 20, 30)` is called, the compiler selects the three-parameter function.
5. Both functions have the same name but different parameter counts.

## 2. Function Overloading Based on Parameter Types-

Functions can also be overloaded by using different parameter types.

```cpp
#include <iostream>
using namespace std;

// Function for integers
int display(int a) {
    return a;
}

// Function for floating-point numbers
double display(double a) {
    return a;
}

int main() {
    cout << "Integer value: " << display(10) << endl;
    cout << "Double value: " << display(5.5) << endl;

    return 0;
}
```

### Output-

```text
Integer value: 10
Double value: 5.5
```

### Explanation-

1. The first `display()` function accepts an `int`.
2. The second `display()` function accepts a `double`.
3. The call `display(10)` selects the integer version.
4. The call `display(5.5)` selects the double version.
5. The compiler selects the overload that provides the best match for the argument.

## 3. Function Overloading Based on the Order of Parameters-

Functions can be overloaded by changing the order of different parameter types.

```cpp
#include <iostream>
using namespace std;

// First function: integer followed by double
void show(int a, double b) {
    cout << "Integer: " << a << ", Double: " << b << endl;
}

// Second function: double followed by integer
void show(double a, int b) {
    cout << "Double: " << a << ", Integer: " << b << endl;
}

int main() {
    show(10, 5.5);
    show(3.5, 20);

    return 0;
}
```

### Output-

```text
Integer: 10, Double: 5.5
Double: 3.5, Integer: 20
```

### Explanation-

1. The first `show()` function accepts an `int` followed by a `double`.
2. The second `show()` function accepts a `double` followed by an `int`.
3. The order of parameter types differs.
4. The compiler selects the appropriate function based on the argument types.
5. This is another valid form of function overloading.

## 4. Function Overloading with Different Return Types?-

**Functions cannot be overloaded by changing only their return type.**

The following example is invalid C++:

```cpp
#include <iostream>
using namespace std;

int calculate(int a) {
    return a;
}

// Error: differs only in return type
double calculate(int a) {
    return a * 2.5;
}

int main() {
    cout << calculate(10) << endl;
    return 0;
}
```

### Output-

```text
Compilation Error
```

### Explanation-

1. Both functions have the same name, `calculate`.
2. Both accept exactly one `int` parameter.
3. Their only difference is the return type.
4. The compiler cannot select between them based only on the expected return type.
5. Therefore, this program is ill-formed and will not compile.

**Correct approach:** Change the parameter list or use a different function name.

## 5. Function Overloading with Class Member Functions-

Member functions of a class can also be overloaded.

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    int multiply(int a, int b) {
        return a * b;
    }

    int multiply(int a, int b, int c) {
        return a * b * c;
    }
};

int main() {
    Calculator c;

    cout << "Product of two numbers: " << c.multiply(4, 5) << endl;
    cout << "Product of three numbers: " << c.multiply(2, 3, 4) << endl;

    return 0;
}
```

### Output-

```text
Product of two numbers: 20
Product of three numbers: 24
```

### Explanation-

1. The `Calculator` class contains two member functions named `multiply()`.
2. The first accepts two integers.
3. The second accepts three integers.
4. The number of arguments determines which overload is selected in these calls.
5. Function overloading works with both ordinary functions and class member functions.

## Advantages of Function Overloading-

* **Improved readability:** Related operations can use the same function name.
* **Code reusability:** Similar operations can be implemented using different parameter lists.
* **Compile-time polymorphism:** The compiler selects the appropriate function during compilation.
* **Convenience:** Programmers do not need separate names such as `addTwo()` and `addThree()` for closely related operations.

## Difference Between Function Overloading and Function Overriding-

| Function Overloading | Function Overriding |
|---|---|
| Functions have the same name but different parameter lists. | A derived class provides a new implementation of an inherited virtual function with a matching signature. |
| Commonly occurs within the same scope, though overloads can also be introduced across class scopes. | Requires inheritance. |
| Supports compile-time polymorphism. | Supports runtime polymorphism when a virtual function is called through an appropriate base-class reference or pointer. |
| The functions may differ in parameter count, types, or order. | The overriding function must match the virtual function's signature, subject to C++ rules. |
| Does not require inheritance. | Requires a base-class and derived-class relationship. |

## Important Points-

* Function overloading means using the same function name with different parameter lists.
* The number, types, or order of parameters can differ.
* Changing only the return type does not create a valid overload.
* The compiler resolves overloaded calls based on the arguments and applicable overload resolution rules.
* Function overloading is a form of compile-time polymorphism.
* Both ordinary functions and class member functions can be overloaded.
* Ambiguous calls can occur when multiple overloads are equally suitable.
* Constructors can also be overloaded, allowing objects to be initialized in different ways.

## Summary-

Function overloading allows multiple functions to share the same name while having different parameter lists. It improves code readability and supports compile-time polymorphism. The compiler selects the appropriate overload based on the arguments and C++ overload resolution rules. However, functions cannot be overloaded by changing only their return type.
