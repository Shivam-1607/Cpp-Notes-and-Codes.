# 📄40. Structures Basics-

## 📌 Theory-

-A **structure (`struct`)** in C++ is a user-defined data type that allows us to group multiple related variables of **different data types** under one name.

-For example, information about a student may contain:

* Name → `string`
  
* Age → `int`
  
* CGPA → `float`

-Instead of creating separate unrelated variables:

```cpp
string name;
int age;
float cgpa;
```

-we can group them inside a structure:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-A structure acts like a blueprint for creating objects containing related data.

---

## 🔹 Structure Syntax-

-The basic syntax is:

```cpp
struct StructureName {
    dataType member1;
    dataType member2;
    dataType member3;
};
```

-For example:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-Here:

* `Student` → structure name
  
* `name` → structure member
  
* `age` → structure member
  
* `cgpa` → structure member

-The semicolon after the closing `}` is required.

---

## 🔹 Creating a Structure Variable-

-Defining a structure does not automatically create a variable.

-After defining:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-we can create a variable:

```cpp
Student student1;
```

-Here:

```text
Student → data type
student1 → variable
```

---

## 🔹 Accessing Structure Members-

-The **dot operator `.`** is used to access structure members.

```cpp
student1.name
student1.age
student1.cgpa
```

### Example-

```cpp
#include <iostream>
using namespace std;

// Define a structure
struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    // Create a structure variable
    Student student1;

    // Assign values to the structure members
    student1.name = "Rahul";
    student1.age = 19;
    student1.cgpa = 9.3;

    // Access and print the members
    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "CGPA: " << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3
```

## 🔹 Structure with Different Data Types-

-One of the biggest advantages of structures is that they can contain different data types.

```cpp
struct Student {
    string name;
    int rollNumber;
    float marks;
    char grade;
    bool passed;
};
```

-A single `Student` object can now contain all of this information.

---

## 🔹 Initializing a Structure-

-A structure can be initialized when the variable is created.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    // Initialize the structure directly
    Student student1 = {"Rahul", 19, 9.3};

    // Display the values
    cout << student1.name << endl;
    cout << student1.age << endl;
    cout << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Rahul
19
9.3
```

-The values are assigned according to the order of the members:

```text
name → "Rahul"
age  → 19
cgpa → 9.3
```

## 🔹 Multiple Structure Variables-

-We can create multiple variables from the same structure.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    // Create two Student objects
    Student student1 = {"Rahul", 19, 9.3};
    Student student2 = {"Aman", 20, 8.7};

    // Display student1
    cout << student1.name << " " << student1.cgpa << endl;

    // Display student2
    cout << student2.name << " " << student2.cgpa << endl;

    return 0;
}
```

### Output-

```text
Rahul 9.3
Aman 8.7
```

-Both variables use the same structure definition but store different data.

## 🔹 Taking Input in a Structure-

-We can take user input directly into structure members.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    Student student1;

    // Take input for each member
    cout << "Enter name: ";
    cin >> student1.name;

    cout << "Enter age: ";
    cin >> student1.age;

    cout << "Enter CGPA: ";
    cin >> student1.cgpa;

    // Display the entered information
    cout << "\nStudent Details:" << endl;
    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "CGPA: " << student1.cgpa << endl;

    return 0;
}
```

### Example Input-

```text
Enter name: Rahul
Enter age: 19
Enter CGPA: 9.3
```

### Output-

```text
Student Details:
Name: Rahul
Age: 19
CGPA: 9.3
```

## 🔹 Changing Structure Members-

-Structure members can be modified after the object is created.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

int main() {
    Student student1 = {"Rahul", 19};

    // Change the age
    student1.age = 20;

    // Change the name
    student1.name = "Aman";

    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;

    return 0;
}
```

### Output-

```text
Name: Aman
Age: 20
```

## 🔹 Structure with an Array-

-We can create an array of structures.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

int main() {
    // Create an array containing 3 Student objects
    Student students[3];

    // Assign values
    students[0].name = "Rahul";
    students[0].age = 19;

    students[1].name = "Aman";
    students[1].age = 20;

    students[2].name = "Rohit";
    students[2].age = 18;

    // Display all students
    for (int i = 0; i < 3; i++) {
        cout << "Name: " << students[i].name << endl;
        cout << "Age: " << students[i].age << endl;
        cout << endl;
    }

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19

Name: Aman
Age: 20

Name: Rohit
Age: 18
```

-The syntax:

```cpp
students[i].name
```

-means:

```text
students[i] → select one Student object
.name       → access its name
```

## 🔹 Structure Inside a Structure-

-A structure can contain another structure as a member.

```cpp
#include <iostream>
using namespace std;

struct Address {
    string city;
    int pinCode;
};

struct Student {
    string name;
    int age;
    Address address;
};

int main() {
    Student student1;

    student1.name = "Rahul";
    student1.age = 19;

    // Access members of the nested Address structure
    student1.address.city = "Pune";
    student1.address.pinCode = 411014;

    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "City: " << student1.address.city << endl;
    cout << "PIN Code: " << student1.address.pinCode << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
City: Pune
PIN Code: 411014
```

## 🔹 Structure and Functions-

-A structure variable can be passed to a function.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

// Function receives a Student structure
void displayStudent(Student student) {
    cout << "Name: " << student.name << endl;
    cout << "Age: " << student.age << endl;
}

int main() {
    Student student1 = {"Rahul", 19};

    // Pass the structure to the function
    displayStudent(student1);

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
```

-A more detailed use of structures with functions will be covered in the next topic.

## 🔹 Structure vs Normal Variables-

-Without a structure:

```cpp
string student1Name;
int student1Age;
float student1CGPA;
```

-For another student:

```cpp
string student2Name;
int student2Age;
float student2CGPA;
```

-This becomes difficult to manage as the number of students increases.

-With a structure:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-we can simply create:

```cpp
Student student1;
Student student2;
Student student3;
```

-This keeps related information organized.

---

## 📝 Important Points-

* A structure is a **user-defined data type**.
  
* Structures group related variables together.
  
* Structure members can have different data types.
  
* A structure is defined using the `struct` keyword.
  
* The dot operator `.` is used to access members.
  
* A structure definition ends with a semicolon.
  
* Multiple objects can be created from the same structure.
  
* Structures can contain arrays, functions-related data, and other structures.
  
* Arrays of structures can be created.
  
* Structures can be passed to functions.
  
* Structures are useful for organizing related data.
