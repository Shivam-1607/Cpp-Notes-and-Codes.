# 📄40. Structures Basics-

## 📌 Theory-

-A **structure (`struct`)** in C++ is a user-defined data type that allows us to group multiple related variables of **different data types** under one name.

-For example, information about a student may contain:

* Name → `string`
  
* Age → `int`
  
* CGPA → `float`

-Instead of creating separate unrelated variables:

```cpp
string name;
int age;
float cgpa;
```

-we can group them inside a structure:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-A structure acts like a blueprint for creating objects containing related data.

---

## 🔹 Structure Syntax-

-The basic syntax is:

```cpp
struct StructureName {
    dataType member1;
    dataType member2;
    dataType member3;
};
```

-For example:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-Here:

* `Student` → structure name
  
* `name` → structure member
  
* `age` → structure member
  
* `cgpa` → structure member

-The semicolon after the closing `}` is required.

---

## 🔹 Creating a Structure Variable-

-Defining a structure does not automatically create a variable.

-After defining:

```cpp
struct Student {
    string name;
    int age;
    float cgpa;
};
```

-we can create a variable:

```cpp
Student student1;
```

-Here:

```text
Student → data type
student1 → variable
```

---

## 🔹 Accessing Structure Members-

-The **dot operator `.`** is used to access structure members.

```cpp
student1.name
student1.age
student1.cgpa
```

### Example-

```cpp
#include <iostream>
using namespace std;

// Define a structure
struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    // Create a structure variable
    Student student1;

    // Assign values to the structure members
    student1.name = "Rahul";
    student1.age = 19;
    student1.cgpa = 9.3;

    // Access and print the members
    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "CGPA: " << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3
```

## 🔹 Structure with Different Data Types-

-One of the biggest advantages of structures is that they can contain different data types.

```cpp
struct Student {
    string name;
    int rollNumber;
    float marks;
    char grade;
    bool passed;
};
```

-A single `Student` object can now contain all of this information.

## 🔹 Initializing a Structure-

-A structure can be initialized when the variable is created.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

int main() {
    // Initialize the structure directly
    Student student1 = {"Rahul", 19, 9.3};

    // Display the values
    cout << student1.name << endl;
    cout << student1.age << endl;
    cout << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Rahul
19
9.3
```

-The values are assigned according to the order of the members:

```text
name → "Rahul"
age  → 19
cgpa → 9.3
```

## 🔹 Multiple Structure Variables-

-We can create multiple variables from the same structure.

```cpp

```

### Output-

```text
Rahul 9.3
Aman 8.7
```

-Both variables use the same structure definition but store different data.

## 🔹 Structure with an Array-

-We can create an array of structures.

```cpp

```

### Output-

```text
Name: Rohit
```



## 🔹 Structure Inside a Structure-

-A structure can contain another structure as a member.

```cpp
#include <iostream>
using namespace std;

struct Address {
    string city;
    int pinCode;
};

    string name;
    int age;
    Address address;
};

int main() {
    Student student1;

    student1.name = "Rahul";
    student1.age = 19;

    // Access members of the nested Address structure

    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "City: " << student1.address.city << endl;
    cout << "PIN Code: " << student1.address.pinCode << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
City: Pune
PIN Code: 411014
```

## 📝 Important Points-

* A structure is a **user-defined data type**.

* Structure members can have different data types.

# 📄41.Structures with Functions-

## 📌 Theory-

-A structure can be used together with functions.

-We can pass a structure to a function just like we pass normal variables.

-There are three common ways to use structures with functions:

1. Pass structure **by value**
   
2. Pass structure **by reference**
   
3. Pass structure **by pointer**

-The method we choose determines whether the function works with a copy or with the original structure.

---

## 🔹 Passing a Structure by Value-

-When a structure is passed **by value**, the function receives a **copy** of the structure.

### Example-

```cpp
#include <iostream>
using namespace std;

// Define a structure
struct Student {
    string name;
    int age;
    float cgpa;
};

// Function receives a copy of the Student object
void displayStudent(Student student) {
    // Access the copied structure's members
    cout << "Name: " << student.name << endl;
    cout << "Age: " << student.age << endl;
    cout << "CGPA: " << student.cgpa << endl;
}

int main() {
    // Create and initialize a Student object
    Student student1 = {"Rahul", 19, 9.3};

    // Pass the structure to the function
    displayStudent(student1);

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3
```

-The function receives a copy of `student1`.

---

## 🔹 Modifying a Structure Passed by Value-

-Because the function receives a copy, changing the parameter does **not** change the original structure.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

// student is a copy of the original object
void changeAge(Student student) {
    // Change only the copy
    student.age = 25;
}

int main() {
    Student student1 = {"Rahul", 19};

    // Pass student1 by value
    changeAge(student1);

    // Original age remains unchanged
    cout << "Age: " << student1.age << endl;

    return 0;
}
```

### Output-

```text
Age: 19
```

-Why?

```text
Original:
student1.age → 19

Function copy:
student.age → 19
```

-Changing the copy:

```text
student.age → 25
```

-does not change:

```text
student1.age → 19
```

---

## 🔹 Passing a Structure by Reference-

-A structure can be passed by reference using `&`.

### Syntax-

```cpp
void functionName(StructureName& object) {
    // Code
}
```

-The function then works directly with the original structure.

### Example-

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

// student is a reference to the original structure
void changeAge(Student& student) {
    // Modify the original structure
    student.age = 25;
}

int main() {
    Student student1 = {"Rahul", 19};

    // Pass the original structure by reference
    changeAge(student1);

    // The original structure was modified
    cout << "Age: " << student1.age << endl;

    return 0;
}
```

### Output-

```text
Age: 25
```

---

## 🔹 Why Use Reference with Structures?-

-Large structures can contain many members.

-Passing by value creates a copy, which can require additional memory and time.

-Passing by reference allows the function to work with the original structure without creating a complete copy.

-For example:

```cpp
void displayStudent(const Student& student) {
    cout << student.name;
}
```

-The `const` prevents the function from modifying the structure.

---

## 🔹 `const` Reference with Structures-

-If a function only needs to **read** a structure, using a `const` reference is often useful.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

// const prevents the function from modifying student
void displayStudent(const Student& student) {
    cout << "Name: " << student.name << endl;
    cout << "Age: " << student.age << endl;
    cout << "CGPA: " << student.cgpa << endl;
}

int main() {
    Student student1 = {"Rahul", 19, 9.3};

    // Pass the structure by const reference
    displayStudent(student1);

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3
```

-Inside the function, this would not be allowed:

```cpp
student.age = 25;
```

-because `student` is a `const` reference.

---

## 🔹 Passing a Structure by Pointer-

-A structure can also be passed to a function using a pointer.

### Syntax-

```cpp
void functionName(StructureName* pointer) {
    // Code
}
```

### Example-

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

// studentPtr stores the address of a Student object
void changeAge(Student* studentPtr) {
    // Use -> to access a member through a pointer
    studentPtr->age = 25;
}

int main() {
    Student student1 = {"Rahul", 19};

    // Pass the address of student1
    changeAge(&student1);

    // The original structure was modified
    cout << "Age: " << student1.age << endl;

    return 0;
}
```

### Output-

```text
Age: 25
```

---

## 🔹 The Arrow Operator `->`-

-When we have a pointer to a structure, we use the **arrow operator `->`** to access its members.

-For example:

```cpp
Student* ptr = &student1;
```

-We can access `age` using:

```cpp
ptr->age
```

-This is equivalent to:

```cpp
(*ptr).age
```

### Example-

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
};

int main() {
    Student student1 = {"Rahul", 19};

    // Store the address of student1
    Student* ptr = &student1;

    // Access age using the arrow operator
    cout << ptr->age << endl;

    // Access name using the arrow operator
    cout << ptr->name << endl;

    return 0;
}
```

### Output-

```text
19
Rahul
```

---

## 🔹 `.` vs `->`-

-This is very important.

### Normal Structure Object-

-Use the **dot operator `.`**:

```cpp
student1.age
```

### Pointer to Structure-

-Use the **arrow operator `->`**:

```cpp
ptr->age
```

-Example:

```cpp
Student student1 = {"Rahul", 19};

Student* ptr = &student1;

// Object
cout << student1.age;

// Pointer
cout << ptr->age;
```

-Both access the same `age`.

---

## 🔹 `->` and `(*ptr).member`-

-These two expressions are equivalent:

```cpp
ptr->age
```

-and:

```cpp
(*ptr).age
```

-Why?

-First:

```cpp
*ptr
```

-dereferences the pointer and gives the structure object.

-Then:

```cpp
(*ptr).age
```

-accesses the `age` member.

-The arrow operator provides a shorter way:

```cpp
ptr->age
```

```text
CGPA: 9.3
```

## 🔹 Function That Modifies a Structure-

-A reference can be used when the function needs to modify the original structure.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

    // Change the existing values
    student.age = 20;
    student.cgpa = 9.5;
}

int main() {
    Student student1 = {"Rahul", 19, 9.3};

    // Modify student1 through the function
    updateStudent(student1);

    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "CGPA: " << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 20
CGPA: 9.5
```

## 🔹 Returning a Structure from a Function-

-A function can also return a complete structure.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

// Function creates and returns a Student structure
Student createStudent() {
    Student student;

    // Assign values
    student.name = "Rahul";

    student.cgpa = 9.3;

    // Return the complete structure
    return student;

int main() {
    // Store the returned structure
    Student student1 = createStudent();

    cout << "Name: " << student1.name << endl;
    cout << "Age: " << student1.age << endl;
    cout << "CGPA: " << student1.cgpa << endl;

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3
```

## 🔹 Structure with Multiple Functions-

-Multiple functions can work with the same structure.

```cpp
#include <iostream>
using namespace std;

struct Student {
    string name;
    int age;
    float cgpa;
};

// Display student information
void displayStudent(const Student& student) {
    cout << "Name: " << student.name << endl;
    cout << "Age: " << student.age << endl;
    cout << "CGPA: " << student.cgpa << endl;

// Update student information
void updateCGPA(Student& student) {
    student.cgpa = 9.8;

    Student student1 = {"Rahul", 19, 9.3};

    // Display original information
    displayStudent(student1);

    // Update the original structure

    // Display updated information
    displayStudent(student1);

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
CGPA: 9.3

After updating CGPA:
Name: Rahul
Age: 19
CGPA: 9.8
```

## 🔹 Comparison of the Three Methods-

-Suppose we have:

```cpp
struct Student {
    string name;
    int age;
};
```

### Pass by Value

```cpp
void function(Student student)
```

* Creates a copy.
  
* Changes affect only the copy.
  
* Original structure remains unchanged.

### Pass by Reference-

```cpp
void function(Student& student)
```

* No complete copy is created.
  
* Function works with the original structure.
  
* Changes affect the original.

### Pass by Pointer-

```cpp
void function(Student* student)
```

* Function receives the address of the structure.
  
* Access members using `->`.
  
* Can represent a null pointer.

---

## 📝 Important Points-

* Structures can be passed to functions.
  
* Passing by value creates a copy.
  
* Passing by reference works directly with the original structure.
  
* Passing by pointer passes the structure's address.
  
* Use `.` with a normal structure object.
  
* Use `->` with a pointer to a structure.
  
* `ptr->member` is equivalent to `(*ptr).member`.
  
* `const Student&` is useful when a function only needs to read a structure.
  
* A function can return a complete structure.
  
* Multiple functions can work with the same structure.

## 🎯 Summary-

### By Value-

```cpp
void display(Student student)
```

```text
Structure → copy → function
```

-Changes do not affect the original.

### By Reference-

```cpp
void update(Student& student)
```

```text
Structure → function
```

-Changes affect the original.

### By Pointer-

```cpp
void update(Student* student)
```

```text
Structure → address → pointer → function
```

-Access members using:

```cpp
student->age
```

### Most Important Rule-

```text
Object      → .
Pointer     → ->
Reference   → .
```

-For example:

```cpp
student.age
ptr->age
ref.age
```

-All three can access the `age` member, but the syntax depends on whether you are using an object, pointer, or reference.
