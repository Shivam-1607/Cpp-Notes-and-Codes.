# 📄31. Strings Basics-

## 📌 Theory-

-A **string** is a sequence of characters used to store text.

-Examples:

```text
"Hello"
"Aditya"
"Hello World"
"C++ Programming"
```

-In C++, strings can be handled mainly in two ways:

1. **C-style strings** → Character arrays
   
2. **`std::string`** → String class provided by the C++ Standard Library

-For modern C++ programming, `std::string` is generally easier and safer to use.

---

## 🔹 Including the String Library-

-To use `std::string`, include:

```cpp
#include <string>
```

-Because `string` belongs to the `std` namespace, we can write:

```cpp
std::string
```

-or use:

```cpp
using namespace std;
```

-and then simply write:

```cpp
string
```

---

## 🔹 Declaring a String-

### Syntax-

```cpp
string variableName;
```

-Example:

```cpp
string name;
```

-This creates a string variable named `name`.

---

## 🔹 Initializing a String-

-A string can be initialized when it is declared.

```cpp
string name = "Aditya";
```

-Another example:

```cpp
string message = "Hello World";
```

---

## 💻 Example 1 — Basic String-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    // Create a string variable and store text in it.
    string name = "Aditya";

    // Display the string.
    cout << "Name: " << name;

    return 0;
}
```

### Output

```text
Name: Aditya
```

---

## 🔹 Taking String Input-

-The `cin` operator can be used to take a single word as input.

```cpp
cin >> name;
```

-However, `cin` stops reading when it encounters a **space**.

-For example, if the user enters:

```text
Aditya Patil
```

-`cin` will read only:

```text
Aditya
```

-To read an entire line, use `getline()`.

---

## 💻 Example 2 — String Input Using `cin`-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name;

    // Take one word as input.
    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello, " << name;

    return 0;
}
```

### Example Input-

```text
Aditya
```

### Output

```text
Hello, Aditya
```

---

## 🔹 `getline()`

-`getline()` is used to read an entire line, including spaces.

### Syntax

```cpp
getline(cin, variableName);
```

-Example:

```cpp
getline(cin, fullName);
```

-If the user enters:

```text
Aditya Patil
```

-the complete text is stored in `fullName`.

---

## 💻 Example 3 — Reading a Full Line-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string fullName;

    // getline() reads the complete line, including spaces.
    cout << "Enter your full name: ";
    getline(cin, fullName);

    cout << "Your name is: " << fullName;

    return 0;
}
```

### Example Input-

```text
Aditya Patil
```

### Output

```text
Your name is: Aditya Patil
```

---

## 🔹 Accessing Individual Characters-

-A string is made up of individual characters.

-For example:

```text
Aditya
```

-can be represented as:

```text
Index:      0   1   2   3   4   5
Character:  A   d   i   t   y
```

-Each character can be accessed using its index.

### Syntax

```cpp
stringName[index]
```

-Example:

```cpp
name[0]
```

-returns the first character.

---

## 💻 Example 4 — Accessing Characters

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name = "Aditya";

    // Indexing starts from 0.
    cout << "First character: " << name[0] << endl;

    // Access the third character.
    cout << "Third character: " << name[2] << endl;

    return 0;
}
```

### Output

```text
First character: A
Third character: i
```

---

## 🔹 Finding String Length

-The `.length()` function returns the number of characters in a string.

### Syntax

```cpp
stringName.length();
```

-Example:

```cpp
name.length();
```

-For:

```text
"Aditya"
```

-the length is:

```text
6
```

---

## 💻 Example 5 — String Length-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name = "Aditya";

    // length() returns the number of characters.
    cout << "Length = " << name.length();

    return 0;
}
```

### Output-

```text
Length = 6
```

---

## 🔹 Traversing a String-

-Since a string contains characters, we can use a loop to visit every character.

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string word = "Hello";

    // Loop through every character using its index.
    for (int i = 0; i < word.length(); i++)
    {
        cout << word[i] << endl;
    }

    return 0;
}
```

### Output

```text
H
e
l
l
o
```

---

## 🔹 Modifying Characters

-Individual characters can be changed using their indexes.

```cpp
string word = "Hello";

word[0] = 'Y';
```

-The string becomes:

```text
Yello
```

### Example-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string word = "Hello";

    // Change the first character from H to Y.
    word[0] = 'Y';

    cout << word;

    return 0;
}
```

### Output-

```text
Yello
```

---

## 📝 Important Points-

1. A string is a sequence of characters.
  
2. `std::string` is provided by the `<string>` library.
 
3. A string can be declared using:

   ```cpp
   string name;
   ```
4. `cin >> string` normally reads only one word.
 
5. `getline()` reads an entire line, including spaces.
 
6. String indexing starts from `0`.
 
7. Individual characters can be accessed using:

   ```cpp
   string[index]
   ```
8. `.length()` returns the number of characters.
  
9. A string can be traversed using a loop.

10. Individual characters can be modified using their indexes.
  
11. Use **double quotes** for strings:

```cpp
"Hello"
```

12. Use **single quotes** for individual characters:

```cpp
'H'
```

## 🎯 Summary-

-The modern C++ way to work with text is `std::string`.

-Basic example:

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name;

    cout << "Enter your name: ";
    getline(cin, name);

    cout << "Hello, " << name;

    return 0;
}
```

```text

     ↓
Initialization
     ↓
Input
     ↓
Character Access
     ↓

     ↓

     ↓

```
