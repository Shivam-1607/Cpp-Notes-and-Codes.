# 📄31. Strings Basics-

## 📌 Theory-

-A **string** is a sequence of characters used to store text.

-Examples:

```text
"Hello"
"Aditya"
"Hello World"
"C++ Programming"
```

-In C++, strings can be handled mainly in two ways:

1. **C-style strings** → Character arrays
   
2. **`std::string`** → String class provided by the C++ Standard Library

-For modern C++ programming, `std::string` is generally easier and safer to use.

---

## 🔹 Including the String Library-

-To use `std::string`, include:

```cpp
#include <string>
```

-Because `string` belongs to the `std` namespace, we can write:

```cpp
std::string
```

-or use:

```cpp
using namespace std;
```

-and then simply write:

```cpp
string
```

---

## 🔹 Declaring a String-

### Syntax-

```cpp
string variableName;
```

-Example:

```cpp
string name;
```

-This creates a string variable named `name`.

---

## 🔹 Initializing a String-

-A string can be initialized when it is declared.

```cpp
string name = "Aditya";
```

-Another example:

```cpp
string message = "Hello World";
```

---

## 💻 Example 1 — Basic String-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    // Create a string variable and store text in it.
    string name = "Aditya";

    // Display the string.
    cout << "Name: " << name;

    return 0;
}
```

### Output

```text
Name: Aditya
```

---

## 🔹 Taking String Input-

-The `cin` operator can be used to take a single word as input.

```cpp
cin >> name;
```

-However, `cin` stops reading when it encounters a **space**.

-For example, if the user enters:

```text
Aditya Patil
```

-`cin` will read only:

```text
Aditya
```

-To read an entire line, use `getline()`.

---

## 💻 Example 2 — String Input Using `cin`-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name;

    // Take one word as input.
    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello, " << name;

    return 0;
}
```

### Example Input-

```text
Aditya
```

### Output

```text
Hello, Aditya
```

---

## 🔹 `getline()`

-`getline()` is used to read an entire line, including spaces.

### Syntax

```cpp
getline(cin, variableName);
```

-Example:

```cpp
getline(cin, fullName);
```

-If the user enters:

```text
Aditya Patil
```

-the complete text is stored in `fullName`.

---

## 💻 Example 3 — Reading a Full Line-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string fullName;

    // getline() reads the complete line, including spaces.
    cout << "Enter your full name: ";
    getline(cin, fullName);

    cout << "Your name is: " << fullName;

    return 0;
}
```

### Example Input-

```text
Aditya Patil
```

### Output

```text
Your name is: Aditya Patil
```

---

## 🔹 Accessing Individual Characters-

-A string is made up of individual characters.

-For example:

```text
Aditya
```

-can be represented as:

```text
Index:      0   1   2   3   4   5
Character:  A   d   i   t   y
```

-Each character can be accessed using its index.

### Syntax

```cpp
stringName[index]
```

-Example:

```cpp
name[0]
```

-returns the first character.

---

## 💻 Example 4 — Accessing Characters

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name = "Aditya";

    // Indexing starts from 0.
    cout << "First character: " << name[0] << endl;

    // Access the third character.
    cout << "Third character: " << name[2] << endl;

    return 0;
}
```

### Output

```text
First character: A
Third character: i
```

---

## 🔹 Finding String Length

-The `.length()` function returns the number of characters in a string.

### Syntax

```cpp
stringName.length();
```

-Example:

```cpp
name.length();
```

-For:

```text
"Aditya"
```

-the length is:

```text
6
```

---

## 💻 Example 5 — String Length-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name = "Aditya";

    // length() returns the number of characters.
    cout << "Length = " << name.length();

    return 0;
}
```

### Output-

```text
Length = 6
```

---

## 🔹 Traversing a String-

-Since a string contains characters, we can use a loop to visit every character.

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string word = "Hello";

    // Loop through every character using its index.
    for (int i = 0; i < word.length(); i++)
    {
        cout << word[i] << endl;
    }

    return 0;
}
```

### Output

```text
H
e
l
l
o
```

---

## 🔹 Modifying Characters

-Individual characters can be changed using their indexes.

```cpp
string word = "Hello";

word[0] = 'Y';
```

-The string becomes:

```text
Yello
```

### Example-

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string word = "Hello";

    // Change the first character from H to Y.
    word[0] = 'Y';

    cout << word;

    return 0;
}
```

### Output-

```text
Yello
```

---

## 📝 Important Points-

1. A string is a sequence of characters.
  
2. `std::string` is provided by the `<string>` library.
 
3. A string can be declared using:

   ```cpp
   string name;
   ```
4. `cin >> string` normally reads only one word.
 
5. `getline()` reads an entire line, including spaces.
 
6. String indexing starts from `0`.
 
7. Individual characters can be accessed using:

   ```cpp
   string[index]
   ```
8. `.length()` returns the number of characters.
  
9. A string can be traversed using a loop.

10. Individual characters can be modified using their indexes.
  
11. Use **double quotes** for strings:

```cpp
"Hello"
```

12. Use **single quotes** for individual characters:

```cpp
'H'
```

## 🎯 Summary-

-The modern C++ way to work with text is `std::string`.

-Basic example:

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name;

    cout << "Enter your name: ";
    getline(cin, name);

    cout << "Hello, " << name;

    return 0;
}
```

-Important string operations learned in this topic:

```text
Declaration
     ↓
Initialization
     ↓
Input
     ↓
Character Access
     ↓
Length
     ↓
Traversal
     ↓
Modification
```

-`std::string` provides a much easier way to work with text than manually managing character arrays.

# 📄33. C-Style Strings-

## 📌 Theory-

-Before `std::string` became commonly used in modern C++, strings were often stored using **character arrays**.

-These are called **C-style strings** because they come from the C programming language.

-A C-style string is a character array that ends with a special character called the **null character**:

```cpp
'\0'
```

-The null character tells C++ where the string ends.

-For example:

```text id="q7n4cw"
H  e  l  l  o  \0
```

-The characters `H`, `e`, `l`, `l`, and `o` form the text, while `\0` marks the end.

---

## 🔹 Declaring a C-Style String-

### Syntax

```cpp
char stringName[size];
```

-Example:

```cpp
char name[20];
```

-This creates a character array that can store characters.

---

## 🔹 Initializing a C-Style String-

-A character array can be initialized using a string literal.

```cpp
char name[] = "Aditya";
```

-C++ automatically adds the null character `'\0'` at the end.

-Conceptually, it is stored as:

```text id="9x3j5q"
A  d  i  t  y  a  \0
```

-Therefore, `"Aditya"` requires **7 characters of storage**, including the null character.

---

## 💻 Example 1 — Basic C-Style String-

```cpp id="k4s8vn"
#include <iostream>
using namespace std;

int main()
{
    // Create a character array containing a C-style string.
    // The compiler automatically adds '\0' at the end.
    char name[] = "Aditya";

    // Display the complete C-style string.
    cout << name;

    return 0;
}
```

### Output-

```text id="h7x2pd"
Aditya
```

---

## 🔹 Character Array vs C-Style String-

-Not every character array is automatically a valid C-style string.

-For example:

```cpp id="n1y5rf"
char letters[] = {'A', 'B', 'C'};
```

-This is a character array, but it does **not** contain a null character.

-A C-style string should have:

```cpp id="q4m7vk"
char letters[] = {'A', 'B', 'C', '\0'};
```

-Now the array is a valid C-style string.

---

## 🔹 Taking Input-

-The `cin` operator can be used to take a single word.

```cpp id="b6x9mq"
char name[20];

cin >> name;
```

-However, just like `std::string`, `cin` stops reading when it encounters a space.

-For input containing spaces, functions such as `cin.getline()` can be used.

---

## 💻 Example 2 — C-Style String Input-

```cpp id="j2v8sx"
#include <iostream>
using namespace std;

int main()
{
    char name[50];

    // Take one word as input.
    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello, " << name;

    return 0;
}
```

### Example Input-

```text id="k9w3az"
Aditya
```

### Output-

```text id="c4f7qp"
Hello, Aditya
```

---

## 🔹 `cin.getline()`-

-`cin.getline()` can read a complete line, including spaces.

### Syntax-

```cpp id="f2m8wd"
cin.getline(arrayName, size);
```

### Example-

```cpp id="s7p4nk"
#include <iostream>
using namespace std;

int main()
{
    char fullName[50];

    // Read an entire line, including spaces.
    cout << "Enter your full name: ";
    cin.getline(fullName, 50);

    cout << "Your name is: " << fullName;

    return 0;
}
```

### Example Input-

```text id="t3v6yx"
Aditya Patil
```

### Output-

```text id="z8q1rm"
Your name is: Aditya Patil
```

---

## 🔹 Finding the Length with `strlen()`-

-The `<cstring>` library provides functions for working with C-style strings.

-`strlen()` returns the number of characters **excluding** the null character.

### Syntax

```cpp id="v9k5bx"
strlen(stringName);
```

### Example

```cpp id="p4m7cs"
#include <iostream>
#include <cstring>

using namespace std;

int main()
{
    char word[] = "Hello";

    // strlen() counts H, e, l, l, o.
    // It does not count the '\0' character.
    cout << "Length = " << strlen(word);

    return 0;
}
```

### Output-

```text id="d6r2kw"
Length = 5
```

---

## 🔹 Copying a C-Style String-

-`strcpy()` copies one C-style string into another.

### Syntax-

```cpp id="n3x8fa"
strcpy(destination, source);
```

### Example-

```cpp id="w6q2jp"
#include <iostream>
#include <cstring>

using namespace std;

int main()
{
    char source[] = "Hello";
    char destination[20];

    // Copy the contents of source into destination.
    strcpy(destination, source);

    cout << destination;

    return 0;
}
```

### Output-

```text id="m5v9qd"
Hello
```

---

## 🔹 Joining C-Style Strings-

-`strcat()` joins one C-style string to the end of another.

### Syntax-

```cpp id="z1c6vx"
strcat(destination, source);
```

### Example-

```cpp id="h8r3wm"
#include <iostream>
#include <cstring>

using namespace std;

int main()
{
    // destination must have enough space for both strings.
    char first[30] = "Hello ";
    char second[] = "World";

    // Add second to the end of first.
    strcat(first, second);

    cout << first;

    return 0;
}
```

### Output-

```text id="q6n4ys"
Hello World
```

---

## 🔹 Comparing C-Style Strings-

-`strcmp()` compares two C-style strings.

### Syntax

```cpp id="g2v7kx"
strcmp(string1, string2);
```

-The result is:

```text id="j5m8pc"
0     → Strings are equal
< 0   → First string is smaller
> 0   → First string is greater
```

### Example-

```cpp id="r8d3wn"
#include <iostream>
#include <cstring>

using namespace std;

int main()
{
    char first[] = "Hello";
    char second[] = "Hello";

    // Compare both strings.
    if (strcmp(first, second) == 0)
    {
        cout << "Strings are equal";
    }
    else
    {
        cout << "Strings are different";
    }

    return 0;
}
```

### Output-

```text id="u4q7bz"
Strings are equal
```

---

## 🔹 Common `<cstring>` Functions-

| Function   | Purpose             |
| ---------- | ------------------- |
| `strlen()` | Finds string length |

| `strcat()` | Joins strings       |
| `strcmp()` | Compares strings    |

-These functions are provided by:

```cpp id="f8w2md"
#include <cstring>
```

## ⚠️ Important: Array Size-

-C-style strings require enough memory for all characters **plus `'\0'`**.

-For example:

```cpp id="e6s3kp"
char name[7] = "Aditya";
```

-This is valid because:

```text id="y7n4cv"
A d i t y a \0
←  7 characters  →
```

-But:

```cpp
char name[6] = "Aditya";
```

-does not provide enough space for the null character.

   ```cpp

   ```

4. `<cstring>` provides functions for manipulating C-style strings.

6. `strcpy()` copies a string.
    
8. `strcat()` joins strings.
    
9. `strcmp()` compares strings.
    
10. `cin >>` reads a single word.

12. The character array must have enough space for the string and `'\0'`.
    
13. `std::string` is generally easier to use in modern C++.
