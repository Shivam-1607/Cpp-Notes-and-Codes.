# 📄42.Classes Basics-

## What is a Class?-

-A **class** in C++ is a user-defined data type that groups:

* **Data members** — variables that store data
  
* **Member functions** — functions that work with that data

-A class acts like a **blueprint** for creating objects.

-For example, a `Student` class can contain a student's name, age, and a function to display the student's information.

---

## Basic Syntax-

```cpp
class ClassName {
public:
    // Data members
    // Member functions
};
```

* `class` is the keyword used to create a class.
  
* `ClassName` is the name of the class.
  
* The `{ }` contain the members of the class.
  
* The semicolon `;` after `}` is required.

---

## Creating a Simple Class-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    void display() {
        // This member function displays the student's information.
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Creating an object of the Student class.
    Student student1;

    // Assigning values to the object's data members.
    student1.name = "Rahul";
    student1.age = 19;

    // Calling the member function using the object.
    student1.display();

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
```

---

## What is an Object?-

-An **object** is an instance of a class.

-If a class is a blueprint, an object is the actual thing created using that blueprint.

-For example:

```cpp
Student student1;
```

-Here:

* `Student` → class
  
* `student1` → object

-We can create multiple objects from the same class.

```cpp
Student student1;
Student student2;
Student student3;
```

-Each object has its own copy of the class's non-static data members.

---

## Multiple Objects-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Creating the first object.
    Student student1;

    // Creating the second object.
    Student student2;

    // Giving values to the first object.
    student1.name = "Aman";
    student1.age = 19;

    // Giving values to the second object.
    student2.name = "Riya";
    student2.age = 20;

    // Each object calls the same member function
    // but works with its own data.
    student1.display();
    student2.display();

    return 0;
}
```

### Output-

```text
Name: Aman
Age: 19
Name: Riya
Age: 20
```

---

## Accessing Class Members-

-The **dot (`.`) operator** is used to access members through an object.

```cpp
object.member;
```

-Example:

```cpp
student1.name;
student1.age;
student1.display();
```

-Here:

* `student1.name` accesses the `name` variable.
  
* `student1.age` accesses the `age` variable.
  
* `student1.display()` calls the `display()` function.

---

## Member Functions Inside a Class-

-A function defined inside a class is called a **member function**.

```cpp
class Calculator {
public:
    int add(int a, int b) {
        // This function belongs to the Calculator class.
        return a + b;
    }
};
```

-Using it:

```cpp
int main() {
    Calculator calc;

    cout << calc.add(10, 20);

    return 0;
}
```

-Output:

```text
30
```

---

## Defining a Member Function Outside the Class-

-A member function can also be declared inside the class and defined outside it.

-The **scope resolution operator (`::`)** is used for this.

### Syntax-

```cpp
class ClassName {
public:
    returnType functionName();
};

returnType ClassName::functionName() {
    // Function definition
}
```

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;

    // Function declaration.
    void display();
};

// Defining the member function outside the class.
// Student::display means display() belongs to Student.
void Student::display() {
    cout << "Name: " << name << endl;
}

int main() {
    Student student1;

    student1.name = "Rahul";

    // Calling the member function.
    student1.display();

    return 0;
}
```

-Output:

```text
Name: Rahul
```

---

## Class with Data and Multiple Functions-

-A class can contain multiple data members and multiple member functions.

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    int area() {
        // Calculates and returns the area.
        return length * width;
    }

    int perimeter() {
        // Calculates and returns the perimeter.
        return 2 * (length + width);
    }
};

int main() {
    Rectangle rectangle1;

    rectangle1.length = 10;
    rectangle1.width = 5;

    cout << "Area: " << rectangle1.area() << endl;
    cout << "Perimeter: " << rectangle1.perimeter() << endl;

    return 0;
}
```

-Output:

```text
Area: 50
Perimeter: 30
```

---

## Default Access in a Class-

-If no access specifier is written in a class, its members are **private by default**.

-Example:

```cpp
class Student {
    int age;  // Private by default.
};
```

-The `age` variable cannot be directly accessed from `main()`.

-For now, we use `public` when we want members to be directly accessible through an object.

-Detailed discussion of `public`, `private`, and `protected` will be covered in the **Access Specifiers** topic.

---

## Class vs Structure-

-Classes and structures are very similar in C++.

-The main basic difference is their default access:

| Feature          | `class`   | `struct` |
| ---------------- | --------- | -------- |
| Default access   | `private` | `public` |
| Member functions | Yes       | Yes      |
| Data members     | Yes       | Yes      |
| Objects          | Yes       | Yes      |
| Supports OOP     | Yes       | Yes      |

-Example:

```cpp
class A {
    int x;  // Private by default.
};

struct B {
    int x;  // Public by default.
};
```

---

## Important Points-

* A **class** is a blueprint for creating objects.
  
* An **object** is an instance of a class.
  
* A class can contain data members and member functions.
  
* Objects are created using the class name.
  
* The dot (`.`) operator is used to access members through an object.
  
* A member function can be defined inside or outside the class.
  
* The scope resolution operator (`::`) is used when defining a member function outside the class.
  
* Class members are **private by default**.
  
* `struct` members are **public by default**.
  
* Multiple objects can be created from the same class.
  
* Each object normally has its own copy of non-static data members.

## Summary-

```text
Class
 ├── Data Members
 │    ├── name
 │    ├── age
 │    └── etc.
 │
 └── Member Functions
      ├── display()
      ├── calculate()
      └── etc.

        ↓

     Objects
        ↓
 student1
 student2
 student3
```

-A class provides the structure, while objects are the actual instances created from that structure.

# 📄43. Access Specifiers-

## What are Access Specifiers?-

-**Access specifiers** control where the members of a class can be accessed from.

-C++ provides three main access specifiers:

1. `public`
2. `private`
3. `protected`

-They control the visibility and accessibility of data members and member functions.

---

## 1. Public-

-Members declared under `public` can be accessed from outside the class using an object.

### Syntax-

```cpp
class Student {
public:
    string name;
    int age;
};
```

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;
};

int main() {
    Student student1;

    // Public members can be accessed directly.
    student1.name = "Rahul";
    student1.age = 19;

    cout << student1.name << endl;
    cout << student1.age << endl;

    return 0;
}
```

### Output-

```text
Rahul
19
```

---

## 2. Private-

-Members declared under `private` can only be accessed from inside the class.

-They cannot be accessed directly from outside the class.

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int age;

public:
    void setAge(int a) {
        // age can be accessed here because this function
        // is a member of the Student class.
        age = a;
    }

    void displayAge() {
        cout << "Age: " << age << endl;
    }
};

int main() {
    Student student1;

    // We cannot do:
    // student1.age = 19;
    // because age is private.

    // Instead, we use a public member function.
    student1.setAge(19);

    student1.displayAge();

    return 0;
}
```

### Output-

```text
Age: 19
```

---

## Why Use Private Members?-

-Private members help protect the internal data of a class.

-For example, suppose a student's age should not be allowed to have an invalid value.

-Instead of allowing:

```cpp
student1.age = -100;
```

-we can control the value through a function.

```cpp
void setAge(int a) {
    if (a >= 0) {
        age = a;
    }
}
```

-This allows the class to control how its data is modified.

---

## 3. Protected-

-Members declared as `protected` can be accessed:

* Inside the same class
* Inside derived classes

-They cannot normally be accessed directly using an object from outside the class.

-Inheritance will be covered later, so for now remember that `protected` is mainly useful when working with **inheritance**.

### Example-

```cpp
class Student {
protected:
    int age;
};
```

-This means `age` is protected and is not directly accessible from `main()`.

---

## Comparing the Three Access Specifiers-

| Access Specifier | Same Class | Derived Class | Outside Class |
| ---------------- | ---------- | ------------- | ------------- |
| `public`         | Yes        | Yes           | Yes           |
| `private`        | Yes        | No*           | No            |
| `protected`      | Yes        | Yes           | No            |

-`private` members can still be accessed indirectly through appropriate public/protected member functions.

---

## Default Access in a Class-

-Class members are **private by default**.

```cpp
class Student {
    int age;
};
```

-This is equivalent to:

```cpp
class Student {
private:
    int age;
};
```

-Therefore:

```cpp
int main() {
    Student student1;

    // Error because age is private.
    // student1.age = 19;
}
```

---

## Default Access in a Structure-

-Structure members are **public by default**.

```cpp
struct Student {
    int age;
};
```

-This is equivalent to:

```cpp
struct Student {
public:
    int age;
};
```

-Therefore:

```cpp
int main() {
    Student student1;

    // This is allowed because age is public.
    student1.age = 19;
}
```

---

## Using Multiple Access Specifiers-

-A class can contain multiple access specifiers.

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int age;

protected:
    int rollNumber;

public:
    string name;

    void display() {
        // All three members can be accessed
        // from inside the class.
        cout << name << endl;
        cout << age << endl;
        cout << rollNumber << endl;
    }
};

int main() {
    Student student1;

    // Public member can be accessed.
    student1.name = "Rahul";

    // These cannot be accessed directly from outside.
    // student1.age = 19;
    // student1.rollNumber = 101;

    student1.display();

    return 0;
}
```

---

## Accessing Private Data Using Public Functions-

-A common pattern is to keep data private and provide public functions to work with it.

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    void setBalance(double amount) {
        // Only positive amounts are accepted.
        if (amount >= 0) {
            balance = amount;
        }
    }

    double getBalance() {
        // Returns the private balance.
        return balance;
    }
};

int main() {
    BankAccount account;

    // Direct access is not allowed:
    // account.balance = 5000;

    // Use public functions instead.
    account.setBalance(5000);

    cout << "Balance: " << account.getBalance() << endl;

    return 0;
}
```

### Output-

```text
Balance: 5000
```

---

## Getter and Setter Functions-

-Functions commonly used to access private data are called:

### Getter-

-A **getter** retrieves or returns the value.

```cpp
int getAge() {
    return age;
}
```

### Setter-

-A **setter** changes or assigns the value.

```cpp
void setAge(int a) {
    age = a;
}
```

-Example:

```cpp
class Student {
private:
    int age;

public:
    // Setter
    void setAge(int a) {
        age = a;
    }

    // Getter
    int getAge() {
        return age;
    }
};
```

-Using them:

```cpp
Student student1;

student1.setAge(19);

cout << student1.getAge();
```

-Output:

```text
19
```

---

## Important Points-

* Access specifiers control access to class members.
  
* C++ has three main access specifiers:

  * `public`
  * `private`
  * `protected`
    
* `public` members can be accessed from outside the class.
  
* `private` members cannot be accessed directly from outside the class.
  
* `protected` members are mainly used with inheritance.
  
* Class members are `private` by default.

* Structure members are `public` by default.
  
* Getters are generally used to retrieve private data.
  
* Setters are generally used to modify private data.
  
* Access control helps protect the internal data of a class.

## Summary-

```text
public
  ↓
Accessible from almost anywhere

private
  ↓
Accessible only inside the same class

protected
  ↓
Accessible inside the class
and derived classes
```
