# 📄42.Classes Basics-

## What is a Class?-

-A **class** in C++ is a user-defined data type that groups:

* **Data members** — variables that store data
  
* **Member functions** — functions that work with that data

-A class acts like a **blueprint** for creating objects.

-For example, a `Student` class can contain a student's name, age, and a function to display the student's information.

---

## Basic Syntax-

```cpp
class ClassName {
public:
    // Data members
    // Member functions
};
```

* `class` is the keyword used to create a class.
  
* `ClassName` is the name of the class.
  
* The `{ }` contain the members of the class.
  
* The semicolon `;` after `}` is required.

---

## Creating a Simple Class-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    void display() {
        // This member function displays the student's information.
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Creating an object of the Student class.
    Student student1;

    // Assigning values to the object's data members.
    student1.name = "Rahul";
    student1.age = 19;

    // Calling the member function using the object.
    student1.display();

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
```

---

## What is an Object?-

-An **object** is an instance of a class.

-If a class is a blueprint, an object is the actual thing created using that blueprint.

-For example:

```cpp
Student student1;
```

-Here:

* `Student` → class
  
* `student1` → object

-We can create multiple objects from the same class.

```cpp
Student student1;
Student student2;
Student student3;
```

-Each object has its own copy of the class's non-static data members.

---

## Multiple Objects-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Creating the first object.
    Student student1;

    // Creating the second object.
    Student student2;

    // Giving values to the first object.
    student1.name = "Aman";
    student1.age = 19;

    // Giving values to the second object.
    student2.name = "Riya";
    student2.age = 20;

    // Each object calls the same member function
    // but works with its own data.
    student1.display();
    student2.display();

    return 0;
}
```

### Output-

```text
Name: Aman
Age: 19
Name: Riya
Age: 20
```

---

## Accessing Class Members-

-The **dot (`.`) operator** is used to access members through an object.

```cpp
object.member;
```

-Example:

```cpp
student1.name;
student1.age;
student1.display();
```

-Here:

* `student1.name` accesses the `name` variable.
  
* `student1.age` accesses the `age` variable.
  
* `student1.display()` calls the `display()` function.

---

## Member Functions Inside a Class-

-A function defined inside a class is called a **member function**.

```cpp
class Calculator {
public:
    int add(int a, int b) {
        // This function belongs to the Calculator class.
        return a + b;
    }
};
```

-Using it:

```cpp
int main() {
    Calculator calc;

    cout << calc.add(10, 20);

    return 0;
}
```

-Output:

```text
30
```

---

## Defining a Member Function Outside the Class-

-A member function can also be declared inside the class and defined outside it.

-The **scope resolution operator (`::`)** is used for this.

### Syntax-

```cpp
class ClassName {
public:
    returnType functionName();
};

returnType ClassName::functionName() {
    // Function definition
}
```

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;

    // Function declaration.
    void display();
};

// Defining the member function outside the class.
// Student::display means display() belongs to Student.
void Student::display() {
    cout << "Name: " << name << endl;
}

int main() {
    Student student1;

    student1.name = "Rahul";

    // Calling the member function.
    student1.display();

    return 0;
}
```

-Output:

```text
Name: Rahul
```

---

## Class with Data and Multiple Functions-

-A class can contain multiple data members and multiple member functions.

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    int area() {
        // Calculates and returns the area.
        return length * width;
    }

    int perimeter() {
        // Calculates and returns the perimeter.
        return 2 * (length + width);
    }
};

int main() {
    Rectangle rectangle1;

    rectangle1.length = 10;
    rectangle1.width = 5;

    cout << "Area: " << rectangle1.area() << endl;
    cout << "Perimeter: " << rectangle1.perimeter() << endl;

    return 0;
}
```

-Output:

```text
Area: 50
Perimeter: 30
```

---

## Default Access in a Class-

-If no access specifier is written in a class, its members are **private by default**.

-Example:

```cpp
class Student {
    int age;  // Private by default.
};
```

-The `age` variable cannot be directly accessed from `main()`.

-For now, we use `public` when we want members to be directly accessible through an object.

-Detailed discussion of `public`, `private`, and `protected` will be covered in the **Access Specifiers** topic.

---

## Class vs Structure-

-Classes and structures are very similar in C++.

-The main basic difference is their default access:

| Feature          | `class`   | `struct` |
| ---------------- | --------- | -------- |
| Default access   | `private` | `public` |
| Member functions | Yes       | Yes      |
| Data members     | Yes       | Yes      |
| Objects          | Yes       | Yes      |
| Supports OOP     | Yes       | Yes      |

-Example:

```cpp
class A {
    int x;  // Private by default.
};

struct B {
    int x;  // Public by default.
};
```

---

## Important Points-

* A **class** is a blueprint for creating objects.
  
* An **object** is an instance of a class.
  
* A class can contain data members and member functions.
  
* Objects are created using the class name.
  
* The dot (`.`) operator is used to access members through an object.
  
* A member function can be defined inside or outside the class.
  
* The scope resolution operator (`::`) is used when defining a member function outside the class.
  
* Class members are **private by default**.
  
* `struct` members are **public by default**.
  
* Multiple objects can be created from the same class.
  
* Each object normally has its own copy of non-static data members.

## Summary-

```text
Class
 ├── Data Members
 │    ├── name
 │    ├── age
 │    └── etc.
 │
 └── Member Functions
      ├── display()
      ├── calculate()
      └── etc.

        ↓

     Objects
        ↓
 student1
 student2
 student3
```

-A class provides the structure, while objects are the actual instances created from that structure.

# 📄43. Access Specifiers-

## What are Access Specifiers?-

-**Access specifiers** control where the members of a class can be accessed from.

-C++ provides three main access specifiers:

1. `public`
2. `private`
3. `protected`

-They control the visibility and accessibility of data members and member functions.

---

## 1. Public-

-Members declared under `public` can be accessed from outside the class using an object.

### Syntax-

```cpp
class Student {
public:
    string name;
    int age;
};
```

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;
};

int main() {
    Student student1;

    // Public members can be accessed directly.
    student1.name = "Rahul";
    student1.age = 19;

    cout << student1.name << endl;
    cout << student1.age << endl;

    return 0;
}
```

### Output-

```text
Rahul
19
```

---

## 2. Private-

-Members declared under `private` can only be accessed from inside the class.

-They cannot be accessed directly from outside the class.

### Example-

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int age;

public:
    void setAge(int a) {
        // age can be accessed here because this function
        // is a member of the Student class.
        age = a;
    }

    void displayAge() {
        cout << "Age: " << age << endl;
    }
};

int main() {
    Student student1;

    // We cannot do:
    // student1.age = 19;
    // because age is private.

    // Instead, we use a public member function.
    student1.setAge(19);

    student1.displayAge();

    return 0;
}
```

### Output-

```text
Age: 19
```

---

## Why Use Private Members?-

-Private members help protect the internal data of a class.

-For example, suppose a student's age should not be allowed to have an invalid value.

-Instead of allowing:

```cpp
student1.age = -100;
```

-we can control the value through a function.

```cpp
void setAge(int a) {
    if (a >= 0) {
        age = a;
    }
}
```

-This allows the class to control how its data is modified.

---

## 3. Protected-

-Members declared as `protected` can be accessed:

* Inside the same class
* Inside derived classes

-They cannot normally be accessed directly using an object from outside the class.

-Inheritance will be covered later, so for now remember that `protected` is mainly useful when working with **inheritance**.

### Example-

```cpp
class Student {
protected:
    int age;
};
```

-This means `age` is protected and is not directly accessible from `main()`.

---

## Comparing the Three Access Specifiers-

| Access Specifier | Same Class | Derived Class | Outside Class |
| ---------------- | ---------- | ------------- | ------------- |
| `public`         | Yes        | Yes           | Yes           |
| `private`        | Yes        | No*           | No            |
| `protected`      | Yes        | Yes           | No            |

-`private` members can still be accessed indirectly through appropriate public/protected member functions.

---

## Default Access in a Class-

-Class members are **private by default**.

```cpp
class Student {
    int age;
};
```

-This is equivalent to:

```cpp
class Student {
private:
    int age;
};
```

-Therefore:

```cpp
int main() {
    Student student1;

    // Error because age is private.
    // student1.age = 19;
}
```

---

## Default Access in a Structure-

-Structure members are **public by default**.

```cpp
struct Student {
    int age;
};
```

-This is equivalent to:

```cpp
struct Student {
public:
    int age;
};
```

-Therefore:

```cpp
int main() {
    Student student1;

    // This is allowed because age is public.
    student1.age = 19;
}
```

---

## Using Multiple Access Specifiers-

-A class can contain multiple access specifiers.

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int age;

protected:
    int rollNumber;

public:
    string name;

    void display() {
        // All three members can be accessed
        // from inside the class.
        cout << name << endl;
        cout << age << endl;
        cout << rollNumber << endl;
    }
};

int main() {
    Student student1;

    // Public member can be accessed.
    student1.name = "Rahul";

    // These cannot be accessed directly from outside.
    // student1.age = 19;
    // student1.rollNumber = 101;

    student1.display();

    return 0;
}
```

---

## Accessing Private Data Using Public Functions-

-A common pattern is to keep data private and provide public functions to work with it.

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    void setBalance(double amount) {
        // Only positive amounts are accepted.
        if (amount >= 0) {
            balance = amount;
        }
    }

    double getBalance() {
        // Returns the private balance.
        return balance;
    }
};

int main() {
    BankAccount account;

    // Direct access is not allowed:
    // account.balance = 5000;

    // Use public functions instead.
    account.setBalance(5000);

    cout << "Balance: " << account.getBalance() << endl;

    return 0;
}
```

### Output-

```text
Balance: 5000
```

---

## Getter and Setter Functions-

-Functions commonly used to access private data are called:

### Getter-

-A **getter** retrieves or returns the value.

```cpp
int getAge() {
    return age;
}
```

### Setter-

-A **setter** changes or assigns the value.

```cpp
void setAge(int a) {
    age = a;
}
```

-Example:

```cpp
class Student {
private:
    int age;

public:
    // Setter
    void setAge(int a) {
        age = a;
    }

    // Getter
    int getAge() {
        return age;
    }
};
```

-Using them:

```cpp
Student student1;

student1.setAge(19);

cout << student1.getAge();
```

-Output:

```text
19
```

---

## Important Points-

* Access specifiers control access to class members.
  
* C++ has three main access specifiers:

  * `public`
  * `private`
  * `protected`
    
* `public` members can be accessed from outside the class.
  
* `private` members cannot be accessed directly from outside the class.
  
* `protected` members are mainly used with inheritance.
  
* Class members are `private` by default.

* Structure members are `public` by default.
  
* Getters are generally used to retrieve private data.
  
* Setters are generally used to modify private data.
  
* Access control helps protect the internal data of a class.

## Summary-

```text

  ↓
Accessible from almost anywhere

private
  ↓
Accessible only inside the same class

protected
  ↓
Accessible inside the class
and derived classes
```

```text

                 Class     Class       Class

```

# 📄44.Constructors-

## What is a Constructor?-

-A **constructor** is a special member function of a class that is automatically called when an object is created.

-It is mainly used to initialize the data members of an object.

-For example, instead of creating a student object and assigning its name and age separately, a constructor can initialize them when the object is created.

## Characteristics of a Constructor-

* Its name must be the same as the class name

* It has no return type, not even `void`.
  
* It is called automatically when an object is created.
  
* It is commonly used to initialize data members.

* Constructors can be overloaded.

* A constructor is generally declared in the `public` section so objects can be created from outside the class.

## Basic Syntax-

```cpp
class ClassName {
public:
    // Constructor
    ClassName() {
        // Initialization code
    }
};
```

-Here, `ClassName()` is the constructor because its name matches the class name and it has no return type.

## 1. Default Constructor-

-A **default constructor** is a constructor that can be called without supplying arguments.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    // Default constructor.
    Student() {
        // Initialize data members when an object is created.
        name = "Unknown";
        age = 0;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // The constructor is called automatically here.
    Student student1;

    // Display the initialized values.
    student1.display();

    return 0;
}
```

### Output-

```text
Name: Unknown
Age: 0
```

### Explanation-

1. `Student student1;` creates an object.
   
2. The `Student()` constructor is called automatically.
   
3. `name` is initialized to `"Unknown"`.
   
4. `age` is initialized to `0`.
   
5. `display()` prints these values.

-Without a user-defined constructor, built-in data members such as `int age;` are not automatically initialized to zero when an ordinary local object is created.

## 2. Constructor Without Parameters-

-A constructor without parameters is commonly used to assign initial values.

```cpp
#include <iostream>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    // Constructor without parameters.
    Rectangle() {
        length = 10;
        width = 5;
    }

    int area() {
        return length * width;
    }
};

int main() {
    Rectangle r1;

    // The constructor has already initialized length and width.
    cout << "Length: " << r1.length << endl;
    cout << "Width: " << r1.width << endl;
    cout << "Area: " << r1.area() << endl;

    return 0;
}
```

### Output-

```text
Length: 10
Width: 5
Area: 50
```

## 3. Constructor and Multiple Objects-

-Each object gets its own initialization when it is created.

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    int value;

    Counter() {
        // Each newly created object starts at zero.
        value = 0;
    }
};

int main() {
    Counter c1;
    Counter c2;

    // Change only the first object's value.
    c1.value = 10;

    cout << "c1: " << c1.value << endl;
    cout << "c2: " << c2.value << endl;

    return 0;
}
```

### Output-

```text
c1: 10
c2: 0
```

-The constructor initializes both objects independently.

## 4. Constructor Using an Initializer List-

-C++ provides a cleaner way to initialize data members called a **member initializer list**.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    // The initializer list initializes the data members.
    Student() : name("Rahul"), age(19) {
    }

    void display() {
        cout << name << endl;
        cout << age << endl;
    }
};

int main() {
    Student s1;
    s1.display();

    return 0;
}
```

### Output-

```text
Rahul
19
```

-In this example:

```cpp
Student() : name("Rahul"), age(19) {
}
```

* `name("Rahul")` initializes `name`.
  
* `age(19)` initializes `age`.
  
* The constructor body is empty because initialization is handled by the initializer list.

-Initializer lists are particularly important for `const` members, reference members, and members that do not have a default constructor.

## 5. Constructor vs Ordinary Member Function-

| Feature      | Constructor                       | Ordinary Member Function            |
| ------------ | --------------------------------- | ----------------------------------- |
| Name         | Same as the class                 | Can have any valid name             |
| Return type  | No return type                    | Has a return type, including `void` |
| Invocation   | Called during object construction | Usually called explicitly           |
| Main purpose | Initialize an object              | Perform an operation                |
| Call syntax  | `Student s1;`                     | `s1.display();`                     |

## Important Points-

* A constructor is automatically called when an object is created.


* It has no return type.
  
* A default constructor can be called without arguments.
  
* A constructor can initialize data members with fixed values.
  
* Each object is initialized separately.
  
* A member initializer list provides a direct way to initialize data members.
  
* If you declare a constructor with parameters, the compiler generally does not automatically provide a no-argument default constructor.
  
* Constructors can be overloaded to support different ways of creating objects.

## Summary=

```text
Class
  |
  v
Object is created
  |
  v
Constructor is called
  |
  v
Data members are initialized
  |
  v
Object is ready to use
```

-A constructor helps ensure that an object starts with appropriate initial values as soon as it is created.

# 📄45. Parameterized Constructor-

## What is a Parameterized Constructor?-

-A **parameterized constructor** is a constructor that accepts one or more arguments to initialize the data members of an object with specific values.

-It allows us to provide values when creating an object instead of assigning them separately after creation.

-For example, when creating a student object, we can pass the student's name and age directly to the constructor.

## Characteristics of a Parameterized Constructor-

* It accepts one or more parameters.
* Its name must be the same as the class name.
* It has no return type, not even `void`.
* It is called automatically when an object is created with matching arguments.
* Different objects can be initialized with different values.
* Parameterized constructors can be overloaded.
* If you declare a parameterized constructor, the compiler generally does not automatically provide a default constructor.

## Basic Syntax-

```cpp
class ClassName {
public:
    ClassName(data_type parameter1, data_type parameter2) {
        // Initialization code
    }
};
```

-Here, `ClassName()` is the constructor, and the parameters receive values supplied when an object is created.

## 1. Simple Parameterized Constructor-

-A parameterized constructor can initialize data members using values passed during object creation.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    // Parameterized constructor.
    Student(string n, int a) {
        name = n;
        age = a;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Pass values to the constructor.
    Student s1("Rahul", 19);
    Student s2("Aman", 20);

    s1.display();
    s2.display();

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
Name: Aman
Age: 20
```

### Explanation-

1. `Student(string n, int a)` defines a constructor that accepts a string and an integer.
2. `Student s1("Rahul", 19);` creates an object and passes `"Rahul"` and `19` to the constructor.
3. The parameters `n` and `a` receive those values.
4. `name = n;` and `age = a;` assign the values to the object's data members.
5. `s2` is initialized independently with `"Aman"` and `20`.
6. The `display()` function prints the values stored in each object.

## 2. Parameterized Constructor Using an Initializer List-

-A **member initializer list** allows data members to be initialized directly when the constructor runs.

-It is generally preferred over assigning values inside the constructor body when the goal is initialization.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Rectangle {
public:
    int length;
    int width;

    // Parameterized constructor using an initializer list.
    Rectangle(int l, int w) : length(l), width(w) {
    }

    int area() {
        return length * width;
    }
};

int main() {
    Rectangle r1(10, 5);
    Rectangle r2(8, 4);

    cout << "Area of Rectangle 1: " << r1.area() << endl;
    cout << "Area of Rectangle 2: " << r2.area() << endl;

    return 0;
}
```

### Output-

```text
Area of Rectangle 1: 50
Area of Rectangle 2: 32
```

### Explanation-

-In the following constructor:

```cpp
Rectangle(int l, int w) : length(l), width(w) {
}
```

* `int l` receives the length.
* `int w` receives the width.
* `length(l)` initializes the data member `length`.
* `width(w)` initializes the data member `width`.
* Each rectangle stores its own dimensions.

## 3. Parameterized Constructor with Multiple Objects-

-We can create multiple objects of the same class and initialize each with different values.

```cpp
#include <iostream>
using namespace std;

class Box {
public:
    int length;
    int width;
    int height;

    Box(int l, int w, int h) {
        length = l;
        width = w;
        height = h;
    }

    int volume() {
        return length * width * height;
    }
};

int main() {
    Box b1(2, 3, 4);
    Box b2(5, 2, 3);

    cout << "Volume of Box 1: " << b1.volume() << endl;
    cout << "Volume of Box 2: " << b2.volume() << endl;

    return 0;
}
```

### Output-

```text
Volume of Box 1: 24
Volume of Box 2: 30
```

### Explanation-

1. `b1` is initialized with dimensions `2`, `3`, and `4`.
2. `b2` is initialized with dimensions `5`, `2`, and `3`.
3. The `volume()` function multiplies the three dimensions.
4. Each object stores separate values, so their volumes are different.

## 4. Default Constructor vs Parameterized Constructor-

| Feature | Default Constructor | Parameterized Constructor |
|---|---|---|
| Parameters | Can be called without arguments | Accepts arguments |
| Initialization | Often uses default values | Uses values supplied during construction |
| Object creation | `Student s1;` | `Student s1("Rahul", 19);` |
| Flexibility | Usually initializes objects in a standard way | Allows different initial values |
| Example declaration | `Student()` | `Student(string n, int a)` |

## Important Points-

* A parameterized constructor accepts arguments during object creation.
* The constructor name must match the class name.
* A constructor has no return type.
* Different objects can receive different initial values.
* A member initializer list is a direct way to initialize data members.
* If only a parameterized constructor is declared, `Student s1;` will not compile unless a suitable default constructor is also provided.
* Constructors can be overloaded to allow multiple ways of initializing objects.
* Constructor parameters are local to the constructor and are separate from the object's data members.

## Summary-

```text
Parameterized Constructor
          |
          v
Object is created with arguments
          |
          v
Constructor receives the values
          |
          v
Data members are initialized
          |
          v
Object is ready to use
```

-A parameterized constructor makes object initialization flexible by allowing values to be supplied at the time of object creation.

# 📄46. Constructor Overloading-

## What is Constructor Overloading?-

-**Constructor overloading** is a feature in C++ that allows a class to have multiple constructors with different parameter lists.

-Each constructor can initialize an object in a different way depending on the arguments supplied during object creation.

-It helps us create objects with different initial values without needing separate initialization functions.

## Characteristics of Constructor Overloading-

* A class can have multiple constructors.
* All constructors must have the same name as the class.
* Constructors must differ in their parameter lists, such as the number, types, or order of parameters.
* Constructors do not have a return type.
* The compiler selects the appropriate constructor based on the arguments provided.
* Constructor overloading is an example of **compile-time polymorphism**.
* Constructors cannot be overloaded based only on different parameter names or return types.

## Basic Syntax-

```cpp
class ClassName {
public:
    ClassName() {
        // Default initialization
    }

    ClassName(int x) {
        // Initialization using one argument
    }

    ClassName(int x, int y) {
        // Initialization using two arguments
    }
};
```

-Here, the class has three constructors. Each constructor has a different parameter list.

## 1. Constructor Overloading with Different Parameters-

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    // Constructor without parameters.
    Student() {
        name = "Unknown";
        age = 0;
    }

    // Constructor with one parameter.
    Student(string n) {
        name = n;
        age = 18;
    }

    // Constructor with two parameters.
    Student(string n, int a) {
        name = n;
        age = a;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
        cout << endl;
    }
};

int main() {
    // Calls the constructor without parameters.
    Student s1;

    // Calls the constructor with one parameter.
    Student s2("Rahul");

    // Calls the constructor with two parameters.
    Student s3("Aman", 20);

    s1.display();
    s2.display();
    s3.display();

    return 0;
}
```

### Output-

```text

Age: 0

Name: Rahul
Age: 18

Name: Aman
Age: 20
```

### Explanation-

1. `Student()` initializes the object with default values.
2. `Student(string n)` accepts a name and sets the age to `18`.
3. `Student(string n, int a)` accepts both a name and an age.
4. `Student s1;` calls the constructor without parameters.
5. `Student s2("Rahul");` calls the constructor with one parameter.
6. `Student s3("Aman", 20);` calls the constructor with two parameters.
7. The compiler selects the matching constructor during compilation.

## 2. Constructor Overloading with Different Data Types-

-Constructors can also be overloaded by changing the types of their parameters.

### Explanation-

- `Demo d1(10);` selects the constructor accepting an `int`.
- `Demo d2(5.5);` selects the constructor accepting a `double`.
- `Demo d3('A');` selects the constructor accepting a `char`.

-The compiler determines which constructor to call based on overload resolution. If a call is ambiguous, the program fails to compile.

## 3. Constructor Overloading Using an Initializer List-

-Member initializer lists can be used with overloaded constructors to initialize data members directly.

4. `Rectangle r2(10, 4);` creates a rectangle with length `10` and width `4`.
5. The `area()` function calculates the area using the stored dimensions.

* Constructor overloading is an example of compile-time polymorphism.

# 📄47. Copy Constructor-

## What is a Copy Constructor?-

-A **copy constructor** is a special constructor in C++ that creates a new object by initializing it with an existing object of the same class.

-It copies the data members of an existing object into a newly created object.

-A copy constructor is useful when we want to create a new object with the same initial values as another object.

## Characteristics of a Copy Constructor-

* It has the same name as the class.
* It has no return type, not even `void`.
* It typically accepts a reference to an object of the same class.
* It is called when a new object is initialized using an existing object.
* The compiler can automatically generate a copy constructor if one is not provided, subject to the class's rules.
* A user-defined copy constructor can customize how an object's data is copied.
* The conventional signature is `ClassName(const ClassName& obj)`.

## Basic Syntax-

```cpp
class ClassName {
public:
    ClassName(const ClassName& obj) {
        // Copy data from the existing object
    }
};
```

-Here, `const ClassName& obj` refers to the existing object whose data is used to initialize the new object.

## 1. Simple Copy Constructor-

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    // Parameterized constructor.
    Student(string n, int a) {
        name = n;
        age = a;
    }

    // Copy constructor.
    Student(const Student& obj) {
        name = obj.name;
        age = obj.age;
    }

    void display() {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main() {
    // Create the first object.
    Student s1("Rahul", 19);

    // Create a new object by copying s1.
    Student s2(s1);

    cout << "Original Object:" << endl;
    s1.display();

    cout << endl;

    cout << "Copied Object:" << endl;
    s2.display();

    return 0;
}
```

### Output-

```text
Original Object:
Name: Rahul
Age: 19

Copied Object:
Name: Rahul
Age: 19
```

### Explanation-

1. `Student(string n, int a)` initializes the first object with a name and age.
2. `Student s1("Rahul", 19);` creates the original object.
3. `Student s2(s1);` creates a new object using the copy constructor.
4. `obj.name` and `obj.age` access the data members of the existing object.
5. The values are copied into the new object's data members.
6. Both objects initially contain the same values, but they are separate objects.

## 2. Copy Constructor Using Initialization Syntax-

-A copy constructor can also be called using the assignment-style initialization syntax.

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int v) : value(v) {
    }

    // Copy constructor.
    Number(const Number& obj) : value(obj.value) {
    }
};

int main() {
    Number n1(100);

    // Copy initialization.
    Number n2 = n1;

    cout << "n1: " << n1.value << endl;
    cout << "n2: " << n2.value << endl;

    return 0;
}
```

### Output-

```text
n1: 100
n2: 100
```

### Explanation-

1. `Number n1(100);` creates an object with the value `100`.
2. `Number n2 = n1;` initializes a new object using the existing object.
3. The copy constructor initializes `n2.value` with `n1.value`.
4. Both objects initially store the value `100`.

-**Important:** `Number n2 = n1;` calls a copy constructor because it creates a new object. In contrast, `n2 = n1;` after `n2` already exists is an assignment operation, not copy construction.

## 3. Copy Constructor and Independent Objects-

-When an object's ordinary data members are copied, changing a copied object's data does not automatically change the original object's corresponding data.

```cpp
#include <iostream>
using namespace std;

class Test {
public:
    int x;

    Test(int a) : x(a) {
    }

    Test(const Test& obj) : x(obj.x) {
    }
};

int main() {
    Test t1(10);

    // Copy t1 into a new object.
    Test t2(t1);

    // Change only the copied object's value.
    t2.x = 50;

    cout << "Original object: " << t1.x << endl;
    cout << "Copied object: " << t2.x << endl;

    return 0;
}
```

### Output-

```text
Original object: 10
Copied object: 50
```

### Explanation-

1. `t1` is created with the value `10`.
2. `t2` is initialized by copying `t1`.
3. Both objects initially contain `10`.
4. `t2.x = 50;` changes only the data member of `t2`.
5. The original object `t1` still contains `10`.

## 4. Default Copy Constructor-

-If a class does not declare its own copy constructor, the compiler can implicitly declare one.

-The implicitly defined copy constructor generally copies each base-class and non-static data member from the corresponding part of the source object.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    int x;
    int y;
};

int main() {
    Demo d1;

    d1.x = 10;
    d1.y = 20;

    // Uses the compiler-generated copy constructor.
    Demo d2 = d1;

    cout << "d2.x: " << d2.x << endl;
    cout << "d2.y: " << d2.y << endl;

    return 0;
}
```

### Output-

```text
d2.x: 10
d2.y: 20
```

### Explanation-

1. `d1` is created and its data members are assigned values.
2. `Demo d2 = d1;` creates a new object from `d1`.
3. The compiler-generated copy constructor copies the data members.
4. The new object contains the same values as the original object.

-Note that `d1` is an ordinary local object, so its uninitialized built-in data members must be assigned values before they are read. This example does that before copying.

## 5. Copy Constructor vs Assignment Operator-

| Feature | Copy Constructor | Assignment Operator |
|---|---|---|
| Purpose | Initializes a new object from an existing object | Assigns values to an already existing object |
| When used | During copy initialization or direct initialization from an object | When assigning one existing object to another |
| Example | `Demo d2 = d1;` | `d2 = d1;` |
| Creates a new object | Yes | No |
| Can be customized | Yes | Yes, by overloading the copy-assignment operator |

## Important Points-

* A copy constructor initializes a new object using an existing object of the same class.
* Its common form is `ClassName(const ClassName& obj)`.
* The `const` reference avoids copying the source object just to pass it as an argument.
* A copy constructor can be called explicitly through direct initialization or copy initialization.
* The compiler can generate a copy constructor automatically.
* The implicitly generated copy constructor performs member-wise copying.
* Member-wise copying can be insufficient for classes that manage dynamically allocated resources or own raw pointers.
* A copy constructor is different from the copy-assignment operator.
* C++ classes that manage resources may need a carefully designed copy constructor or may need copying to be disabled.

-A copy constructor allows a new object to be initialized from an existing object of the same class.

# 📄48. Destructor-

## What is a Destructor?-

-A **destructor** is a special member function of a class that is automatically called when an object's lifetime ends.

-It is mainly used to release resources acquired by an object, such as dynamically allocated memory, file handles, or other resources.

-A destructor is the counterpart of a constructor: a constructor initializes an object, while a destructor performs cleanup when the object's lifetime ends.

## Characteristics of a Destructor-

* Its name is the same as the class name, preceded by a tilde (`~`).
* It has no return type, not even `void`.
* It takes no parameters.
* A class can have only one destructor; destructors cannot be overloaded.
* It is called automatically when an object's lifetime ends, subject to the rules governing its lifetime.
* It is commonly used to release resources.
* A destructor can be declared `public` or `private`, depending on the class's design.
* A destructor can be virtual, which is important when deleting derived objects through base-class pointers.

## Basic Syntax-

```cpp
class ClassName {
public:
    // Constructor
    ClassName() {
        // Initialization code
    }

    // Destructor
    ~ClassName() {
        // Cleanup code
    }
};
```

-Here, `~ClassName()` is the destructor because its name matches the class name with a tilde (`~`) before it.

## 1. Simple Destructor-

-A destructor is called automatically when an object goes out of scope.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    Student() {
        cout << "Constructor called." << endl;
    }

    ~Student() {
        cout << "Destructor called." << endl;
    }
};

int main() {
    cout << "Main function started." << endl;

    Student s1;

    cout << "Object is being used." << endl;

    return 0;
}
```

### Output-

```text
Main function started.
Constructor called.
Object is being used.
Destructor called.
```

### Explanation-

1. The program begins executing `main()`.
2. The message `"Main function started."` is printed.
3. `Student s1;` creates an object, so its constructor is called.
4. The program prints `"Object is being used."`.
5. When `main()` ends, the local object's lifetime ends.
6. The destructor is called automatically before control returns to the caller.

## 2. Destructor with Multiple Objects-

-When multiple local objects are created in the same scope, their destructors are called in the reverse order of their completed construction.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    int id;

    Demo(int x) : id(x) {
        cout << "Constructor: " << id << endl;
    }

    ~Demo() {
        cout << "Destructor: " << id << endl;
    }
};

int main() {
    Demo d1(1);
    Demo d2(2);
    Demo d3(3);

    cout << "Inside main function." << endl;

    return 0;
}
```

### Output-

```text
Constructor: 1
Constructor: 2
Constructor: 3
Inside main function.
Destructor: 3
Destructor: 2
Destructor: 1
```

### Explanation-

1. `d1`, `d2`, and `d3` are constructed in that order.
2. Each constructor prints the object's ID.
3. The message `"Inside main function."` is printed.
4. When `main()` ends, the objects are destroyed in reverse construction order.
5. Therefore, `d3` is destroyed first, followed by `d2` and `d1`.

## 3. Destructor and Dynamic Memory-

-A destructor is particularly useful when a class manages a resource that must be released explicitly.

-The following example demonstrates allocating memory with `new` and releasing it with `delete` in the destructor.

```cpp
#include <iostream>
using namespace std;

class Array {
private:
    int* ptr;

public:
    Array(int size) {
        // Allocate memory dynamically.
        ptr = new int[size];

        cout << "Memory allocated." << endl;
    }

    ~Array() {
        // Release the allocated memory.
        delete[] ptr;

        cout << "Memory released." << endl;
    }
};

int main() {
    Array a1(5);

    cout << "Array object is in use." << endl;

    return 0;
}
```

### Output-

```text
Memory allocated.
Array object is in use.
Memory released.
```

### Explanation-

1. `Array a1(5);` creates an object.
2. The constructor allocates memory for five integers using `new[]`.
3. The program prints `"Array object is in use."`.
4. When `a1` goes out of scope, its destructor is called.
5. `delete[] ptr;` releases the allocated memory.

-**Important:** This simplified class demonstrates resource cleanup, but it does not define safe copy behavior. Copying an `Array` object would copy the pointer rather than duplicate the allocated array, potentially causing double deletion. In production C++, prefer a standard container such as `std::vector<int>` when appropriate, or implement proper copy and move semantics.

## 4. Constructor vs Destructor-

| Feature | Constructor | Destructor |
|---|---|---|
| Purpose | Initializes an object | Performs cleanup |
| Name | Same as the class name | Same as the class name with `~` |
| Return type | No return type | No return type |
| Parameters | Can accept parameters | Takes no parameters |
| Overloading | Can be overloaded | Cannot be overloaded |
| Invocation | Called during object construction | Called when the object's lifetime ends |
| Main use | Establishes the object's initial state | Releases resources and performs cleanup |
| Example | `Student()` | `~Student()` |

## Important Points-

* A destructor is called when an object's lifetime ends.
* Its name begins with a tilde (`~`).
* A destructor takes no parameters and has no return type.
* A class can have only one destructor.
* Local automatic objects are generally destroyed when their scope ends.
* Local objects are destroyed in reverse order of completed construction.
* Dynamically allocated objects created with `new` generally require `delete` to invoke their destructor and release their storage.
* Objects created with `new[]` generally require `delete[]`.
* A destructor should not allow exceptions to escape during stack unwinding.
* A virtual destructor is important when a derived object may be deleted through a base-class pointer.
* Smart pointers and standard containers often eliminate the need to manage resources manually.

## Summary-

```text

       |
       v

       |
       v

       |
       v

       |

Resources Are Released
```

-A destructor helps a class perform cleanup when an object's lifetime ends, making it an important part of resource management in C++.

# 📄49. `this` Pointer in C++-

## What is the `this` Pointer?-

-The **`this` pointer** is a special pointer available inside non-static member functions of a class. It points to the object for which the member function is currently called.

-It is commonly used to distinguish between an object's data members and function parameters when they have the same name.

-For example, if a constructor has a parameter named `age` and the class also has a data member named `age`, we can use `this->age` to refer to the data member.

## Characteristics of the `this` Pointer-

* It is available in non-static member functions.
* It refers to the current object.
* It can access the current object's members using the `->` operator.
* It is commonly used when parameter names and data member names are identical.
* It can be used to return the current object from a member function.
* It is not available in static member functions because static functions do not operate on a particular object through an implicit `this` pointer.
* In a `const` member function, the object cannot be modified through `this`.

## Basic Syntax-

```cpp
this->data_member;
```

-Here, `this` points to the current object, and `->` accesses one of its members.

## 1. Using `this` to Access Data Members-

-The `this` pointer helps distinguish data members from parameters with the same name.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int age;

    Student(string name, int age) {
        // Access data members using this.
        this->name = name;
        this->age = age;
    }

    void display() {
        cout << "Name: " << this->name << endl;
        cout << "Age: " << this->age << endl;
    }
};

int main() {
    Student s1("Rahul", 19);

    s1.display();

    return 0;
}
```

### Output-

```text
Name: Rahul
Age: 19
```

### Explanation-

1. The constructor accepts two parameters, `name` and `age`.
2. `this->name` refers to the current object's data member.
3. `this->age` refers to the current object's age data member.
4. The right-hand `name` and `age` refer to the constructor parameters.
5. The values are assigned to the object and displayed using `display()`.

## 2. Using `this` to Resolve Naming Conflicts-

-Without `this`, a parameter with the same name as a data member hides that data member within the parameter's scope.

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int value) {
        // The parameter is on the right.
        // The data member is on the left.
        this->value = value;
    }

    void display() {
        cout << "Value: " << value << endl;
    }
};

int main() {
    Number n1(100);
    Number n2(200);

    n1.display();
    n2.display();

    return 0;
}
```

### Output-

```text
Value: 100
Value: 200
```

### Explanation-

- `this->value` identifies the data member belonging to the current object.
- The `value` on the right-hand side refers to the constructor parameter.
- Each object stores its own value.

## 3. Returning the Current Object Using `this`-

-The current object can be returned using `*this`, which dereferences the pointer and refers to the object itself.

-This technique is useful for **method chaining**, where multiple member function calls are linked together.

```cpp
#include <iostream>
using namespace std;

class Number {
public:
    int value;

    Number(int value) : value(value) {
    }

    Number& setValue(int value) {
        this->value = value;
        return *this;
    }

    void display() {
        cout << "Value: " << value << endl;
    }
};

int main() {
    Number n1(10);

    n1.setValue(20).display();

    return 0;
}
```

### Output-

```text
Value: 20
```

### Explanation-

1. `setValue()` changes the current object's `value`.
2. `return *this;` returns a reference to the current object.
3. The returned reference allows `display()` to be called on the same object.
4. `n1.setValue(20).display();` demonstrates method chaining.

## 4. The `this` Pointer in Multiple Objects-

-The `this` pointer refers to whichever object invokes the member function.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    int x;

    Demo(int x) : x(x) {
    }

    void showAddress() {
        cout << "Object address: " << this << endl;
    }
};

int main() {
    Demo d1(10);
    Demo d2(20);

    d1.showAddress();
    d2.showAddress();

    return 0;
}
```

### Example Output-

```text

Object address: 0x7ffe5678
```

-The addresses above are illustrative. Actual memory addresses vary between executions and systems.

### Explanation-

1. `d1.showAddress()` calls the function for `d1`.
2. Inside that call, `this` points to `d1`.
3. `d2.showAddress()` calls the function for `d2`.
4. Inside that call, `this` points to `d2`.
5. The two objects normally have different addresses because they are distinct objects.

## 5. `this` Pointer vs `*this`-

| Feature | `this` | `*this` |
|---|---|---|
| Meaning | Pointer to the current object | The current object itself |
| Type in an ordinary member function | Pointer type | Object expression |
| Access syntax | `this->value` | `(*this).value` |
| Common use | Access members through the pointer | Return or work with the current object |
| Example | `this->value = 10;` | `return *this;` |

## Important Points-

* `this` is an implicit pointer available in non-static member functions.
* It refers to the object on which the member function is invoked.
* `this->member` accesses a member of the current object.
* `this->` is useful when a parameter and a data member share the same name.
* `*this` refers to the current object rather than its pointer.
* Returning `*this` by reference can enable method chaining.
* Static member functions do not have a `this` pointer.
* In a `const` member function, `this` behaves as a pointer to a const object.
* The `this` pointer cannot be used in a static member function.

# 📄50. Static Data Members and Static Member Functions-

## What is the `static` Keyword?-

-In C++, the `static` keyword is used to define class members that belong to the class itself rather than to individual objects.

-**Static data members** share one common value among all objects of a class.

-**Static member functions** can be called using the class name without creating an object.

-For example, if we want to count how many student objects have been created, a static data member can store the count shared by all students.

## Characteristics of Static Data Members-

* A static data member belongs to the class rather than to individual objects.
* Only one shared instance exists for a particular static data member.
* All objects of the class can access the same static data member.
* A static data member has static storage duration.
* In traditional C++, a static data member is declared inside the class and defined outside it.
* Since C++17, an `inline static` data member can be initialized directly inside the class.

## Basic Syntax-

```cpp
class ClassName {
public:
    static int count;
};

// Definition outside the class.
int ClassName::count = 0;
```

-Here, `static int count;` declares a shared data member, and `int ClassName::count = 0;` defines and initializes it.

## 1. Static Data Member-

-A static data member is shared by all objects of the same class.

```cpp
#include <iostream>
using namespace std;

class Student {
public:
    static int count;

    Student() {
        count++;
    }
};

// Define and initialize the static data member.
int Student::count = 0;

int main() {
    Student s1;
    Student s2;
    Student s3;

    cout << "Total objects created: " << Student::count << endl;

    return 0;
}
```

### Output-

```text
Total objects created: 3
```

### Explanation-

1. `static int count;` declares a shared variable for the class.
2. `int Student::count = 0;` defines the variable and initializes it to zero.
3. Every time a `Student` object is constructed, the constructor increments `count`.
4. Three objects are created, so the count becomes `3`.
5. `Student::count` accesses the shared variable using the class name.

## 2. Static Data Member Shared by All Objects-

-When one object changes a static data member, the change is visible through every object of the class.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    static int value;
};

int Demo::value = 10;

int main() {
    Demo d1;
    Demo d2;

    cout << "Initial value: " << d1.value << endl;

    // Change the shared data member.
    d2.value = 50;

    cout << "Value through d1: " << d1.value << endl;
    cout << "Value through d2: " << d2.value << endl;
    cout << "Value through class: " << Demo::value << endl;

    return 0;
}
```

### Output-

```text
Initial value: 10
Value through d1: 50
Value through d2: 50
Value through class: 50
```

### Explanation-

1. `Demo::value` is initialized to `10`.
2. Both `d1` and `d2` refer to the same static data member.
3. Assigning `50` through `d2.value` changes the shared value.
4. Accessing the value through `d1`, `d2`, or `Demo` now gives `50`.

-Although accessing a static member through an object is valid, using the class name is generally clearer.

## 3. Static Member Function-

-A **static member function** belongs to the class rather than to an individual object.

-It can be called using the class name and can directly access static data members and other static member functions.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    static int count;

    // Static member function.
    static void showCount() {
        cout << "Count: " << count << endl;
    }
};

int Demo::count = 100;

int main() {
    // Call without creating an object.
    Demo::showCount();

    return 0;
}
```

### Output-

```text
Count: 100
```

### Explanation-

1. `static int count;` declares a static data member.
2. `static void showCount()` declares a static member function.
3. `Demo::showCount();` calls the function using the class name.
4. The function accesses `count` directly because it is static.
5. No object is required to call the function.

## 4. Static Member Function to Modify Shared Data-

-A static member function can modify static data members because they belong to the class.

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    static int count;

    static void increment() {
        count++;
    }

    static void display() {
        cout << "Count: " << count << endl;
    }
};

int Counter::count = 0;

int main() {
    Counter::increment();
    Counter::increment();
    Counter::increment();

    Counter::display();

    return 0;
}
```

### Output-

```text
Count: 3
```

### Explanation-

1. `count` starts at `0`.
2. `Counter::increment()` increases it by one.
3. The function is called three times.
4. `Counter::display()` prints the final value, which is `3`.

## 5. Limitations of Static Member Functions-

-Static member functions do not have an implicit `this` pointer because they are not associated with a particular object.

-Therefore, they cannot directly access non-static data members or call non-static member functions without an object.

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    int x = 10;
    static int count;

    static void show() {
        cout << count << endl;

        // cout << x; // Error: x is non-static.
    }
};

int Demo::count = 5;

int main() {
    Demo::show();

    return 0;
}
```

### Output-

```text
5
```

### Explanation-

1. `count` is static, so `show()` can access it directly.
2. `x` is a non-static data member belonging to an individual object.
3. A static member function has no implicit current object.
4. Therefore, accessing `x` directly inside `show()` would cause a compilation error.

-A static member function can access a non-static member if it is given an appropriate object, for example, through a reference or pointer parameter.

## 6. Static Data Members vs Non-Static Data Members-

| Feature | Static Data Member | Non-Static Data Member |
|---|---|---|
| Belongs to | Class | Individual object |
| Number of instances | One shared member per class | One member per object |
| Storage duration | Static | Depends on the object's storage duration |
| Access | `ClassName::member` | Usually `object.member` |
| Shared between objects | Yes | No |
| Example | `static int count;` | `int age;` |

## 7. Static Member Functions vs Non-Static Member Functions-

| Feature | Static Member Function | Non-Static Member Function |
|---|---|---|
| Belongs to | Class | Operates on a particular object |
| Requires an object to call | No | Normally yes |
| Has an implicit `this` pointer | No | Yes |
| Direct access to static members | Yes | Yes |
| Direct access to non-static members | No | Yes |
| Example | `static void display();` | `void display();` |

## Important Points-

* Static data members are shared by all objects of the class.
* Static data members can be accessed using the class name and scope resolution operator (`::`).
* In traditional C++, a static data member generally needs a definition outside the class.
* Since C++17, `inline static` data members can be initialized within the class definition.
* Static member functions can be called without creating an object.
* Static member functions do not have a `this` pointer.
* Static member functions cannot directly access non-static members without an object.
* Static members are useful for shared counters, class-wide configuration, and utility functions.
* Static members are shared within the relevant class definition; they are not automatically shared across unrelated classes.

# 📄51. Friend Function in C++-

## What is a Friend Function?-

-A **friend function** is a non-member function that is granted permission to access the private and protected members of a class.

-It is declared inside the class using the `friend` keyword, but it is not a member function of that class.

-A friend function is useful when an external function needs access to a class's internal data.

-For example, a function that adds two objects may need access to their private data members. A friend function can perform this operation directly.

## Characteristics of a Friend Function-

* It is declared inside a class using the `friend` keyword.
* It is not a member function of the class.
* It can access the private and protected members of the class that declares it as a friend.
* It is generally defined outside the class, without using the `friend` keyword in its definition.
* It is called like an ordinary function, not through an object using the dot operator.
* It does not have a `this` pointer because it is not a member function.
* A friend function can be declared in the public, private, or protected section of a class.
* Friendship is not automatically mutual, transitive, or inherited.

## Basic Syntax-

```cpp
class ClassName {
private:
    int value;

public:
    friend void display(ClassName obj);
};

void display(ClassName obj) {
    // Can access private members of ClassName.
}
```

-Here, `friend void display(ClassName obj);` grants the function `display()` permission to access the private and protected members of `ClassName`.

## 1. Simple Friend Function-

-A friend function can access private data even though it is not a member of the class.

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    Student(int m) : marks(m) {
    }

    // Declare a friend function.
    friend void displayMarks(Student s);
};

// Define the friend function outside the class.
void displayMarks(Student s) {
    cout << "Marks: " << s.marks << endl;
}

int main() {
    Student s1(95);

    // Call it like an ordinary function.
    displayMarks(s1);

    return 0;
}
```

### Output-

```text
Marks: 95
```

### Explanation-

1. `marks` is a private data member of the `Student` class.
2. `friend void displayMarks(Student s);` declares `displayMarks()` as a friend.
3. The function is defined outside the class.
4. `s.marks` accesses the private data because the function has been granted friendship.
5. `displayMarks(s1);` calls the function like an ordinary function.

## 2. Friend Function to Add Two Objects-

-A friend function can access private members of multiple objects when the relevant classes grant it friendship.

```cpp
#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) : value(v) {
    }

    // Declare a friend function.
    friend int add(Number n1, Number n2);
};

// Define the friend function.
int add(Number n1, Number n2) {
    return n1.value + n2.value;
}

int main() {
    Number n1(10);
    Number n2(20);

    cout << "Sum: " << add(n1, n2) << endl;

    return 0;
}
```

### Output-

```text
Sum: 30
```

### Explanation-

1. The `Number` class contains the private data member `value`.
2. The `add()` function is declared as a friend of `Number`.
3. The function receives two `Number` objects.
4. It accesses `n1.value` and `n2.value` directly.
5. The sum of `10` and `20` is returned and printed.

## 3. One Friend Function Accessing Two Classes-

-A function can be declared as a friend in two different classes. This allows it to access the private and protected members of both classes.

```cpp
#include <iostream>
using namespace std;

class B;

class A {
private:
    int x;

public:
    A(int a) : x(a) {
    }

    friend int add(A, B);
};

class B {
private:
    int y;

public:
    B(int b) : y(b) {
    }

    friend int add(A, B);
};

// Access private members of both classes.
int add(A obj1, B obj2) {
    return obj1.x + obj2.y;
}

int main() {
    A a1(15);
    B b1(25);

    cout << "Sum: " << add(a1, b1) << endl;

    return 0;
}
```

### Output-

```text
Sum: 40
```

### Explanation-

1. `class B;` declares `B` before it is used in the declaration of `A`'s friend function.
2. Both classes declare `add()` as a friend.
3. The function can access `A::x` and `B::y`.
4. The values `15` and `25` are added.
5. The result `40` is printed.

## 4. Friend Function vs Member Function-

| Feature | Friend Function | Member Function |
|---|---|---|
| Belongs to the class | No | Yes |
| Declaration | Uses the `friend` keyword inside the class | Declared as a class member |
| Access to private members | Granted by friendship | Allowed for its own class |
| `this` pointer | Not available | Available in non-static member functions |
| Calling style | `display(obj);` | `obj.display();` |
| Main purpose | Allows an external function to access class internals | Performs operations as a class member |

## Important Points-

* A friend function is not a member of the class.
* The `friend` keyword grants access to private and protected members.
* A friend function is called like an ordinary function.
* It does not have an implicit `this` pointer.
* Friendship must be explicitly granted by the class whose private or protected members need to be accessed.
* Friendship is not mutual: if class A declares a function as its friend, that does not automatically grant A access to another class's private members.
* Friendship is not transitive: if A is a friend of B and B is a friend of C, A does not automatically become a friend of C.
* Friendship is not inherited by derived classes.
* Use friend functions only when necessary, because excessive friendship can weaken encapsulation.

## Summary-

```text

           |
           v
Friend Function Is Declared
           |
           v
Class Grants Access Permission
           |
           v
External Function Accesses
Private or Protected Members
           |
           v
Required Operation Is Performed
```

-A friend function provides controlled access to a class's private and protected members without becoming a member of that class.

# 📄52. Friend Class in C++-

## What is a Friend Class?-

-A **friend class** is a class that is granted permission to access the private and protected members of another class.

-The `friend` keyword is used to declare a class as a friend inside the class whose members need to be accessed.

-A friend class is useful when two classes need to work closely together and one class needs access to the internal data of the other.

-For example, a `Car` class may contain private information about a car, while a `Mechanic` class may need permission to access that information to perform an inspection.

## Characteristics of a Friend Class-

* A friend class is declared using the `friend` keyword.
* It can access the private and protected members of the class that declares it as a friend.
* It does not automatically grant reciprocal access.
* Friendship is not inherited or transitive.
* A friend class does not become a member or derived class of the class granting friendship.
* A class can have multiple friend classes.
* Friendship can be declared in the public, private, or protected section of a class.

## Basic Syntax-

```cpp
class ClassA {
private:
    int value;

    // ClassB is granted friendship.
    friend class ClassB;
};

class ClassB {
public:
    void display(ClassA obj) {
        // Can access ClassA's private members.
    }
};
```

-Here, `friend class ClassB;` allows the member functions of `ClassB` to access the private and protected members of `ClassA`.

## 1. Simple Friend Class-

-A friend class can access private data members of another class.

```cpp
#include <iostream>
using namespace std;

class Student {
private:
    int marks;

public:
    Student(int m) : marks(m) {
    }

    // Grant friendship to the Teacher class.
    friend class Teacher;
};

class Teacher {
public:
    void displayMarks(Student s) {
        // Access the private member of Student.
        cout << "Marks: " << s.marks << endl;
    }
};

int main() {
    Student s1(95);

    Teacher t1;

    // Call the member function of Teacher.
    t1.displayMarks(s1);

    return 0;
}
```

### Output-

```text
Marks: 95
```

### Explanation-

1. The `Student` class contains a private data member named `marks`.
2. `friend class Teacher;` grants the `Teacher` class access to the private and protected members of `Student`.
3. The `Teacher` class defines the `displayMarks()` member function.
4. The function accesses `s.marks` directly because `Teacher` is a friend of `Student`.
5. The program prints the student's marks.

## 2. Friend Class Accessing Multiple Private Members-

-A friend class can access multiple private data members of the class that grants it friendship.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Employee {
private:
    string name;
    double salary;

public:
    Employee(string n, double s) : name(n), salary(s) {
    }

    friend class Manager;
};

class Manager {
public:
    void displayEmployee(Employee e) {
        cout << "Name: " << e.name << endl;
        cout << "Salary: " << e.salary << endl;
    }
};

int main() {
    Employee e1("Rahul", 45000);

    Manager m1;

    m1.displayEmployee(e1);

    return 0;
}
```

### Output-

```text
Name: Rahul
Salary: 45000
```

### Explanation-

1. The `Employee` class contains private members `name` and `salary`.
2. The `Manager` class is declared as a friend of `Employee`.
3. The `displayEmployee()` function accesses both private members.
4. The function prints the employee's name and salary.

## 3. Friendship Is Not Mutual-

-If class A declares class B as a friend, class B can access A's private and protected members.

-However, class A does not automatically gain access to B's private members.

```cpp
#include <iostream>
using namespace std;

class B;

class A {
private:
    int x = 10;

public:
    friend class B;
};

class B {
private:
    int y = 20;

public:
    void displayA(A obj) {
        cout << "A's value: " << obj.x << endl;
    }

    void displayB() {
        cout << "B's value: " << y << endl;
    }
};

int main() {
    A a1;
    B b1;

    b1.displayA(a1);
    b1.displayB();

    return 0;
}
```

### Output-

```text
A's value: 10
B's value: 20
```

### Explanation-

1. Class `A` declares class `B` as its friend.
2. Therefore, `B` can access the private member `A::x`.
3. Class `B` can access its own private member `y` normally.
4. Class `A` does not automatically receive access to `B::y`.
5. Friendship must be declared separately in each class when reciprocal access is required.

## 4. Friend Class vs Friend Function-

| Feature | Friend Class | Friend Function |
|---|---|---|
| Meaning | Grants access to a class | Grants access to a specific function |
| Declaration | `friend class B;` | `friend void display(A obj);` |
| Access scope | Member functions of the friend class can access the granting class's private and protected members | The specified friend function can access those members |
| Membership | The friend class remains a separate class | The friend function remains a non-member function |
| Typical use | Two classes need close cooperation | One external function needs special access |

## Important Points-

* A friend class is declared using the `friend` keyword.
* It can access the private and protected members of the class that grants friendship.
* Friendship does not make the friend class a derived class.
* Friendship is not mutual, transitive, or inherited.
* A class can grant friendship to multiple classes.
* A friend class can access the granting class's private members through an object of that class.
* The granting class does not automatically gain access to the friend class's private members.
* Use friend classes carefully because they reduce encapsulation and increase coupling between classes.
