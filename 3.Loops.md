# 📄14.for Loop-

## 📌 Theory

-A `for` loop is used to **repeat a block of code** a specific number of times.

-It has three main parts:

1. **Initialization** — starts the loop variable.
 
2. **Condition** — decides whether the loop continues.
 
3. **Update** — changes the loop variable after each iteration.

## 🔹 Syntax-

```cpp
for (initialization; condition; update)
{
    // Statements to repeat
}
```

## 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Start i at 1, continue while i <= 5,
    // and increase i by 1 after every iteration
    for (int i = 1; i <= 5; i++)
    {
        cout << i << endl;
    }

    return 0;
}
```

### Output-

```text
1
2
3
4
5
```

## 🔹 How It Works-

-For this loop:

```cpp
for (int i = 1; i <= 5; i++)
```

-The execution is:

```text
Initialization → int i = 1
       ↓
Check condition → i <= 5
       ↓
Execute loop body
       ↓
Update → i++
       ↓
Check condition again
       ↓
Repeat
```

-When `i` becomes `6`, the condition `i <= 5` becomes false and the loop stops.

## 🔹 Printing Even Numbers-

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Start from 2 and increase by 2
    // This prints only even numbers
    for (int i = 2; i <= 10; i += 2)
    {
        cout << i << " ";
    }

    return 0;
}
```

### Output-

```text
2 4 6 8 10
```

## 🔹 Reverse Loop-

-A `for` loop can also run backwards.

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Start at 5 and decrease i by 1
    for (int i = 5; i >= 1; i--)
    {
        cout << i << " ";
    }

    return 0;
}
```

### Output-

```text
5 4 3 2 1
```

## 📝 Important Points-

* `for` loops are useful when the number of repetitions is known or controlled by a counter.
  
* Initialization runs only once
  
* The condition is checked before each iteration.
  
* The update runs after the loop body.
  
* `i++` increases `i` by 1.
  
* `i--` decreases `i` by 1.
  
* A loop can execute zero times if its condition is false initially.

## 🎯 Summary-

```text
for loop
   │
   ├── Initialization
   │
   ├── Condition
   │      │
   │    True
   │      ↓
   │   Loop Body
   │      ↓
   │    Update
   │      │
   │      └────→ Condition
   │
   └── False → Stop
```
# 📄15. while Loop-

## 📌 Theory-

-A `while` loop is used to repeatedly execute a block of code **as long as a condition remains true**.

-Unlike a `for` loop, the initialization and update are usually written separately.

## 🔹 Syntax-

```cpp
while (condition)
{
    // Statements
    // Update the loop variable
}
```

## 💻 Example-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int i = 1;  // Initialize the loop variable

    // Continue the loop while i is less than or equal to 5
    while (i <= 5)
    {
        cout << i << endl;

        i++;  // Increase i to eventually make the condition false
    }

    return 0;
}
```

### Output-

```text
1
2
3
4
5
```

## 🔹 How It Works-

```text
Initialize i
     ↓
Check condition
     ↓
   True?
   /   \
 Yes    No
  ↓      ↓
Execute  Stop
  ↓
Update
  ↓
Check condition again
```

## 🔹 Example with User Input-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int number;

    // Ask the user to enter a number
    cout << "Enter a positive number: ";
    cin >> number;

    // Continue until the user enters 0 or a negative number
    while (number > 0)
    {
        cout << "You entered: " << number << endl;

        // Take another number for the next iteration
        cout << "Enter another number: ";
        cin >> number;
    }

    cout << "Loop ended.";

    return 0;
}
```

## 🔹 Infinite `while` Loop-

-If the condition never becomes false, the loop continues indefinitely.

```cpp
while (true)
{
    // This loop runs continuously
}
```

-An infinite loop should normally be avoided unless it is intentionally required.

## 🔹 `for` Loop vs `while` Loop-

| `for` Loop                                                | `while` Loop                                  |
| --------------------------------------------------------- | --------------------------------------------- |
| Initialization, condition and update are usually together | These can be written separately               |
| Useful when repetitions are controlled by a counter       | Useful when repetition depends on a condition |
| Compact syntax                                            | More flexible for condition-based loops       |

## 📝 Important Points-

* A `while` loop checks the condition **before** executing the body.
  
* If the condition is initially false, the loop executes **zero times**.
  
* The loop variable should normally be updated inside the loop.
  
* Forgetting the update can create an infinite loop.
  
* `while` is useful when the exact number of iterations is not known beforehand.

## 🎯 Summary-

```text
while (condition)
       │
       ↓
   Condition
    /     \
 True     False
  ↓         ↓
Body       Stop
  ↓
Update
  │
  └────→ Condition
```
# 📄16.do-while Loop-

## 📌 Theory-

-A `do-while` loop is used to repeatedly execute a block of code while a condition is true.

-The main difference from a `while` loop is that the `do-while` loop executes its body **at least once**, because the condition is checked **after** the loop body.

## 🔹 Syntax-

```cpp
do
{
    // Statements
}
while (condition);
```

**Note:** A semicolon `;` is required after the `while` condition.

## 💻 Example

```cpp
#include <iostream>
using namespace std;

int main()
{
    int i = 1;  // Initialize the loop variable

    do
    {
        // This code executes before the condition is checked
        cout << i << endl;

        i++;  // Increase i after each iteration
    }
    while (i <= 5);  // Check the condition after executing the body

    return 0;
}
```

### Output-

```text
1
2
3
4
5
```

## 🔹 How It Works-

```text
Initialize
    ↓
Execute loop body
    ↓
Update variable
    ↓
Check condition
   /       \
 True     False
  ↓         ↓
Repeat     Stop
```

## 🔹 Important Difference from `while`-

### `while` Loop-

-The condition is checked **before** the body.

```cpp
int i = 10;

while (i < 5)
{
    cout << i;
}
```

-Output:

```text
No output
```

-The condition is false initially, so the body never executes.

### `do-while` Loop-

-The body executes **before** the condition is checked.

```cpp
int i = 10;

do
{
    cout << i;
}
while (i < 5);
```

-Output:

```text
10
```

-Even though `i < 5` is false, the body executes once.

## 🔹 Example with User Input-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int number;

    do
    {
        // Ask the user to enter a positive number
        cout << "Enter a positive number: ";
        cin >> number;

        // Display the entered number
        cout << "You entered: " << number << endl;

    } while (number > 0);  // Repeat while number is positive

    cout << "Loop ended.";

    return 0;
}
```

## 🔹 `while` vs `do-while`-

| `while` | `do-while` |
|---|---|
| Condition is checked first | Condition is checked after the body |
| May execute zero times | Executes at least once |
| `while (condition)` | `do { } while (condition);` |
| No semicolon after condition block | Semicolon required after `while(condition);` |

## 📝 Important Points-

- `do-while` executes the body **at least once**.
  
- The condition is checked after the body.
  
- It is useful when an action must happen before checking the condition.
  
- The `while` condition must end with `;`.
  
- It can also be used to create menu-driven programs.

## 🎯 Summary-

```text
       do
        ↓
   Execute Body
        ↓
     Condition
      /     \
   True     False
    ↓         ↓
  Repeat     Stop
```
