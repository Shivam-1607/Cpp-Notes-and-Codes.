# 📄24.Arrays Basics-

## 📌 Theory-

-An **array** is a collection of multiple values of the **same data type** stored under one variable name.

-Instead of creating separate variables:

```cpp
int marks1 = 80;
int marks2 = 75;
int marks3 = 90;
```

-We can use an array:

```cpp
int marks[3] = {80, 75, 90};
```

-Each value in an array is accessed using an **index**.

## 🔹 Syntax

```cpp
data_type array_name[size];
```

-Example:

```cpp
int numbers[5];
```

-This creates an integer array that can store **5 integers**.

## 🔹 Array Index

-C++ arrays use **zero-based indexing**.

-For an array of 5 elements:

```text
Index:     0    1    2    3    4
          ┌────┬────┬────┬────┬────┐
Array:    │ 10 │ 20 │ 30 │ 40 │ 50 │
          └────┴────┴────┴────┴────┘
```

-The first element is at index `0`, and the last element is at index `size - 1`.

## 💻 Creating and Initializing an Array

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Create an integer array containing 5 values
    int numbers[5] = {10, 20, 30, 40, 50};

    // Access the first element using index 0
    cout << numbers[0] << endl;

    // Access the third element using index 2
    cout << numbers[2] << endl;

    // Access the last element using index 4
    cout << numbers[4] << endl;

    return 0;
}
```

### Output-

```text
10
30
50
```

## 🔹 Changing an Array Element

-Array elements can be modified using their index.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[3] = {10, 20, 30};

    // Change the value at index 1
    numbers[1] = 100;

    cout << numbers[0] << endl;
    cout << numbers[1] << endl;
    cout << numbers[2] << endl;

    return 0;
}
```

### Output

```text
10
100
30
```

## 🔹 Array with a `for` Loop

-Arrays are commonly used with loops to process multiple elements.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    // Start from index 0 and continue until index 4
    for (int i = 0; i < 5; i++)
    {
        // Print the element at the current index
        cout << numbers[i] << endl;
    }

    return 0;
}
```

### Output

```text
10
20
30
40
50
```

## 🔹 Taking Array Size from Initialization

-When values are provided during initialization, the size can be omitted.

```cpp
int numbers[] = {10, 20, 30, 40};
```

-C++ automatically determines the size as `4`.

## 🔹 Different Data Types-

-Arrays can contain different types of data, but all elements within one array must have the same type.

### Integer Array-

```cpp
int numbers[3] = {10, 20, 30};
```

### Double Array-

```cpp
double prices[3] = {10.5, 20.5, 30.5};
```

### Character Array-

```cpp
char letters[3] = {'A', 'B', 'C'};
```

## 📝 Important Points-

- An array stores multiple values of the same data type.

- Array indexing starts from `0`.

- The last index is `size - 1`.

- Arrays have a fixed size when declared as built-in C++ arrays.

- Elements are accessed using `array_name[index]`.

- Arrays work very well with loops.

- Accessing an index outside the valid range can cause undefined behavior.

## 🎯 Summary-

```text
              Array
                │
        ┌───────┴───────┐
        ↓               ↓
 Same Data Type     Multiple Values
        │
        ↓
 Index starts at 0
        │
        ↓
 0 → First Element
 1 → Second Element
 2 → Third Element
        │
        ↓
 size - 1 → Last Element
```
# 📄25. Array Input

## 📌 Theory

-Array elements can be entered by the user using `cin`.

-Instead of assigning every element manually, we can use a **loop** to take input for all elements.

-This is useful when working with large arrays.

## 🔹 Basic Syntax

```cpp
for (int i = 0; i < size; i++)
{
    cin >> array[i];
}
```

-The loop starts from index `0` and stores each input value at the corresponding index.

## 💻 Example-

```cpp id="8f7v2m"
#include <iostream>
using namespace std;

int main()
{
    // Create an integer array that can store 5 values
    int numbers[5];

    // Take input for each array element
    for (int i = 0; i < 5; i++)
    {
        // Store the user's input at index i
        cin >> numbers[i];
    }

    // Display the entered values
    cout << "Array elements: ";

    for (int i = 0; i < 5; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Example Input-

```text
10 20 30 40 50
```

### Output-

```text
Array elements: 10 20 30 40 50
```

## 🔹 Input with a Prompt

```cpp id="z8xq2j"
#include <iostream>
using namespace std;

int main()
{
    int marks[5];

    // Take marks for 5 subjects
    for (int i = 0; i < 5; i++)
    {
        // i + 1 makes the subject number start from 1
        cout << "Enter marks for subject " << i + 1 << ": ";
        cin >> marks[i];
    }

    return 0;
}
```

### Example Output-

```text
Enter marks for subject 1: 85
Enter marks for subject 2: 78
Enter marks for subject 3: 92
Enter marks for subject 4: 81
Enter marks for subject 5: 75
```

## 🔹 Calculating the Sum of Array Elements-

-Array input can be combined with calculations.

```cpp id="h2a8xw"
#include <iostream>
using namespace std;

int main()
{
    int numbers[5];
    int sum = 0;

    // Take input for 5 elements
    for (int i = 0; i < 5; i++)
    {
        cin >> numbers[i];

        // Add the current element to sum
        sum = sum + numbers[i];
    }

    cout << "Sum = " << sum;

    return 0;
}
```

### Example Input-

```text
10 20 30 40 50
```

### Output

```text
Sum = 150
```

## 🔹 Taking Array Size from the User-

-A common beginner approach is to ask the user for the number of elements.

```cpp id="v1x5a7"
#include <iostream>
using namespace std;

int main()
{
    int n;

    // Ask for the number of elements
    cout << "Enter number of elements: ";
    cin >> n;

    int numbers[n];

    // Take input for each element
    for (int i = 0; i < n; i++)
    {
        cout << "Enter element " << i + 1 << ": ";
        cin >> numbers[i];
    }

    // Display the elements
    cout << "Array: ";

    for (int i = 0; i < n; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

**Note:** `int numbers[n];` uses a variable-length array, which is **not standard C++**. Standard C++ code should use a compile-time constant size or `std::vector` when the size is known only at runtime.

## 📝 Important Points-

* `cin >> array[i]` stores input at index `i`.
  
* A `for` loop is commonly used to input array elements.
  
* Array indexing starts at `0`.
  
* For an array of size `5`, valid indexes are `0` to `4`.
  
* The loop condition should prevent accessing indexes outside the array.
  
* For runtime-sized collections, `std::vector` is preferred in standard C++.

## 🎯 Summary-

```text
Create Array
     ↓
Start loop at index 0
     ↓
Take input → array[i]
     ↓
Increase i
     ↓
Repeat until all elements are entered
     ↓
Array is ready to use
```
# 📄26 .Array Traversal

## 📌 Theory

-**Array traversal** means visiting each element of an array one by one.

-Traversal is commonly used when we want to:

* Display all elements
  
* Calculate the sum or average
  
* Find the largest or smallest element
  
* Search for a particular value
  
* Perform an operation on every element

-The most common way to traverse an array is by using a `for` loop.

-Each array element is accessed using its **index**.

-For an array of 5 elements:

```text
Index:    0    1    2    3    4
Element:  10   20   30   40   50
```

-The first element is at index `0`, and the last element is at index `size - 1`.

---

## 🔹 Basic Syntax

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i];
}
```

### Explanation-

* `int i = 0` → Start from the first index.
  
* `i < size` → Continue until the last valid index.
  
* `i++` → Move to the next index.
  
* `arr[i]` → Access the current array element.

---

## 💻 Example 1 — Print All Array Elements-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    // Traverse the array from index 0 to index 4.
    for (int i = 0; i < 5; i++)
    {
        // arr[i] gives the element stored at the current index.
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40 50
```

---

## 💻 Example 2 — Traversing an Array Using Its Size-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {5, 10, 15, 20, 25};

    // sizeof(numbers) gives the total memory occupied by the array.
    // sizeof(numbers[0]) gives the memory occupied by one element.
    // Dividing them gives the number of elements.
    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Traverse every element of the array.
    for (int i = 0; i < size; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
5 10 15 20 25
```

---

## 🔹 Forward Traversal-

-**Forward traversal** means visiting elements from the first element to the last element.

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i] << " ";
}
```

-Example:

```text
10 → 20 → 30 → 40 → 50
```

---

## 🔹 Reverse Traversal-

-**Reverse traversal** means visiting elements from the last element to the first element.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Start from the last index: size - 1.
    // Continue while i is greater than or equal to 0.
    // Decrease i after every iteration.
    for (int i = size - 1; i >= 0; i--)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
50 40 30 20 10
```

---

## 💻 Example 3 — Find the Largest Element-

-Array traversal can also be used to perform calculations on every element.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {25, 10, 45, 30, 15};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Assume the first element is the largest initially.
    int largest = numbers[0];

    // Start from index 1 because index 0 is already stored in largest.
    for (int i = 1; i < size; i++)
    {
        // If the current element is greater than largest,
        // update largest with the current element.
        if (numbers[i] > largest)
        {
            largest = numbers[i];
        }
    }

    cout << "Largest element = " << largest;

    return 0;
}
```

### Output-

```text
Largest element = 45
```

---

## 📝 Important Points-

1. Array traversal means **visiting array elements one by one**.
   
2. Array indexing starts from **0**.
   
3. The last index is always `size - 1`.
   
4. A `for` loop is commonly used for array traversal.
   
5. Forward traversal goes from `0` to `size - 1`.
    
6. Reverse traversal goes from `size - 1` to `0`.
    
7. `arr[i]` is used to access the element at index `i`.
    
8. Traversal can be used for searching, sorting, calculating sums, finding maximum/minimum values, and displaying elements.
    
9. Be careful not to access an index outside the valid range.

## 🎯 Summary-

-**Array traversal** is the process of accessing every element of an array systematically.

-The basic forward traversal is:

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i];
}
```

-Reverse traversal can be performed using:

```cpp
for (int i = size - 1; i >= 0; i--)
{
    cout << arr[i];
}
```

-Traversal is one of the most important operations when working with arrays in C++.
