# 📄24.Arrays Basics-

## 📌 Theory-

-An **array** is a collection of multiple values of the **same data type** stored under one variable name.

-Instead of creating separate variables:

```cpp
int marks1 = 80;
int marks2 = 75;
int marks3 = 90;
```

-We can use an array:

```cpp
int marks[3] = {80, 75, 90};
```

-Each value in an array is accessed using an **index**.

## 🔹 Syntax

```cpp
data_type array_name[size];
```

-Example:

```cpp
int numbers[5];
```

-This creates an integer array that can store **5 integers**.

## 🔹 Array Index

-C++ arrays use **zero-based indexing**.

-For an array of 5 elements:

```text
Index:     0    1    2    3    4
          ┌────┬────┬────┬────┬────┐
Array:    │ 10 │ 20 │ 30 │ 40 │ 50 │
          └────┴────┴────┴────┴────┘
```

-The first element is at index `0`, and the last element is at index `size - 1`.

## 💻 Creating and Initializing an Array

```cpp
#include <iostream>
using namespace std;

int main()
{
    // Create an integer array containing 5 values
    int numbers[5] = {10, 20, 30, 40, 50};

    // Access the first element using index 0
    cout << numbers[0] << endl;

    // Access the third element using index 2
    cout << numbers[2] << endl;

    // Access the last element using index 4
    cout << numbers[4] << endl;

    return 0;
}
```

### Output-

```text
10
30
50
```

## 🔹 Changing an Array Element

-Array elements can be modified using their index.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[3] = {10, 20, 30};

    // Change the value at index 1
    numbers[1] = 100;

    cout << numbers[0] << endl;
    cout << numbers[1] << endl;
    cout << numbers[2] << endl;

    return 0;
}
```

### Output

```text
10
100
30
```

## 🔹 Array with a `for` Loop

-Arrays are commonly used with loops to process multiple elements.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    // Start from index 0 and continue until index 4
    for (int i = 0; i < 5; i++)
    {
        // Print the element at the current index
        cout << numbers[i] << endl;
    }

    return 0;
}
```

### Output

```text
10
20
30
40
50
```

## 🔹 Taking Array Size from Initialization

-When values are provided during initialization, the size can be omitted.

```cpp
int numbers[] = {10, 20, 30, 40};
```

-C++ automatically determines the size as `4`.

## 🔹 Different Data Types-

-Arrays can contain different types of data, but all elements within one array must have the same type.

### Integer Array-

```cpp
int numbers[3] = {10, 20, 30};
```

### Double Array-

```cpp
double prices[3] = {10.5, 20.5, 30.5};
```

### Character Array-

```cpp
char letters[3] = {'A', 'B', 'C'};
```

## 📝 Important Points-

- An array stores multiple values of the same data type.

- Array indexing starts from `0`.

- The last index is `size - 1`.

- Arrays have a fixed size when declared as built-in C++ arrays.

- Elements are accessed using `array_name[index]`.

- Arrays work very well with loops.

- Accessing an index outside the valid range can cause undefined behavior.

## 🎯 Summary-

```text
              Array
                │
        ┌───────┴───────┐
        ↓               ↓
 Same Data Type     Multiple Values
        │
        ↓
 Index starts at 0
        │
        ↓
 0 → First Element
 1 → Second Element
 2 → Third Element
        │
        ↓
 size - 1 → Last Element
```
# 📄25. Array Input

## 📌 Theory

-Array elements can be entered by the user using `cin`.

-Instead of assigning every element manually, we can use a **loop** to take input for all elements.

-This is useful when working with large arrays.

## 🔹 Basic Syntax

```cpp
for (int i = 0; i < size; i++)
{
    cin >> array[i];
}
```

-The loop starts from index `0` and stores each input value at the corresponding index.

## 💻 Example-

```cpp id="8f7v2m"
#include <iostream>
using namespace std;

int main()
{
    // Create an integer array that can store 5 values
    int numbers[5];

    // Take input for each array element
    for (int i = 0; i < 5; i++)
    {
        // Store the user's input at index i
        cin >> numbers[i];
    }

    // Display the entered values
    cout << "Array elements: ";

    for (int i = 0; i < 5; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Example Input-

```text
10 20 30 40 50
```

### Output-

```text
Array elements: 10 20 30 40 50
```

# 📄26 .Array Traversal

## 📌 Theory

-**Array traversal** means visiting each element of an array one by one.

-Traversal is commonly used when we want to:

* Display all elements
  
* Calculate the sum or average
  
* Find the largest or smallest element
  
* Search for a particular value
  
* Perform an operation on every element

-The most common way to traverse an array is by using a `for` loop.

-Each array element is accessed using its **index**.

-For an array of 5 elements:

```text
Index:    0    1    2    3    4
Element:  10   20   30   40   50
```

-The first element is at index `0`, and the last element is at index `size - 1`.

---

## 🔹 Basic Syntax

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i];
}
```

### Explanation-

* `int i = 0` → Start from the first index.
  
* `i < size` → Continue until the last valid index.
  
* `i++` → Move to the next index.
  
* `arr[i]` → Access the current array element.

---

## 💻 Example 1 — Print All Array Elements-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    // Traverse the array from index 0 to index 4.
    for (int i = 0; i < 5; i++)
    {
        // arr[i] gives the element stored at the current index.
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
10 20 30 40 50
```

---

## 💻 Example 2 — Traversing an Array Using Its Size-

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {5, 10, 15, 20, 25};

    // sizeof(numbers) gives the total memory occupied by the array.
    // sizeof(numbers[0]) gives the memory occupied by one element.
    // Dividing them gives the number of elements.
    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Traverse every element of the array.
    for (int i = 0; i < size; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
5 10 15 20 25
```

---

## 🔹 Forward Traversal-

-**Forward traversal** means visiting elements from the first element to the last element.

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i] << " ";
}
```

-Example:

```text
10 → 20 → 30 → 40 → 50
```

---

## 🔹 Reverse Traversal-

-**Reverse traversal** means visiting elements from the last element to the first element.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Start from the last index: size - 1.
    // Continue while i is greater than or equal to 0.
    // Decrease i after every iteration.
    for (int i = size - 1; i >= 0; i--)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text
50 40 30 20 10
```

---

## 💻 Example 3 — Find the Largest Element-

-Array traversal can also be used to perform calculations on every element.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {25, 10, 45, 30, 15};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Assume the first element is the largest initially.
    int largest = numbers[0];

    // Start from index 1 because index 0 is already stored in largest.
    for (int i = 1; i < size; i++)
    {
        // If the current element is greater than largest,
        // update largest with the current element.
        if (numbers[i] > largest)
        {
            largest = numbers[i];
        }
    }

    cout << "Largest element = " << largest;

    return 0;
}
```

### Output-

```text
Largest element = 45
```

---

## 📝 Important Points-

1. Array traversal means **visiting array elements one by one**.
   
2. Array indexing starts from **0**.
   
3. The last index is always `size - 1`.
   
4. A `for` loop is commonly used for array traversal.
   
5. Forward traversal goes from `0` to `size - 1`.
    
6. Reverse traversal goes from `size - 1` to `0`.
    
7. `arr[i]` is used to access the element at index `i`.
    
8. Traversal can be used for searching, sorting, calculating sums, finding maximum/minimum values, and displaying elements.
    
9. Be careful not to access an index outside the valid range.

## 🎯 Summary-

-**Array traversal** is the process of accessing every element of an array systematically.

-The basic forward traversal is:

```cpp
for (int i = 0; i < size; i++)
{
    cout << arr[i];
}
```

-Reverse traversal can be performed using:

```cpp
for (int i = size - 1; i >= 0; i--)
{
    cout << arr[i];
}
```

-Traversal is one of the most important operations when working with arrays in C++.

# 📄27. Array Operations:

## 📌 Theory-

-After creating and traversing an array, we can perform different **operations** on its elements.

-Common array operations include:

* Finding the sum of elements
  
* Finding the average
  
* Finding the largest element
  
* Finding the smallest element
  
* Searching for an element
  
* Counting elements based on a condition

-These operations are usually performed using **loops and array indexing**.

---

## 🔹 Finding the Sum-

-The sum of an array is calculated by adding all its elements.

### Syntax-

```cpp
int sum = 0;

for (int i = 0; i < size; i++)
{
    sum = sum + arr[i];
}
```

### Example-

```cpp id="x7f3ka"
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int sum = 0;

    // Visit every element and add it to sum.
    for (int i = 0; i < size; i++)
    {
        sum = sum + numbers[i];
    }

    cout << "Sum = " << sum;

    return 0;
}
```

### Output-

```text
Sum = 150
```

---

## 🔹 Finding the Average-

-The average is calculated using:

```text
Average = Sum / Number of elements
```

### Example-

-To find the smallest element:

2. Compare it with the remaining elements.

3. If a smaller element is found, update the variable.


## 🔹 Searching for an Element-

-Searching means checking whether a particular value exists in the array.

-A simple method is **linear search**.

### Example-

```cpp id="v8d2lm"
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int target = 30;
    bool found = false;

    // Check every element one by one.
    for (int i = 0; i < size; i++)
    {
        // If the current element matches the target,
        // the element has been found.
        if (numbers[i] == target)
        {
            found = true;
            break; // Stop searching once the element is found.
        }
    }

    if (found)
    {
        cout << "Element found";
    }
    else
    {
        cout << "Element not found";
    }

    return 0;
}
```

### Output-

```text
Element found
```

## 🔹 Counting Elements-

-We can also count how many elements satisfy a particular condition.

### Example — Count Even Numbers

```cpp id="j5nq2s"
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 15, 22, 31, 40, 55};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int count = 0;

    // Traverse the array and check every element.
    for (int i = 0; i < size; i++)
    {
        // An even number has a remainder of 0 when divided by 2.
        if (numbers[i] % 2 == 0)
        {
            count++;
        }
    }

    cout << "Number of even elements = " << count;

    return 0;
}
```

### Output-

```text
Number of even elements = 3
```

5. Linear search checks elements one by one.
    
6. `break` can stop a search when the required element is found.
    
7. `%` can be used to check whether numbers are even or odd.
    
8. Use `double` when an average may contain decimal values.

# 📄28.Array Searching:

## 📌 Theory-

-**Array searching** means finding whether a particular value exists in an array.

-One of the simplest searching techniques is **Linear Search**.

-In linear search, each element is checked one by one from the beginning of the array until:

* The required element is found, or
  
* All elements have been checked.

-For example:

```text
Array:  10  25  30  45  50
Index:   0   1   2   3   4
```

-If we search for `30`, the program checks:

```text
10 → 25 → 30
```

-The element is found at index `2`.

---

## 🔹 Linear Search Syntax

```cpp
for (int i = 0; i < size; i++)
{
    if (arr[i] == target)
    {
        // Element found
    }
}
```

-Here:

* `arr[i]` → Current array element
  
* `target` → Value we are searching for
  
* `i` → Current index

---

## 💻 Example 1 — Search for an Element

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 25, 30, 45, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int target = 30;

    // This variable keeps track of whether the element was found.
    bool found = false;

    // Check every element from the first index to the last index.
    for (int i = 0; i < size; i++)
    {
        // Compare the current element with the target.
        if (numbers[i] == target)
        {
            found = true;

            // Display the position where the element was found.
            cout << "Element found at index " << i;

            // Stop the loop because the element has been found.
            break;
        }
    }

    // If the loop finished without finding the element,
    // found will still be false.
    if (!found)
    {
        cout << "Element not found";
    }

    return 0;
}
```

### Output

```text
Element found at index 2
```

---

## 💻 Example 2 — Search Using User Input

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[5];

    // Take 5 elements from the user.
    cout << "Enter 5 numbers: ";

    for (int i = 0; i < 5; i++)

    for (int i = 0; i < 5; i++)
    {
        if (numbers[i] == target)
        {
            cout << "Element found at index " << i;

            found = true;

            // Stop after finding the first occurrence.
            break;
        }
    }

    if (!found)
    {
        cout << "Element not found";
    }

    return 0;
}
```

### Example Output

```text

Enter number to search: 40
Element found at index 3
```

---

## 🔹 Searching for Multiple Occurrences-

-An element can appear more than once in an array.

-If we want to find **all occurrences**, we should not use `break`.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 20, 40, 20};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int target = 20;

    // Check every element because the target may occur multiple times.
    for (int i = 0; i < size; i++)
    {
        if (numbers[i] == target)
        {
            cout << "Found at index " << i << endl;
        }
    }

    return 0;
}
```

### Output

```text
Found at index 1
Found at index 3
Found at index 5
```

---

## 🔹 Returning the Index

-We can store the index of the found element in a variable.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {5, 15, 25, 35, 45};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    int target = 25;

    // -1 means that the element has not been found yet.
    int index = -1;

    for (int i = 0; i < size; i++)
    {
        if (numbers[i] == target)
        {
            index = i;

            // Stop after finding the first occurrence.
            break;
        }
    }

    if (index != -1)
    {
        cout << "Element found at index " << index;
    }
    else
    {
        cout << "Element not found";
    }

    return 0;
}
```

### Output

```text
Element found at index 2
```

---

## 🔹 Time Complexity

-For an array containing `n` elements, linear search may need to check every element.

-Therefore:

```text
Best Case    → O(1)
Worst Case   → O(n)
```

### Best Case

-The target is the first element.

```text
Target → 10
Array  → 10 20 30 40 50
```

-Only one comparison is needed.

### Worst Case

-The target is the last element or does not exist.

```text
Array → 10 20 30 40 50
Target → 100
```

-Every element must be checked.

---

## 📝 Important Points-

1. Searching means finding a particular value in an array.
   
2. **Linear Search** checks elements one by one.
   
3. Linear search works even when the array is **not sorted**.
   
4. `arr[i] == target` checks whether the current element matches the target.
   
5. `break` stops the loop after finding the first occurrence.
    
6. Remove `break` when you want to find all occurrences.
    
7. Array indexes start from `0`.
    
8. `-1` is commonly used to indicate that an element was not found.
    
9. Linear search has a worst-case time complexity of **O(n)**.

## 🎯 Summary-

-The basic idea of linear search is:

```text
Start
  ↓
Check first element
  ↓
Is it the target?
  ↓ No
Check next element
  ↓
Continue until found or array ends
```

-Basic implementation:

```cpp
for (int i = 0; i < size; i++)
{
    if (arr[i] == target)
    {
        // Element found
        break;
    }
}
```
-Linear search is one of the fundamental array algorithms and is an important foundation for learning more advanced searching techniques.
# 📄29.Array Sorting-

## 📌 Theory-

-**Array sorting** means arranging the elements of an array in a specific order.

-The two common orders are:

* **Ascending order** → Smallest to largest
  
* **Descending order** → Largest to smallest

-For example:

```text
Original:
40 10 30 20 50

Ascending:
10 20 30 40 50

Descending:
50 40 30 20 10
```

-One of the simplest sorting algorithms to understand is **Bubble Sort**.

---

## 🔹 Bubble Sort

-**Bubble Sort** repeatedly compares two adjacent elements.

-If they are in the wrong order, they are swapped.

-For ascending order:

```text
if arr[j] > arr[j + 1]
```

-then the two elements are swapped.

### Basic Idea

-Suppose we have:

```text
5  3  8  1
```

-First comparison:

```text
5 > 3
```

-Swap:

```text
3  5  8  1
```

-Next:

```text
5 < 8
```

-No swap.

-Next:

```text
8 > 1
```

-Swap:

```text
3  5  1  8
```

-The largest element has moved toward the end.

-This process is repeated until the entire array is sorted.

---

## 🔹 Bubble Sort Syntax-

```cpp
for (int i = 0; i < size - 1; i++)
{
    for (int j = 0; j < size - i - 1; j++)
    {
        if (arr[j] > arr[j + 1])
        {
            // Swap the elements
        }
    }
}
```

-There are two loops because multiple passes are required.

---

## 💻 Example 1 — Bubble Sort in Ascending Order-

```cpp id="u3f7q2"
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {50, 20, 40, 10, 30};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Outer loop controls the number of passes.
    for (int i = 0; i < size - 1; i++)
    {
        // Inner loop compares adjacent elements.
        // After every pass, the largest unsorted element
        // moves toward the end of the array.
        for (int j = 0; j < size - i - 1; j++)
        {
            // If the current element is greater than
            // the next element, they are in the wrong order.
            if (numbers[j] > numbers[j + 1])
            {
                // Store the current element temporarily.
                int temp = numbers[j];

                // Move the next element to the current position.
                numbers[j] = numbers[j + 1];

                // Put the original current element in the next position.
                numbers[j + 1] = temp;
            }
        }
    }

    // Display the sorted array.
    cout << "Ascending order: ";

    for (int i = 0; i < size; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output-

```text id="3x8v1a"
Ascending order: 10 20 30 40 50
```

---

## 🔹 Understanding the Swap-

-The following code swaps two values:

```cpp
int temp = numbers[j];
numbers[j] = numbers[j + 1];
numbers[j + 1] = temp;
```

-Suppose:

```text
numbers[j]     = 50
numbers[j + 1] = 20
```

-Step 1:

```text
temp = 50
```

-Step 2:

```text
numbers[j] = 20
```

-Step 3:

```text
numbers[j + 1] = 50
```

-Result:

```text
20 50
```

## 💻 Example 2 — Bubble Sort in Descending Order-

-For descending order, the comparison is reversed.

```cpp id="4z9v2k"
#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {50, 20, 40, 10, 30};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    // Perform multiple passes through the array.
    for (int i = 0; i < size - 1; i++)
    {
        // Compare adjacent elements.
        for (int j = 0; j < size - i - 1; j++)
        {
            // For descending order, swap when the
            // current element is smaller than the next.
            if (numbers[j] < numbers[j + 1])
            {
                int temp = numbers[j];

                numbers[j] = numbers[j + 1];

                numbers[j + 1] = temp;
            }
        }
    }

    cout << "Descending order: ";

    for (int i = 0; i < size; i++)
    {
        cout << numbers[i] << " ";
    }

    return 0;
}
```

### Output

```text id="y4n7w1"
Descending order: 50 40 30 20 10
```

---

## 🔹 Bubble Sort Passes

-Consider:

```text
5  3  4  1
```

### Pass 1

-Compare `5` and `3`:

```text
3  5  4  1
```

-Compare `5` and `4`:

```text
3  4  5  1
```

-Compare `5` and `1`:

```text
3  4  1  5
```

-Largest element `5` is now at the end.

### Pass 2

```text
3  4  1  5
```

-Compare `3` and `4` → no swap.

-Compare `4` and `1` → swap:

```text
3  1  4  5
```

### Pass 3

-Compare `3` and `1` → swap:

```text
1  3  4  5
```

-The array is now sorted.

---

## 🔹 Time Complexity-

-For the basic Bubble Sort algorithm:

```text
Best Case    → O(n²)
Worst Case   → O(n²)
```

-Bubble Sort uses nested loops, so it can become slow when the array contains many elements.

-There are optimized versions of Bubble Sort that can achieve **O(n)** in the best case when the array is already sorted.

---

## 📝 Important Points-

1. Sorting arranges array elements in a particular order.
   
2. Ascending order goes from **smallest to largest**.
   
3. Descending order goes from **largest to smallest**.
   
4. Bubble Sort compares **adjacent elements**.
   
5. Elements are swapped when they are in the wrong order.
    
6. A temporary variable can be used to swap two values.
    
7. Bubble Sort uses nested loops.
    
8. Basic Bubble Sort has **O(n²)** time complexity.
    
9. The comparison condition determines whether the array is sorted in ascending or descending order.

## 🎯 Summary-

-Bubble Sort repeatedly compares neighboring elements and swaps them when necessary.

### Ascending

```cpp
if (arr[j] > arr[j + 1])
```

### Descending

```cpp
if (arr[j] < arr[j + 1])
```

-The general process is:

```text
Compare → Swap if necessary → Repeat → Sorted Array
```

-Bubble Sort is simple and useful for learning sorting fundamentals, although more efficient sorting algorithms are normally preferred for large datasets.
